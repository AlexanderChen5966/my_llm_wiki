## R（操作步驟）

### 四大階段

1. **構想期（Idea Stage）** — 用研究換取建構許可
   - 退出條件：問題-解方契合度（Problem-Solution Fit）
   - 陷阱：42% 新創失敗因建構沒人要的東西；AI 讓這更容易發生
2. **MVP 期** — 快速建構，避免技術負債複利
   - 退出條件：真正的產品市場契合度（PMF）
   - 關鍵：從第一天起建立持續性脈絡（CLAUDE.md）
3. **上市期（Launch Stage）** — 可重複的永續成長引擎
   - 退出條件：成長可重複 + 產品承受生產負載 + 運營不依賴創辦人
4. **規模期（Scale Stage）** — 建構護城河
   - 三大護城河：深度專業知識、整合深度、用戶行為數據飛輪

### Claude 三工具分工

| 工具 | 定位 | 最適用時機 |
|------|------|-----------|
| Claude Chat | 快速交流 | 提取重點、確認聲明正確性 |
| Claude Cowork | 知識工作完整成品 | 整合逐字稿、建立競爭格局 |
| Claude Code | 代理式程式設計 | 程式碼、Plan Mode、git 整合 |
