## 核心論點

Google IO 2026 Chrome 宣告代理式網路時代：WebMCP 讓 AI 代理直接呼叫網站結構化工具；Modern Web Guidance 引導 code agent 建構現代網頁；Chrome 內建 Gemini Nano 讓 AI 在瀏覽器端執行。

## 三大主軸

1. **WebMCP**（Chrome 149）：開放標準，讓網站暴露 JS 函式 / HTML 表單給代理直接呼叫
2. **Modern Web Guidance**：Antigravity 一鍵安裝的常青技能，引導 agent 產出符合 Baseline 的現代網頁
3. **Chrome DevTools for Agents**：代理可直接存取 Console log、Network 流量、Accessibility tree 進行自動偵錯
