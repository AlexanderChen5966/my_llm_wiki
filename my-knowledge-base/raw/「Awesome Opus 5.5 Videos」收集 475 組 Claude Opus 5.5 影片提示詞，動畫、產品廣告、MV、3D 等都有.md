## 「Awesome Opus 5.5 Videos」收集 475 組 Claude Opus 5.5 影片提示詞的免費專案

Awesome Opus 5.5 Videos 是一個專門收集 Claude Opus 5.5 影片生成案例與提示詞的免費開源專案，主要整理網路上創作者使用 Claude Opus 5.5 製作出的動畫、3D 場景、互動效果與視覺作品。目前專案已經收集 475 組提示詞，而且還在更新中。除了保留作品成果之外，也會附上原作者使用的提示詞與來源貼文，方便其他人直接研究、複製，甚至修改成自己的版本。

值得一提的是，這裡所謂的「Claude 生成影片」，不是像 Sora、Veo 一樣直接由 AI 產生一段影片，而是讓 Claude Opus 5.5 根據提示詞撰寫 HTML、Canvas、SVG、Three.js 等程式碼，再由瀏覽器即時渲染成動畫。

因此可以看到非常多不同風格的成果，像是動態視覺、文字動畫、UI 展示、產品宣傳、資訊圖表、科普解說、3D 場景，甚至小遊戲與互動式作品都有。部分作品還會搭配 GSAP、GLSL、粒子特效、Web Audio 等技術，做出接近專業 Motion Graphics 的視覺效果。

主要特色

- 免費開源的 Claude Opus 5.5 影片 Prompt 收藏專案
- 已收集超過 470 組實際使用過的 Prompt
- 每個案例皆附上原作者貼文或來源
- README 精選 100 組代表性作品
- 涵蓋 Motion Graphics、科普解說、3D 場景、遊戲與互動作品
- 常見技術包含 HTML、Canvas、SVG、Three.js、GSAP、GLSL 等
- Prompt 可直接複製，再修改成自己的主題與風格
- Skillry 提供原始作品與 Live Remake 對照觀看
