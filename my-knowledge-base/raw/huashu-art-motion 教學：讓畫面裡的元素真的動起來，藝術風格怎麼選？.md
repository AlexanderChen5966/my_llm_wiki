一張插畫慢慢放大，和畫裡的風、光、角色真的在動，是兩種不同的觀看感受。huashu-art-motion 想處理的是後者，先設計畫面，再讓元素按各自的規律運動。

這套 Skill 是給程式代理讀取的動畫工作規則，提供風格做法、程式場景與解說範例。因為每種風格都指定可辨識的動作，使用時要交代「什麼在動」，只寫畫家名字還不夠。

它適合需要藝術轉場、課程插段或圖表解說的人。先挑一種表現方式做短段，確認動畫有幫助傳達內容，再延伸成整片。

## huashu-art-motion 的風格卡與原始專案在哪裡？

[Vox 的 X 分享](https://x.com/Voxyz_ai/status/2109690569563746755?ref=aiposthub.com) 介紹了這套工具的藝術風格與解說用法；真正的安裝方式、範例與限制，要回到 [花叔的原始專案](https://github.com/alchaincyf/huashu-art-motion?ref=aiposthub.com) 查看。

專案持續補充內容，因此分享貼文與專案首頁的風格數量可能不同。選用時直接看所需的那張風格卡與範例，會比背總數更實用。

風格卡的作用是把審美描述拆成可執行規則。例如星空可以旋轉、燈光可以向外擴散，讓代理知道畫面內部需要改變什麼。

## 先選主動作，再決定藝術風格

假設要替讀書課程做一段十幾秒動畫，先決定「書頁打開，內容變成一座城市」。這是觀眾跟得上的主動作，配色與筆觸再圍繞它選擇。

下面幾種需求，適合交給代理用不同方式處理：

| 想讓觀眾理解的事 | 先說清楚的畫面行為 |
| --- | --- |
| 一個觀念變成下一個觀念 | 哪個形狀保留、哪個部分變形 |
| 數據隨時間變化 | 座標先出現，數值如何逐步增加 |
| 穿越不同藝術世界 | 主角往哪裡走，跨界時哪些東西換風格 |

畫面行為確定後，再請代理提出不同的構圖。不要只把範例的人物、桌子或房間換個顏色，否則新題材仍會被舊構圖限制。

## 可複製的藝術動畫需求範本

先依原始專案安裝並檢查繪圖環境，再於載入該 Skill 的 Claude Code 專案送出需求。先做關鍵影格，即可檢查風格與構圖。

以下為本站改寫的創作需求，非 Vox 或花叔的逐字 prompt，尚未做成片實測。

```
用 huashu-art-motion 製作 15 秒直式動畫。
主題：一本書打開後，書頁變成一座會呼吸的城市。
先讀專案對應的風格卡，提出三種不同構圖供我選。
先給靜態關鍵影格，選定後才製作完整動畫。
主動作是書頁展開並形成城市，不要只做整張圖的縮放。
安排兩項配合風格的循環動作，例如窗光與雲的移動。
如需要人物，先詢問我是否提供自己的角色圖。
輸出短片、可再修改的程式與各場景時間表。
```

## 驗收時，把鏡頭移動和物件移動分開看

先暫時忽略鏡頭，確認畫面裡仍有清楚的主動作。若只剩背景緩慢移動，就要重寫動作需求，而不是再增加濾鏡。

再檢查轉場前後的主體位置。如果觀眾需要重新尋找主角，轉場再華麗也會打斷故事。可以先鎖定一條移動路徑，讓風格改變發生在同一個位置附近。

專案提供數值檢查與看片流程，但通過腳本不表示敘事一定清楚。最後仍要看一遍正常速度的成片，確認文字能讀完、主體找得到。

### huashu-art-motion 的範例可以全部直接商用嗎？

專案把程式與文件的授權，和作者角色、部分示範影像分開說明。沿用工具時，應使用自己的角色或已取得權利的素材。

### 想做講課動畫，也需要模仿特定畫家嗎？

不需要。白板、圖表、形狀變化等解說語法更適合某些教學內容，選擇能讓觀念看懂的畫面即可。

先把一段口播改成一個可看懂的主動作，再比較三種構圖，這會是開始使用這套工具的好練習。
