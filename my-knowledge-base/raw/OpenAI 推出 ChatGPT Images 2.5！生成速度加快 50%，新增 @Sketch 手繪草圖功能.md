OpenAI 於台灣時間 9 月 9 日凌晨在官方部落格正式宣布推出 ChatGPT Images 2.5，這是繼今年 4 月 Images 2.0 發布後最大規模的影像生成升級。新版主打更快的生成速度、更銳利的細節、更精確的編輯控制，並新增「Sketch」繪圖功能與模板分享機制。根據官方數據，每週全球使用者在 ChatGPT Images 與 API 上創造超過 30 億張圖片，Images 2.5 的推出將進一步擴大這項服務的應用範圍。  

## ChatGPT Images 2.5 生成速度提升 50%，品質全面進化

根據官方說明，ChatGPT Images 2.5 最直接的進步是速度。與 Images 2.0 相比，新版將影像生成延遲降低了約 50%，對於需要快速迭代創意的使用者來說，這個差距相當有感，意味著在同樣時間內可以產出更多想法並進行更多輪調整。無論是快速出圖還是精細生成，使用者都能以更短的時間獲得結果。

![](https://www.youtube.com/watch?v=6l7ble9P74o)

在品質方面，Images 2.5 能夠產出更自然的光影與更豐富的紋理細節，在保留參考照片中的主體特徵上表現更好，並且能更可靠地遵循多輪編輯指令。官方強調，模型在處理複雜構圖時能維持更一致的編輯效果，每次修改不會導致畫面品質隨時間遞減，這對需要多次調整的設計工作流程是實質性的改善。對於使用 API 的開發團隊來說，這項一致性讓以參考照片為核心的工作流程更可靠，變化版本也能始終錨定原始來源，不會在多次迭代中逐漸偏離。

新版本同時改善了智慧與風格表現。Images 2.5 能更準確理解複雜的視覺指令，包含真實世界資訊的圖片內容更精確，也支援透明背景等進階版面配置。風格呈現方面，模型更能忠實反映使用者的藝術風格要求，在生成一系列品牌素材或 UI 概念時不易偏離原本的視覺方向。官方指出，這對需要大量一致風格素材的企業用戶尤其重要，無論是生成一系列品牌創意素材、保持特定階層結構的 UI 概念，或是符合既定版面框架的簡報視覺，Images 2.5 的表現都更可靠。

### 「Sketch」繪圖：輸入 @Sketch 即可手繪草圖

這次更新中最令人矚目的新功能是「Sketch」繪圖工具。使用者現在可以直接在 ChatGPT 介面中繪製草圖，並將這些手繪內容作為影像生成的參考基準。官方表示，只要在 ChatGPT 中輸入「@Sketch」即可啟動這項功能。無論是快速勾勒房間佈局、服裝輪廓，還是單純畫個有趣的塗鴉，ChatGPT 都會將草圖轉化為完整的圖片。使用者不需要是專業藝術家，Sketch 只是讓最終生成的影像更貼近腦中原貌的另一種溝通方式。

此外，OpenAI 還推出了針對常見影像格式的模板功能，涵蓋海報（Poster）、商品（Merch）等熱門格式，讓使用者不必從零開始，只需選擇模板再填入細節即可快速生成符合需求的視覺內容。結合「提示分享」機制，使用者可以將自己設計的影像生成提示分享給其他人，例如官方舉例的「如果你活在 80 年代會是什麼樣子」這類在社群上病毒式擴散的提示模板。而「以評論編輯」的功能則讓指定局部修改更加直覺，系統只會調整指定區域，其他部分保持不變。

### 開發者 API：Flare 與 Sunburst 雙版本

OpenAI 也針對開發者推出了兩款 API 模型。GPT-Image-2.5 Flare 是預設版本，適合大多數應用場景，在品質提升的同時保持比 GPT-Image-2 低 50% 的延遲，適用於社群內容創作、產品視覺體驗、視覺搜尋、快速原型設計與高量生成等任務，在效率與品質之間取得良好平衡。GPT-Image-2.5 Sunburst 則針對高階視覺工作流程設計，提供更嚴格的編輯控制，適合廣告素材、產品型錄生成等專業場景，但生成時間也相對較長。

早期使用者 Higgsfield AI 的產品主管 Axultan Alimkulov 表示：「GPT-Image-2.5 Flare 在品質、編輯精確度與速度方面的表現令人印象深刻，讓我們能為用戶創造更流暢的創作體驗。」Higgsfield AI 是一家專注於 AI 影像與影片生成的平台，他們的回饋代表了開發者社群對新版 API 的正面評價。

### 安全機制與系統卡

OpenAI 在官方部落格中也說明了 Images 2.5 的安全措施，建立在既有的防護機制之上，對提示詞與生成圖片進行審查以防止有害內容輸出。官方持續採用 C2PA 元資料與不可見浮水印技術，協助識別由 OpenAI 工具生成的圖片，並發布了系統卡（System Card）詳細說明評估方法與安全方針。這套安全架構從 Images 2.0 時期就已建立，2.5 版在品質進步的同時維持了相同水準的安全防護。

### 結語

ChatGPT Images 2.5 的升級集中在三大方向：速度提升 50%、品質細節強化、以及編輯與分享機制的全面完善。每週超過 30 億張的生成量已經證明 ChatGPT Images 是當今最大規模的 AI 影像平台之一，而 2.5 版的推出進一步鞏固了這項地位。從 @Sketch 手繪草圖到提示分享的社群機制，OpenAI 正逐步將影像生成從單次輸出推向反覆協作的創作模式，讓每個人都能更輕鬆地將自己腦中的畫面變成現實。
