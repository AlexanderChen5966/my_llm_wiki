## 一、Claude 是什麼？為什麼它不只是聊天機器人

Claude 與同類產品相比語感相對自然，不容易讓人一眼就看出是 AI 寫的機械腔。更重要的是，搭配 Skills、Cowork 等工具（未來幾期會員專刊會逐一介紹），不只給你建議，更會實際幫你完成工作。

## Claude 方案怎麼選？免費版、Pro、Max 差在哪

開始使用前，需要先在 claude.ai 建立帳號。Claude 目前提供四種方案：免費版（$0）適合偶爾體驗；Pro 約每月 20 美元（或每年 200 美元）、提供標準用量，適合定期使用；Max 5x 約每月 100 美元、提供 Pro 五倍的使用容量，適合經常用 Claude 處理各種任務的人；Max 20x 約每月 200 美元、提供 Pro 二十倍的使用容量，適合每天大量使用、且經常需要協作的重度用戶。建議讀者們先從免費版試用，熟悉操作後升級至 Pro，才能完整解鎖後面會介紹的進階功能。（付費用戶注意：Anthropic 不定期提供免費額度回饋，可參考 [Claude 免費額度領取教學](https://www.bnext.com.tw/article/90528/claude-free-credit-claim-guide) 。）

### Chat 模式是什麼？一般問答與寫作先用它

預設用 Chat 模式就夠了。Chats 管理所有一般對話的地方，可以瀏覽、搜尋或讓 Claude 幫你從過往聊天裡找回需要的資訊。

### Cowork 模式是什麼？適合交辦多步驟任務

Cowork 比較像是請 Claude 當你的「AI 同事」，一起管理專案、分配任務和追進度。

### Code 模式是什麼？適合寫程式、除錯與建立工具

Code 則是專門處理程式碼、寫程式和除錯的模式，初學者可以先不用理它。

### Customize（邊欄上方）怎麼用？設定 Claude 的記憶、語氣與 Skills

這是 Claude 的「個性化設定中心」，可以告訴 Claude 你的身份、偏好語氣、輸出格式；點進去後會看到 Memory、Style 等選項，用來調整它回覆你的風格。這裡同時也是開發與管理 Skills 的入口，團隊可以在此為特定情境打造專用技能。

### Projects 怎麼用？把同一任務的資料集中管理

Projects 讓你把同一個任務相關的對話，集中在一個獨立的「工作空間」裡，裡面可以共用同一組指令、上傳的文件與背景脈絡。

### Artifacts 是什麼？用來保存文件、程式碼與小工具

Artifacts 則會把 Claude 幫你產生、而且足夠完整的文件、程式碼或小工具，放到專用的「作品區」，方便之後打開、修改或重用。

### 對話紀錄（Starred / Recents）

把重要的聊天串加上星號，就會固定收在 Starred 裡，不會被後續的新對話往下擠掉。Recents 則是你最近開過的對話列表，運作方式很像通訊 App 的聊天紀錄，方便快速回到剛剛聊過的內容。

### 對話輸入欄

這裡是跟 Claude 互動的核心區域，直接打字送出就能開始對話。輸入欄右側的模型選擇器（例如 Sonnet 4.6）可以切換不同版本的 Claude，而「Extended」則代表啟用較長思考時間與篇幅的回覆模式，適合處理比較複雜或篇幅較大的任務。

### ＋ 按鈕

點下去會展開工具列，包括 Research（讓 Claude 代你搜尋並整合多個資訊來源）、上傳檔案（例如 PDF、圖片等）、網路搜尋開關，以及其他與外部工具的整合選項。

## 三、Claude 提示詞怎麼寫？掌握背景、任務、限制 3 個關鍵

「輸入垃圾，輸出也是垃圾。」這句話在 AI 工具上完全成立。

提示詞的品質，是決定 Claude 輸出好不好的最關鍵因素。很多人用 AI 效果不理想，往往不是工具的問題，而是問法的問題。好消息是，這件事有方法可以學。

Anthropic 官方建議，一個有效的提示詞應該包含三個要素。第一是背景設定：告訴 Claude 你是誰、這件事的目的是什麼，讓它在回答之前就掌握必要的脈絡。第二是任務說明：具體描述你要它做什麼，愈精確愈好，不要讓它自己猜測你的意圖。第三是規則限制：格式、語氣、字數、不能做什麼，全部在這裡說清楚。

把這三段組合在一起，你的輸出品質就會超越大多數使用者。完整的範例看起來像這樣：「我是一位行銷企劃，正在為主打 Z 世代的品牌活動準備社群文案。請幫我寫三個版本的活動標題，風格要有衝擊感、能在社群上引發討論，每個標題不超過 20 個字，使用繁體中文。」

![#0 Claude系列教學第一篇](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-07/cury-1782976303.png?w=1200&output=webp)

一般類型的任務，按照三步驟簡易提示法組成一串結構完整的提示詞，就能獲得不錯的結果。

圖／ 《數位時代》

要注意的是，如果對話越來越長，Claude 的回應品質會逐漸下降，這是正常現象。遇到這種情況，直接告訴 Claude「請整理目前的對話脈絡，我們換一個新視窗繼續」即可。有相關背景文件的話，也建議直接上傳附件，比單純用文字描述更有效率。

## 四、Claude 模型怎麼選？Sonnet、Opus、Haiku 適合哪些任務

Claude 目前提供三個主要模型，適合不同類型的任務，選對模型可以在速度與品質之間取得最好的平衡。

### ① Sonnet 適合什麼？日常寫作、分析與大多數任務

是日常使用的主力。它速度快、能力強、最省使用額度，寫作、分析、腦力激盪、一般問答都能勝任。對大多數人來說，八成以上的對話在 Sonnet 上開始和結束就已經足夠。

### ② Opus 適合什麼？複雜推理、深度研究與高難度任務

是 Claude 目前推理能力最強的模型，適合財務分析、深度研究、複雜程式開發，以及任何需要多步驟推理的任務。它支援「延伸思考」模式，開啟後可以看到 Claude 在給出答案之前的完整推理過程，對於需要高度可信度的工作特別有參考價值。代價是速度較慢、消耗額度較高，不適合拿來處理簡單的日常任務。

### ③ Haiku 適合什麼？快速查詢、分類與輕量編輯

是三個模型中最快、最便宜的，免費方案即可使用，適合快速查詢、簡單分類與輕量編輯。它特別適合搭配 Claude 的瀏覽器擴充功能使用，需要快速反應的場景，Haiku 是最好的選擇。

## 五、新手必開的 5 個功能：Connectors、Chrome、Style、Projects、Research

### ① Connectors 怎麼用？串接 Notion、Slack、Google Calendar

讓 Claude 與你常用的工具直接串接，例如 Notion、Slack、Google Calendar。串接後，Claude 可以直接讀取你的行事曆或 Notion 頁面，省去手動複製貼上的時間。設定入口在左下帳號頭像選單內「Settings → Connectors」。

### ② Claude in Chrome 是什麼？在網頁側邊欄直接使用 Claude

這是一個很多人還不知道的 Google Chrome 瀏覽器擴充功能（安裝連結）。裝好之後，Claude 會以側邊欄的形式出現在瀏覽器裡，你可以在任何網頁上直接呼叫它，請它整理當前頁面的內容、幫忙快速提問或生成文字，完全不用再來回切換分頁。

### ③ Use Style 怎麼設定？讓 Claude 固定用你的偏好語氣

讓你設定 Claude 的預設回應風格，例如語氣要偏正式還是口語、比較常用段落敘述還是條列說明，甚至可以要求它先給重點再展開說明。這些偏好只要設定一次，之後的對話就會自動套用；你也可以為不同任務客製多種理想的回覆風格，視情況切換使用。

### ④ Projects 怎麼設定？讓 Claude 記住專案背景資料

是 Claude 裡最被低估的功能之一。你可以建立一個專案，上傳所有相關的文件、背景資料與規則說明，之後在這個專案裡開啟的每一個對話，Claude 都會自動帶著這些背景知識，不需要每次重新說明。對於長期、持續性的工作（例如固定客戶的專案、持續進行的研究計畫），Projects 是必用功能。

### ⑤ Research 模式怎麼用？讓 Claude 搜尋並整理資料來源

啟用後，Claude 不會立刻回答，而是先拆解你的問題、主動搜尋多個外部資訊來源並做基本的交叉比對，最後輸出一份附有引用來源的完整研究報告。等待時間會隨題目複雜度而變化，通常需要數分鐘，少數特別龐雜的問題可能會更久；但對於需要深入調查的主題，這已經是目前市場上最省力的研究型工具之一。

Research 模式也在「＋」選單內。輸入想研究的問題時，可以視需要附上檔案或其他資料來源，並選擇使用 Research 或 Web search。若只啟用 Research，Claude 會優先根據你提供的檔案與內容進行深入整理；若同時勾選 Research 與 Web search，則會在整理附檔的同時，一併補充網路上可查到的相關資訊，最後產出一份帶有引用來源的詳盡回答。

## 六、Claude 進階工具有哪些？Cowork、Claude Code、Skills 差在哪

以下介紹的功能，是 Claude 真正拉開與其他 AI 工具距離的地方。部分功能需要下載桌面版 Claude App 才能使用。（ [安裝連結](https://claude.com/download) ）

## 第一次使用 Claude，建議從哪 3 個任務開始

### ① Cowork 怎麼用？讓 Claude 在背景執行工作

是 Claude 的自主執行功能，目前僅限桌面版。開啟後，Claude 可以在背景獨立處理任務：讀取你電腦裡的檔案、依照排程執行工作、完成一系列操作，不需要你全程盯著畫面。你也可以在 Cowork 裡設計或安裝一組組「Plug-ins（外掛工作流程）」，把多個步驟包成一套自動化系統。

Anthropic 提供了多種官方範本，涵蓋法律、行銷、財務等常見場景；每一套流程都像一位熟悉特定工作的虛擬同事，已經理解你的品牌語氣與輸出格式，可以直接產出可用成果，而不只是幫你完成單一步驟。

![#2 Claude系列教學第一篇](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-07/kgvv-1782976304.png?w=1200&output=webp)

圖／ 《數位時代》

Cowork 是桌面版 Claude 才有的「自動幫你做事」模式。它不只是聊天，而是可以在你電腦上讀取本機檔案、根據指示執行一連串步驟，像是整理資料、產出報告、排程任務等。你可以為 Cowork 設計或安裝事先定義好的工作流程，讓它在背景幫你跑完整個流程，最後交出可再編輯的成果，例如 DOCX 或 PPTX 檔案，完整設定步驟可參考： [Claude Cowork 是什麼、怎麼用？新手 10 分鐘設定教學](https://www.bnext.com.tw/article/91158/from-chat-to-cowork-local-claude-workflow-guide) ，或直接看 [6 步驟做出可編輯的 PPT](https://www.bnext.com.tw/article/90392/claude-cowork-ai-ppt) 。

### ② Claude Code 是什麼？用自然語言寫程式與除錯

是目前少數能完整涵蓋開發流程的 AI 程式工具，可以在 Claude 桌面版 App 或終端機指令列使用。（尚未安裝的讀者可先看 [Claude Code 安裝教學](https://www.bnext.com.tw/article/90451/claude-code) ）

你只要用自然語言描述需求，Claude Code 就能自動寫出程式碼、建立網頁、修復錯誤，甚至協助執行測試與除錯。即使你不是軟體工程師，也可以用 Claude Code 完成許多過去必須委外、或需要開發團隊支援的技術工作，例如 [做出你的第一個瀏覽器外掛](https://www.bnext.com.tw/article/91402/claude-code-no-coding-4-steps-build-your-own-tool-guidebook)

### ③ Claude Skills 是什麼？把常用工作流程存成一鍵指令

把你反覆在用的提示詞，存成一個可以一鍵呼叫的指令。設定入口在主頁的「Customize → Skills」。假設你每天都要讓 Claude 整理會議記錄，過去每次都要重新說明格式規則；設定成一個 Skill 之後，只要在對話中指定使用該 Skill，或在 Skills 清單中點選，它就會依照設定好的流程自動執行。

你甚至可以直接請 Claude 幫你建立 Skills，只要描述你的工作流程，它會先幫你草擬一組指令，再由你視需要微調細節。想深入了解 Skill 架構與進階用法，可參考 [Claude Skill 教學：如何建立自己的 Skill？](https://www.bnext.com.tw/article/89709/claude-code-skills)

技術上，每個 Skill 都會被存成一個結構化的 skill.md 檔案，裡面用固定格式記錄角色設定、步驟與輸出規則；對使用者來說，你只需要一鍵叫用，而不必每次從頭輸入整段提示。

```
name: explain-like-friend
description: 用朋友的口吻，把任何主題講到一般人聽得懂，附上關鍵重點與可採取行動。適合用在：看不懂的文章、技術名詞、政策說明、商業簡報。
argument-hint: [主題或貼上的文字]
---

你是「一般使用者友善說明助手」。當使用者貼一段文字、丟一個名詞、或問「這在講什麼」時，請依照下面步驟回應。

## 回答風格

- 使用自然口語、像在跟朋友聊天，但保持有禮、專業
- 避免專有名詞；不得不用時，要順手加一句白話解釋
- 以「一般成人、非專業背景」為預設讀者
- 控制在 3～6 個短段落內，不要長篇大論

## 回答結構（每次都要有）

1. **一句話總結**
   - 先用一句話講：這在「大概在說什麼」，避免抽象形容
   - 模板例子：
     - 「這段主要在說：XXX 公司打算怎麼賺錢。」
     - 「簡單講，就是政府要對 XXX 做新的規定。」

2. **用生活比喻解釋一次**
   - 替主題找一個貼近日常生活的比喻（例如家庭、學校、公司、排隊、賣東西）
   - 格式範例：
     - 「你可以想像成……」
     - 「如果用日常例子來比喻，就是……」

3. **三點重點整理**
   - 用 3 點列出「這件事最重要的重點」
   - 每點一句話為主，必要時補半句說明
   - 優先回答：
     - 這件事是什麼？
     - 為什麼現在出現？
     - 誰會受到影響？

4. **如果我是一般人，這跟我有什麼關係？**
   - 說明對「一般使用者」可能的影響：
     - 會不會影響到他日常使用的服務或工作
     - 有沒有需要特別注意的風險或好處
   - 模板例子：
     - 「如果你是上班族，可能會看到……」
     - 「如果你是學生／家長，實際感受會是……」

5. **可以立刻做的 1～3 個行動**
   - 根據內容給 1～3 個具體可做的事情（選擇最實際的）
   - 例如：
     - 「如果你有在用這個服務，可以先確認……」
     - 「未來簽約、買東西時，可以多注意……」
     - 「如果你是相關從業人員，可以開始思考……」

## 回答時的注意事項

- 優先忠實轉述原文內容，不要腦補不存在的資訊
- 不要替任何公司或政府背書，也不要使用「一定會」「保證」這類字眼
- 如果原文資訊不完整、或你不確定，請直說：
  - 「這段文字沒有講清楚 XXX，所以以下是合理推測，而不是既定事實。」
- 避免使用行銷式口吻（例如「顛覆」「秒殺」「革命性」），改用可觀察、可驗證的描述。

## 使用說明給模型（非使用者）

當使用者：

- 問「這在講什麼」「幫我講成一般人聽得懂」「幫我解釋這篇文章」
- 或貼上一大段文字，沒有明確問題，但看起來像新聞／公告／報告／技術說明

你都可以自動套用本 skill 的結構來回答。  
若使用者有特別指明對象（例如「跟我爸媽解釋」），請在「比喻」與「關係」段落中順手調整對象，但仍然維持同樣的五段結構。
```

從客服到數位員工：宏華國際如何用 AI Agent 幫企業把握每一筆商機？

宏華國際將客服經驗模組化、場景化，打造出適用多元產業的 AI 客服代理人，協助企業降低導入門檻與試錯成本，加速 AI 落地應用。

---

分享

隨著生成式 AI 與 AI Agent 的快速發展，企業導入 AI 應用，早已不是「要不要」的是非題，而是「如何選對解決方案」的決策題。

以 AI 客服為例，市場上雖然有眾多解決方案，但真正能夠拉開差距的，不是技術本身，而是對產業場景、服務流程與顧客需求的理解，這是決定AI 能否改善營運效率、提升顧客體驗，並創造實際商業價值的關鍵。

深耕客服領域多年的宏華國際，憑藉著長期累積的第一線服務經驗，以及對產業應用場景的深刻洞察，打造出適用多元產業的 AI 客服代理人，透過將客服經驗模組化、場景化，協助企業降低 AI 導入門檻與試錯成本，讓 AI 不只是技術工具，而是真正能快速落地、創造營運效益的虛擬助手。

## 有溫度的 AI 服務，成為企業競爭力的新關鍵

宏華國際資深技術顧問李宗遠指出，對企業、尤其是服務業而言，客服的價值早已不只是接聽電話或回覆訊息，而是建立顧客信任、優化服務體驗的重要平台。透過客服，企業不僅能維持對外溝通的一致性與完整性，也能延伸服務時間與服務範圍，進而即時掌握顧客需求，有效承接每一次商機。

然而，過去要打造全天候客服，企業往往需要投入大量人力與管理成本。如今，AI大幅降低了建置與維運成本，24 小時服務不再是大企業的專利。透過 AI 客服代理人，即使是資源有限的中小企業，也能在不額外增加人力的前提下，快速建立客服機制，提供更貼心、更有溫度的服務，而這也將成為未來服務業的重要競爭力。

以餐飲業為例，消費者有聚餐需求時，通常會透過網路訂位系統同時向多家餐廳預約，等到接近用餐日時，再做出最終選擇。此時，餐飲業者若能在網路訂位流程中整合 AI 客服代理人，主動提供完整且貼心的一條龍服務，例如：推薦適合餐點、提醒停車資訊、確認特殊飲食需求，甚至提前規劃包廂與慶生活動等，讓顧客到店前就有好的服務體驗，自然有機會打動顧客的心、成為最終選擇。

李宗遠認為，AI 的價值不只是提升效率，更在於協助企業打造更有溫度的服務，這不僅有助於降低臨時取消率、提升訂單轉換率與顧客黏著度，更能建立差異化競爭優勢，讓 AI 從工具真正成為企業夥伴。

## AI 客服下一階段，比的不是技術，而是誰更懂服務場景

然而，AI 要打造有溫度的服務，關鍵不在於採用了哪些技術，而是 AI 能否真正理解不同產業的服務場景與顧客需求。為此，宏華將多年來服務不同產業、不同場景所累積的第一線經驗，轉化為開發 AI 客服代理人的重要基礎，讓 AI 不只是回答問題，更能理解企業的服務流程，以及客戶的情緒與潛在需求，提供更貼近人性的互動體驗。

李宗遠認為，宏華 AI 客服代理人可以為企業帶來三項價值。第一項是將原本仰賴人工處理的流程自動化。AI 客服代理人不僅能線上服務客戶，完成訂位、預約、報修等流程，還能自動執行後續作業，例如：生成維修派工單，並通知師傅前往服務。

第二項則是優化顧客體驗。AI 客服代理人以多模態 AI 作為核心，可以進行語音、文字與影像的互動，因此，顧客透過電話、LINE、社群平台、網站或實體門市等留下的互動記錄，都能整合至同一平台，避免在服務過程中產生斷點。

第三項是延長服務時間與擴大服務範圍，承接更多商機。AI 客服代理人支援國語、台語、英語 24 小時應答，無論顧客在任何時間、透過何種管道聯絡，甚至使用外語，都能獲得即時回覆。

## 十多年客服經驗，如何成為宏華 AI 的護城河？

當 AI 客服的技術能力逐漸成熟，真正難以複製的，不是模型，而是背後累積的服務經驗，而這正是宏華最大的競爭力。

宏華國際新事業處協理曾世忠指出，宏華國際深耕客服領域超過十年，累積全台數一數二的服務量能與顧客互動經驗。從客服、門市到到府服務，這些第一線服務經驗，不僅讓團隊更理解真實客服情境，也更熟悉不同產業的服務流程與需求，成為 AI 客服代理人得以持續優化的關鍵。

這些第一線經驗讓宏華非常清楚顧客互動過程中的各種變數，包括臨時修改需求、跳躍式提問、說話帶有情緒等。曾世忠表示，真實世界的客服互動很少按照既定腳本進行，許多AI在面對顧客突然改變想法或偏離原本的對話流程時，容易陷入重複問答或無法理解語意的困境，進而影響使用體驗。  
也正因此，宏華訓練的不只是 AI 的智商（知識理解、順暢對話），更重視服務情商（情緖分析），讓 AI 能理解對話情境、顧客情緒與需求變化，可以「秒問秒答、邊聽邊想」，而非只是依照固定腳本機械式回應。

除了理解真實客服互動情境外，長期服務不同產業客戶的經驗，也讓宏華更了解各產業面臨的服務情境與需求差異，並將這些產業 Know-how 模組化，發展出餐飲、技術服務、專業服務等產品包，企業只要完成需求完成設定，便能快速導入，大幅降低建置時間與試錯成本。

「AI Agent 的價值不只是協助企業服務客戶，更將成為企業營運的重要基礎設施。」曾世忠認為，未來，AI Agent 除了協助企業回應外部客戶需求，也將進一步應用於員工服務、人資諮詢等內部場景，成為串聯企業內外部溝通的重要角色。而宏華國際也將持續投入相關技術發展，協助企業在 AI 時代建立更穩定、更具韌性的營運能力。
