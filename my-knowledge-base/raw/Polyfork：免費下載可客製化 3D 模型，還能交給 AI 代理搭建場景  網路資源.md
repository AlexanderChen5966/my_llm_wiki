網站連結 [https://polyfork.dev/](https://polyfork.dev/)

Polyfork 是一個提供可下載、可調整 3D 素材的線上資產庫，主打低多邊形模型、主題套件，以及能依參數重新組合的程式化模型。它與只有固定網格的模型素材站不同：部分資產本身帶有可讀取的設定參數，使用者能在網站預覽器或下載檔案中調整顏色、比例與零件，再把變化後的模型放入自己的場景。對正在製作遊戲、互動展示或 3D 網頁的人來說，這讓「找模型」也能延伸成「依需求修改模型」。

網站提供模型瀏覽、套件與角色等不同入口。單一資產可按主題、用途或技術需求探索；同一套件中的模型則採用共同的色盤、比例與格線規則，方便把建築、道具和環境素材放在同一場景中，減少風格不一致或尺度難以搭配的問題。部分角色以可調整的設定組成，能更換服裝、身形或指定區域的顏色；官方說明其骨架維持一致，因此既有動作也能延用在角色變化上。

Polyfork 的素材設計也考慮到不同開發工具。低多邊形模型可免費使用，並能以 GLB 等格式下載或從官方 CDN 載入；three.js 開發者還能使用 ES module 直接建立場景物件，官方示例不需要額外 loader 或非同步等待。其他常見流程則可依支援格式匯入 Godot、Blender、Unity、Unreal 等工具。網站也提供 MCP 伺服器與 REST API，讓 Claude Code、Cursor、Codex 等 AI 代理搜尋模型、查詢資產資訊、尋找相配資產或預覽場景，方便把模型挑選納入程式化的場景製作流程。

- **免費低多邊形素材：** 可先用免費模型和套件製作原型、遊戲場景或網頁展示。
- **可調整的模型：** 標示為可修改的資產包含顏色、尺寸比例或部件等參數，適合依場景需求微調。
- **相容多種格式與工具：** 依模型提供的檔案，整合 three.js、GLB/glTF、Unity、Godot、Blender 等製作流程。
- **主題套件與角色：** 共用色彩和比例的套件方便組成完整場景，角色選項則支援外觀調整。
- **MCP 與 API：** 讓 AI 編程代理能透過工具搜尋和挑選資產，減少手動查找素材的往返。

網站另有付費 HD 資產與訂閱方案，主要提供高模版本、PBR 材質、個人 CDN 等進階選項；實際方案與價格可能調整，使用前應以 [官方方案頁](https://polyfork.dev/pricing) 為準。素材授權方面，官方允許將下載模型用於個人或商業作品，包含遊戲、應用程式、網站與客戶專案，並不要求標註來源；但不得把原始或修改過的模型檔另行轉售、重新上傳或以素材包形式散布。若要在自己經營的平台上代使用者託管模型，則須依平台授權規範處理。詳細範圍請閱讀 [Polyfork 授權說明](https://polyfork.dev/licensing) 。

整體來說，Polyfork 適合需要快速取得可用 3D 素材，又希望保留一定修改彈性的遊戲開發者、three.js 創作者與 3D 網頁設計者；若正在嘗試讓 AI 代理參與場景生成，其 MCP 和 API 也提供了直接探索資產庫的管道。開始使用時，可以先從免費低多邊形模型挑選資產，再確認檔案格式、可調參數與授權條款是否符合專案需求。更多素材與整合資訊可前往Polyfork 官方網站查看。
