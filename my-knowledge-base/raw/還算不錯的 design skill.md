分享幾個知名且還算不錯的 design skill

​

溫馨小提醒：這些 design skill 都有自己的設計特色，而設計這種事本來就是半主觀的見仁見智，所以喜歡就撿去用，不喜歡就 let it go 就好 XXD

​

1. Impeccable (star 9400)

是在 Anthropic 推出的 frontend-dsign skill 的基礎上，建立的更深的專業知識和更多的控制，包含 7 個特定領域的參考檔案，20 個命令以及反模式設計 (官網做得很票釀)

[https://impeccable.style/](https://impeccable.style/)

​

2. UI Skill (star 986)

我很久以前有在粉絲團分享過這個 ui skill，他算是很早期就推出的，一開始只有 baseline 的 ui 規範，現在也擴展到有 15 個 skill 了，特別的是除了 web 之外還有 swif ui 的 skill；優勢是可以按需引用，不用強迫我們一次裝一整包檔案

3. Taste Skill (star 3300)

一個標榜「高品味」的 skill，可以讓 AI 生成有現代化且高品質的設計，GitHub 的 readme.md 文件有提供一個生成的範例，大家可以看看是否符合你心目中的高品味

[https://github.com/Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)

​

4. Better Icons (star 666)

如果覺得 AI 產生一堆 emoji 很煩，如果就是想要用美美的 svg icons 的話，可以考慮使用 Better Icons，他是一個 MCP Toos，會從包含以下網站 Lucide、Heroicons、Material Deisgn.. 等 150+ 個圖示集合中進行搜尋，共高達 200,000 多個圖示

5. Superdesign (start 6100)

這是一個很強大的開源工具，有 marketplace，可以很好的跟 IDE (VS Code, Cursor, Windsurf...) 進行整合，也支援 Skills，可安裝在 Claude Code

網站上就有很多設計作品集可參考，也可以直接使用對應的提示詞，整合的很棒

6. Design Plugin(star 650)

他的特色是可以給元件或頁面產生多個 UI 版本，讓我們在瀏覽器中選擇比較，我們可以直接給他回饋，例如我喜歡 A 的 ___ 部位 + B 的 ____ 部位，然後他就會融合精煉，直到我們滿意為止
