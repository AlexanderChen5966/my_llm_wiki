Jig 3D 組裝教學最實用的地方，是讓原本只看得到一個角度的步驟，可以換方向理解。看懂每個零件，不一定就能知道兩塊板子應該怎麼接。

但立體畫面也可能畫錯。孔洞朝向、螺絲數量與先後順序，只要其中一項不對，漂亮的教材就可能把人帶往錯誤的操作。

Jig 共同創辦人 Numa 在 [X 原始分享](https://x.com/numaausaumon/status/2112214425910595901?ref=aiposthub.com) 示範，把 IKEA 網站的說明書交給工具，再使用 `/assembly` 建立可觀看的組裝說明。這提供了一個很適合拆解的練習起點。

對老師、產品訓練人員與需要解釋零件關係的人來說，這種做法適合先處理一個小步驟，再逐頁核對。本文提供的是可自行修改的教學流程，沒有把原作者的產出速度當成每個人都能重現的保證。

要讓第一份教材有用，先把「哪一份說明書、哪一個產品、哪幾個步驟」說清楚，才有辦法判斷生成結果是否正確。

## Jig 3D 組裝教學先準備什麼？從產品型號與來源 PDF 開始

第一份練習應該選零件少、步驟短，而且找得到原廠說明書的物件。如此一來，生成畫面出現疑問時，可以直接回到來源找答案，不必憑生活經驗猜測。

Numa 的案例使用 IKEA 網站提供的 PDF，但家具名稱相同，不代表所有尺寸與版本都共用一本說明書。因此，下載前先對照實際產品編號、尺寸與文件封面，尤其留意左右方向不同的款式。

若要練習 IKEA 家具，可以從 [IKEA 官方組裝說明入口](https://www.ikea.com/us/en/customer-service/assembly-instructions/?ref=aiposthub.com) 依產品名稱或商品編號查找。本文不指定一個未核對型號的 PDF 讓所有讀者套用，因為找到相符的版本本來就是第一項操作。

把找到的原始檔保留在資料夾，再記下來源頁、下載日期與檔名。如果原廠後來修改警告文字，就能辨識教材用的是哪一版，也能避免團隊重新下載後混用新舊內容。

### 為什麼不能只給一張組裝完成照？

完成照能提供外觀，卻通常看不見內側孔位、背板固定方式與接合順序。因此，它適合用來比對最後形狀，不能代替分步驟說明的依據。

先選三到五個連續步驟作為範圍，並把相關頁面與前面的零件表一起提供。如果只裁出其中一個箭頭，工具可能知道板子會移動，卻不知道它是哪一塊、朝哪一面。

遇到文字不清楚的掃描檔，先確認人類能否辨認。看不清的尺寸和符號要回原廠重找清晰版本，因為把模糊輸入轉成清楚的立體畫面，可能只會讓錯誤看起來更有說服力。

來源確定後，再把零件整理成有名字的清單，後面的每個動作才會指向同一個物件。

## 用 /assembly 建立第一版：先讓工具說明它準備畫什麼

第一輪的目標是看懂零件關係，因此先要求工具整理計畫，比直接追求完整華麗的動畫容易修正。 [Ask by Jig 官方網站](https://ask.jig.com/?ref=aiposthub.com) 提供建立與瀏覽立體解說的入口，介面與可用額度請以登入時顯示為準。

原作者公開的最短做法是 `/assembly` 加上 PDF。實際使用時，可以先上傳相符的說明書，再補充要處理的頁數、觀看者程度與輸出內容，讓工具知道要優先解釋哪些關係。

以下是本站自行撰寫的範例，不是原作者完整提示詞，也不代表所有版本都有相同的匯出功能：

```
/assembly
附件是本次唯一的組裝依據。請先閱讀封面、零件表與第［頁碼］到第［頁碼］頁。
先列出這幾頁用到的零件編號、數量、接合方向與需要保留的警告。
本次只處理步驟［起點］到［終點］，觀眾是第一次組裝的人。
先給我逐步製作計畫，暫時不要補上說明書沒有的結構。
確認後再建立能旋轉觀看的立體說明，每步只強調當下要動的零件。
任何看不清楚的符號請指出原頁位置，不要猜測數字或孔位。
```

收到計畫後，先比較零件編號。假如原廠把兩塊外觀相近的板子分成不同代號，生成清單也必須保留差異，不能為了畫面簡潔合併成「側板」。

### 每一步要留下哪些資訊？

可用「目前零件、要做的動作、完成後的方向、對應 PDF 頁碼」記錄。這四項讓觀看者知道現在正在處理什麼，也讓修改時能回到明確的位置。

其中方向最好用物件本身的特徵描述，例如「有長槽的一面朝內」，比單寫左邊、右邊穩定。因為鏡頭轉動後，畫面左右會改變，零件上的槽卻仍然在同一面。

若工具把隱藏的孔位補得過於完整，先要求它標示哪些結構有來源、哪些只是示意。只有能從文件確認的部分適合當作操作說明，其餘應刪除或弱化呈現。

計畫與零件表對得上，再做第一個動作。先把一個接合關係畫正確，比一次生成整件家具更能判斷這套流程是否適用。

## 3D 畫面怎麼驗收？把孔位、順序與觀看角度分開看

驗收時先看結構是否符合來源，再看鏡頭是否容易理解。這兩個問題分開處理，才不會因為畫面流暢，就忽略零件其實接錯了位置。

以下清單可以用來逐步對照，右欄的通過條件要以你手上的 PDF 為依據。

| 檢查項目 | 回到來源確認什麼 | 可以留下的結果 |
| --- | --- | --- |
| 零件身份 | 代號、外形與數量 | 每一步能指出正在移動的零件 |
| 接合位置 | 槽、孔與接觸面 | 連接關係與原圖一致 |
| 執行順序 | 步驟編號與箭頭 | 未跳過會影響後續的動作 |
| 視角 | 被遮住的操作區域 | 關鍵接合能從另一面看清 |
| 原廠提醒 | 人數、工具與固定要求 | 重要提醒仍跟著相關步驟出現 |

這張表先處理「有沒有畫對」，再處理「看不看得懂」。例如螺絲先穿過哪一塊板子是結構問題，鏡頭被手臂擋住則是觀看問題，兩者需要不同的修改。

### 讓鏡頭服務一個正在發生的動作

同一步驟最好先有全貌，再靠近接合點，最後回到完成的位置。如果鏡頭全程快速旋轉，觀看者雖然看到很多角度，卻可能分不清到底是哪個零件在移動。

也可以要求工具在關鍵位置短暫停留，讓觀眾有時間對照實體。停留多久應由實際觀看決定，因為一個熟悉產品的製作者，往往比新手更快看懂畫面。

先把聲音關掉看一次，觀察只靠零件強調與順序是否能理解。再打開解說聽一次，確認口頭提到的方向真的出現在畫面中，避免旁白和動畫各自正確卻對不上時間。

若作為課堂教材，可請未看過原稿的人指出下一個動作。對方需要不斷回問的地方，就是值得補上一個角度或一段停留的位置，而不是再加裝飾效果的地方。

結構與觀看都過關後，才適合把小段範圍擴大。否則新增十個步驟，只會讓同一種誤讀重複出現。

## 畫錯一個步驟怎麼改？固定已正確內容，只重做有問題的地方

修正時把錯誤描述成一個可指出的位置，通常比「整體再精準一點」有效。因為工具需要知道哪個零件、哪個動作和哪一頁來源發生衝突，才能保留已經正確的部分。

例如第二步的層板翻面，不必把整份說明重做。先記下該步畫面與來源，再要求只改層板方向，保留其他零件與鏡頭，完成後重新比較修正前後。

```
只修改步驟［編號］。
目前畫面把零件［代號］的［特徵面］朝向［方向］。
附件第［頁碼］頁顯示它應朝向［方向］，請依該圖修正。
保留其他零件、已批准的順序、配色與鏡頭。
修改後提供此步的開始與結束畫面，並列出改動。
```

這是本站的局部修正範例。若系統無法保留原有內容，先另存前一版，避免一次修孔位時，把已核對的零件名稱也一起改掉。

### 常見失敗通常該退回哪一步？

零件忽然變多，先查來源範圍是不是混入另一款產品。方向持續錯誤，先改成以槽、孔和標記面描述，再檢查模型是否把照片當成鏡像。這些問題不一定靠增加提示詞長度解決。

如果接合的結果正確，過程卻直接穿過其他零件，問題出在路徑。可以把一個動作拆成「先抬起、再平移、最後接合」，讓工具處理中間過程，而不是只知道起點與終點。

如果模型無法從簡化線圖理解真實結構，就停止擴寫該步。這時保留原廠圖，再加清楚的箭頭與口頭解說，可能比一段錯誤的立體重建更適合教學。

## 教材完成後怎麼交付？讓原 PDF、版本與使用範圍一起留下

交付的核心是讓下一位使用者能找到來源和修改入口。只有一段成片，往往看不出哪裡有問題，也難以知道畫面引用的是哪一份產品文件。

整理一個資料夾，放入原 PDF、來源連結、這次處理的頁碼、已確認的零件表與最新作品入口。若平台提供分享或匯出，依實際可用功能選擇，並確認接收者開啟後能看到相同的版本。

需要放到課堂投影時，用教室可能使用的螢幕測試文字大小。手機能旋轉觀看，不代表投影到教室後，後排學生也看得清楚孔位，所以關鍵接合最好另外保留近景。

若要提供印刷版，把每步開始與完成的狀態分開，圖說寫出正在做的動作。這能讓無法播放互動內容的人，仍然保有一條可以跟上的閱讀路徑。

最後保留一張驗收紀錄，列明哪些頁碼已逐步對照、哪些細節只作示意。當產品文件更新，團隊就能從受影響的步驟開始修改，不必重新猜測整份教材。

這份流程適合先選一個有清楚來源的物件，做完一個短段落，再請第一次接觸的人照著理解。只要有一處需要猜測，就回到原圖補齊，而不是用更多動畫把疑問蓋過去。

## 練習一次板件接合：從原圖寫出能檢查的動作單

實際練習可以選兩塊板件的接合，把「看懂圖」變成可驗證的描述。以下是本站設計的練習情境，零件代號和孔位都要換成來源文件裡的內容，不代表任何特定家具的真實組裝步驟。

先在紙上寫下板件甲和板件乙，再各標一個能辨識的面。假設甲有一條長槽、乙有一排孔，文字就用這兩個特徵指向物件，避免只說大板子與小板子。

接著把原圖的箭頭解成一個順序，像是先立起甲、再讓乙靠近、最後完成接合。若箭頭只表示最後方向，沒有交代中間路徑，就把中間過程視為示意，別增加來源沒有顯示的精密尺寸。

第一輪要求工具只做這段，並讓其他零件保持淡色或固定位置。觀看者能把視線放在兩塊板件，就容易發現槽的方向是否翻轉，也能看出接合時有沒有直接穿透。

### 開始、接近與完成各留一個畫面

開始畫面要能辨認兩個零件，接近畫面要看得見接觸面，完成畫面則要和 PDF 的結果對得上。這三張圖一起看，才知道動畫是在解釋一個合理過程，還是從兩個散件突然跳成完成品。

如果接近時看不見槽，先改鏡頭，不要改零件。若完成後方向不對，先改物件姿態，不要為了看起來順而把來源圖也解釋成另一種方向。

同一個步驟可以準備正面與斜上方兩個觀看版本，請第一次接觸的人選哪個較容易理解。這不是選美，而是看他能否指出哪一面朝內、下一步要接哪個位置。

### 把觀看者的疑問變成下一次修正

對方若問「哪一塊才是甲」，就補身份標示。若問「為什麼板子突然到那裡」，就補中間動作。若問「這顆螺絲從哪裡來」，就回頭看是否漏了零件或準備步驟。

把這些回饋寫進動作單，並保留修改前後畫面。下一次做相似接合時，可以沿用已有效的標示與鏡頭，但仍要重新核對新的零件代號與原廠說明。

這份短練習完成後，檢查者應能說出兩個零件的身份、方向與接合結果。若只能說「看起來會組裝」，就還缺少足以用來教學的明確資訊。

## Jig 3D 組裝教學 FAQ

### 一定要用 IKEA 說明書嗎？

不必。選擇自己有權使用、產品版本明確、內容清楚的組裝文件即可。原廠 PDF 的優點是通常有零件代號與步驟，可以逐項核對。

### /assembly 能保證重建正確孔位嗎？

不能。它是啟動原作者流程的簡短指令，結果仍需要與來源比較。需要承重或涉及實際安全的操作，應以原廠文件與專業指示為準。

### 能把產出當作原廠正式說明嗎？

不能自行如此標示。這是依來源製作的教學輔助內容，正式交付時應保留來源與適用版本，避免讓使用者誤以為已經由原廠審核。
