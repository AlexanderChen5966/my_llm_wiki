把一堆素材丟給 AI，最容易遇到的困擾，是影片看起來完成了，卻不知道該怎麼改其中一個鏡頭。

Codex CapCut 的官方流程把重點放在可編輯粗剪，也就是先排好素材與段落，再讓創作者回到時間軸調整。

X 上的角色短片展示從提示詞、角色建立一路做到剪輯，但這些步驟包含不同的創作決定，不能只靠一句「幫我做完」交代。

CapCut 官方產品頁已說明，可從上傳片段與文字需求開始，實際入口仍可能因版本、帳號與地區不同。

如果你已經有自己的素材，適合先試一支短片的素材選擇與順序，因為你能比較 AI 的取捨是否符合原本目的。

因此，串接工具之前，先把要剪什麼與不能改什麼寫清楚。

## Codex CapCut 的可編輯粗剪是什麼？

粗剪先解決素材選擇、段落順序與大致長度，細節則留給可以調整的時間軸。時間軸就是編輯器裡用來排列影片、文字、音訊與特效的工作區。

你可以把第一版理解成一份排好的剪輯草稿。鏡頭不適合就換掉，字幕太快就延長，音樂太大聲就調低，而不必因為要修一句話就重做整支片。

[CapCut × Codex 官方頁](https://www.capcut.com/tools/capcut-x-codex?ref=aiposthub.com) 將流程描述為上傳素材、說明需求、分析片段，再準備可編輯粗剪。它也列出字幕、不同格式版本與後續微調等使用方向。

這和「一句話生成成片」的閱讀方式不同。第一版的價值在於提供可接手的起點，內容與創意仍需要有人確認。

### 先看當前官方入口，再照步驟連線

截至 2026 年 10 月 25 日，官方頁把體驗描述為桌面 PC 上的工作流，並說明它不是只開瀏覽器就能使用的線上編輯器。頁面同時使用 Codex 與 ChatGPT 桌面工作流的名稱，應依當前官方入口與支援環境操作。

開始時先打開官方頁，閱讀當前外掛取得與授權指示，確認你的應用程式版本和帳號可用。不要把同名第三方 MCP 或舊版安裝教學直接當成官方連線方法。

MCP 可以先理解為讓 AI 代理呼叫外部工具的一種連線方式；但這個頁面定位的是 CapCut × Codex 的官方流程，不代表網路上所有名稱帶 MCP 的專案都有相同功能。

## 素材與角色，哪些應該先準備？

已有真實產品或人物素材時，先指定它們的身份與用途。因為 AI 生成的新畫面可能很好看，卻不一定是產品實際具有的外觀或功能。

[Antonio Costa 的案例](https://x.com/xetgepete/status/2109687401052275180?ref=aiposthub.com) 展示從角色建立、AI 影片到 CapCut 剪輯的串接。貼文含行銷內容，文章採用的是它的分工線索，不沿用促銷折扣或效果保證。

若你要做的是咖啡店新品短片，可以先把素材整理成以下清單。

| 素材 | 用途 | 應該保留的內容 |
| --- | --- | --- |
| 飲品實拍 | 呈現實際商品 | 杯型、配料與顏色 |
| 製作過程 | 交代產品特色 | 真實操作，不補不存在的步驟 |
| 品牌標誌 | 片尾識別 | 正確比例與可讀性 |
| 售價與活動文字 | 提供購買資訊 | 已確認的數字與日期 |
| 音樂或音效 | 建立節奏 | 可使用的授權與來源 |

表格中的保留項目，是給第一版的邊界。如果沒有實拍影片，先說明要使用示意或生成畫面，也不要讓代理把示意誤寫成實際商品證據。

### 檔名能讓提示詞少猜一步

把素材命名成「飲品正面」「倒奶過程」「品牌標誌」等可辨認的名稱，再用這些名稱交代用途。若所有檔案都叫未命名，提示詞就需要花更多力氣描述自己指的是哪一個。

素材太多時，先列出可用與不可用的片段。因為模糊、遮擋或包含未授權人物的片段若進入粗剪，後續就可能必須大幅拆掉，所以可以先從候選清單排除。

例如「倒奶過程」拍了兩次，可以在清單註明第二次對焦清楚，優先使用。這個判斷應有畫面依據，因為只說「選最好的一段」，工具可能按照與你不同的標準挑片。

## 把短片需求寫成一份可交接的提示詞

先提供觀眾、目的與段落，再談風格。因為「有質感」無法告訴編輯器，哪個產品特點應先出現、哪段素材不能刪掉。

以下為 AI 郵報整理的短片需求範本，請依你實際上傳的素材調整。它不是原作者逐字指令，也不代表每個帳號已支援範本中的所有動作。

```
用我提供的素材，準備一支可繼續修改的新品短片粗剪。

觀眾：第一次認識這家咖啡店的人。
目的：看懂新飲品的外觀與一個主要特色。
目標：直式短片，約 20 秒；先提出鏡頭順序再建立草稿。

段落：
開場用「飲品正面」，讓觀眾先看清商品。
中段用「倒奶過程」，搭配已提供的產品特色文字。
片尾保留品牌標誌與已確認的購買資訊。

保留條件：
只使用提供或已授權的素材。
不要發明產品功能、折扣、人物評價與活動日期。
字幕使用繁體中文，避免蓋住飲品與重要操作。
音樂不能蓋住需要聽清楚的現場聲音。

交付：
可編輯的草稿、素材使用清單，以及需要人工判斷的項目。
先不要發布，也不要自行購買素材。
```

範本把商品事實與創作風格分開。若第一版節奏不對，可以保留素材與文字，只改鏡頭長度，不必讓工具重新發明整段故事。

### 用時間碼修稿，比「再活潑一點」具體

時間碼是片中某個位置的時間標記。例如「第 6 秒的字幕延長一秒」就能指出修改範圍，而「整支再清楚一點」通常會牽動更多項目。

粗剪出來後，可以要求「保留開場與片尾，只替換中段模糊的倒奶鏡頭」。如果問題是字幕擋住商品，則只調字幕位置，不同時改音樂、轉場與字型。

## 回到 CapCut，先修字幕還是轉場？

先修內容錯誤與音畫問題，再處理視覺裝飾。售價錯了、產品被遮住或聲音對不上時，即使轉場很順，也無法達成短片目的。

[官方 Codex MCP 功能頁](https://www.capcut.com/features/codex-mcp?ref=aiposthub.com) 同樣把生成草稿定位成可接手修改的起點。你仍要在編輯器檢查片段、文字、聲音與輸出選擇。

| 檢查順序 | 具體要看什麼 |
| --- | --- |
| 內容 | 商品、數字、人物與畫面是否符合事實 |
| 鏡頭 | 關鍵步驟是否被剪掉，素材是否重複 |
| 字幕 | 繁中用字、顯示時間、手機可讀性 |
| 音訊 | 人聲、現場聲與音樂的關係 |
| 節奏 | 每段是否有足夠時間理解 |
| 輸出 | 比例、解析度、片尾與實際檔案 |

這個順序讓修稿先處理會改變理解的問題。確認內容沒有錯，再決定要不要加特效，能避免花時間美化最後還是得刪掉的畫面。

輸出後要用實際檔案播放一次，特別看開頭、接縫與片尾。因為編輯器預覽和輸出檔案是不同檢查階段，所以仍要確認字幕、音訊與素材在最後檔案中正確呈現。

若要做多個比例版本，分別檢查商品和文字的位置。直式畫面不能只靠裁掉橫式左右兩邊，否則原本並排的資訊可能消失。

也可以保留一份簡短修改表，例如「第一版字幕擋住杯身，第二版只移字幕」。因為其他條件沒有一起更動，你才能判斷修稿是否解決原本問題，而不只是得到另一支看起來不同的片。

## Codex CapCut 常見問題

### 沒有素材，也能開始嗎？

官方頁也描述從概念與素材資產展開的方向，但沒有素材時，仍需要決定角色、美術與故事。新手若想學剪輯，先用自己拍的幾段影片，比同時處理所有生成環節容易比較。

### 這是免費的一鍵成片工具嗎？

官方頁有體驗入口，但不能據此推論所有模型、素材與次數都無限制免費。使用前查看目前方案、授權與生成動作的費用，第一版仍需要精修。

### 可以在任何瀏覽器直接操作嗎？

官方說明指向桌面 PC 工作流，實際可用性也可能因應用程式版本、帳號與地區不同。先確認官方當前要求，再開始準備連線。

### 拿到第一版，就可以交付嗎？

先核對商品與文字，再檢查字幕、鏡頭順序和聲音。最後播放實際輸出檔，確認比例與片尾符合需求，才能知道可編輯粗剪是否已完成精修。

## 先用自己的素材完成一支可修改短片

已有腳本與素材的人，較容易判斷 Codex 與 CapCut 省下了哪一步。先把段落順序與保留條件講清楚，再用同一份素材比較第一版和精修版。

如果你還不確定影片要讓觀眾記住什麼，先寫一句目的，再選素材。可編輯粗剪的價值，是讓後續判斷與修改有地方落實，而不是省略判斷。
