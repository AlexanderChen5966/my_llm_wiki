Claude 品牌動畫每次都重新交代顏色、Logo 和語氣，代理就容易漏掉某一項。把這些資料放在專案裡，能讓下一次製作從同一個起點開始。

Hamza Khalid 公開的做法，是準備品牌資料夾、加入 CLAUDE.md，再用時間碼修改成片。CLAUDE.md 是給 Claude Code 讀取的專案說明檔，可以記下製作規則與檢查要求。

這套方法適合要反覆做產品短片的人。先把一次次重講的要求寫下來，再看下一支片是否真的少了同類錯誤。

## 資料夾先留下哪些資訊？

先整理會跨影片重用的東西，再把本次片子的需求獨立寫開。這樣改一支影片的賣點時，不會順便改掉整個品牌的規則。

| 檔案類型 | 建議內容 |
| --- | --- |
| 品牌資料 | Logo、色碼、字體與可用介面 |
| 本次需求 | 觀眾、單一重點、片長與比例 |
| 製作規則 | 不可改的名稱、檢查方式與交付格式 |
| 修稿紀錄 | 哪一秒、哪個元素、要改成什麼 |

如果參考片有喜歡的鏡頭，另寫下喜歡的原因，例如標題停得夠久、產品操作能看懂。只丟連結不說原因，代理可能模仿到你不需要的部分。

## 可複製的 CLAUDE.md 內容方向

在 Claude Code 開啟品牌資料夾後，把規則存為根目錄的 CLAUDE.md，本次內容另存 brief.md。範本中的 brand/ 也要對上實際素材資料夾，下一次從同一專案開始。

以下是本站依公開方法撰寫的範本，非 Hamza 的原始檔，尚未做成片實測。

```
本專案製作［品牌名稱］的產品短片。
每次開工先讀 brand/ 與本次 brief.md。
品牌名稱、Logo 比例、色碼與功能文案以資料夾為準。
參考片只取節奏與構圖原則，不複製他人的素材與台詞。
先提出場景表，並標出每段文字完整出現的時間。
完成初版後輸出關鍵影格，檢查裁字、遮擋與空白場景。
修稿時用時間碼、元素名稱與預期變化記錄問題。
只修改被指出的場景，保留可比較的前一版。
交付 MP4、專案原始檔與本次變更紀錄。
```

## 用時間碼，讓修改意見可以核對

「第三段太慢」仍有解釋空間，可以改成「第 8 秒產品畫面完整出現後，把停留縮短半秒」。它同時說明位置、目前狀態與目標變化。

修改後重看前後銜接，因為縮短半秒可能讓配樂與字幕也需要重新對齊。驗收範圍應包含被影響的相鄰鏡頭。

### CLAUDE.md 放越多規則越好嗎？

先留下確定會重複使用的要求。單次的創作想法放在本次需求中，避免下一支影片被上一支的內容限制。

### 這篇提供 Hamza 的完整課程 prompt 嗎？

沒有。本文提供公開流程的整理與本站需求範本，完整課程內容請從作者原貼查看取得方式。

先把最近一次被改過的三個問題記進專案，再拿它製作下一支短片，就能觀察這份品牌記憶是否有用。
