Canva Craft 把一張圖怎麼安排，放到了畫出像素之前。對常做海報和社群圖的人，這個改變值得注意，因為成品除了好看，還得把文字和主角放在合適的位置。

Canva 在台灣時間十月二十三日的官方公告中推出這個自研模型。它先根據提示寫構圖計畫，再交由圖像模型渲染，最高輸出 2K，並能搭配三十多種比例。

這次聲量也來自 DesignArena 排名，但模型第四名和研究團隊第二名是不同口徑。名次能提供比較線索，還不能回答繁體海報的每個字是否正確。

修改方式同樣影響能不能交件。Craft 的圖片可再透過 Magic Layers 轉成可編輯元素，這與直接取得每層都完整的向量原稿，仍是不同工作。

我認為，已有固定圖文需求的創作者，適合先用一張真實素材測構圖、改字和修改範圍。需要精確品牌稿的人，則應把檢查後的成品當作選用依據。

要知道這個模型能省下哪一步，先看它如何把一段提示分成構圖與渲染。

## Canva Craft 怎麼畫圖？先把文字與構圖關係排好

兩階段架構把「畫面應該怎麼安排」和「把它畫出來」分成兩個工作。這對設計任務的意義，是文字、物件和留白之間的關係，可以先成為規劃內容，而非只在最後看整張圖是否接近要求。

依 [Canva 官方發布文](https://www.canva.com/newsroom/news/canva-craft/?ref=aiposthub.com) ，第一階段會把提示轉成構圖計畫，包含元素、相對位置、大小、視覺層級及需要出現的文字。第二階段再依計畫渲染圖片。

視覺層級指的是讀者先看到什麼，再看到什麼。例如一張講座海報，活動名稱通常要比報名須知更醒目。若小字和主標一樣突出，即使沒有錯字，也可能讓讀者抓不到重點。

### 把需求寫成彼此有關係的畫面

因此提示可以先交代用途，再描述元素關係。以下是編輯建議的測試題，不是本站已實測成功的結果：直式講座海報，上方保留主標，中間放講者，下方放時間和報名資訊，避免文字蓋住臉。

這份需求比「做一張很專業的海報」更容易檢查，因為主標位置、人物遮擋和資訊區域都有明確條件。模型若漏掉其中一項，創作者能指出問題，而不只反覆要求更好看。

Canva 也表示，訓練較重視設計資料，並加入專業設計師回饋。這能解釋公司為何把構圖和文字當成重點，但資料來源和訓練方法，是設計方向的依據，還不是每一份成品的驗收結果。

官方列舉的訓練內容包括人工製作的海報、簡報、菜單與資訊圖表。這些格式會把標題、說明和影像放進共同版面，因此有助於理解公司為何強調元素關係，而不只單一主體的細節。

同一個版面也可能有多個合理答案。活動海報和商品廣告的重點不同，模型照同一句「主角置中」生成，未必符合兩者的閱讀習慣，所以用途應在提示中先說清楚。

兩階段規劃讓畫面關係有了明確處理位置，但這些改善仍需要用實際輸出評估。

## DesignArena 模型第四、研究團隊第二，分別代表什麼？

官方引用兩種排名，評估的是不同對象，不能放在同一個名次上解讀。Craft 是模型名稱，Canva Research 則是開發它的研究團隊。第四與第二描述的不是同一份名單。

[Canva 官方原貼](https://x.com/canva/status/2113348707223753165?ref=aiposthub.com) 以研究團隊第二為宣傳重點，後續貼文則列出模型第四和 Elo 分數。Elo 是依對戰比較更新的相對評分，名次會隨參與模型和投票結果改變。

對創作者來說，榜單比較適合回答「哪些工具值得先試」，而非直接回答「這次客戶的字體、商品和文案能不能過稿」。兩個問題需要不同的輸入和檢查方式。

### 類別排名和內部評測也要各自看

官方另列人像、自然、抽象圖案和產品等子類別。分類有助於挑選適合自己的測試題，例如做人物主視覺的人，與只做商品白底圖的人，關心的細節就不一樣。

但類別中的好成績，不能直接替代品牌規範。一張人像很自然，仍可能不適合公司的風格。一張商品圖很吸引人，也仍需要檢查瓶身比例、標誌和包裝文字是否符合真實產品。

Canva 表示，內部評測比較了超過二萬五千對圖片，由專業設計師和研究者參與。這個數字統計圖片對比的組數，和參與人數、獨立客戶驗收的次數分屬不同口徑。

Canva 還描述了設計師與研究者共同參與的內部圖片對比。這類評測有助於公司改善指令遵循和排版品質，但它與外部使用者自行重跑的結果不同，本文保留官方自述的身分。

[Canva Research 的介紹](https://www.canva.com/newsroom/news/introducing-canva-research/?ref=aiposthub.com) 也指出，設計即使符合形式條件，仍可能忽略文化背景或品牌辨識。這正是為什麼「漂亮」和「適合交件」需要分開問。

排名能縮小想測的候選，能否滿足自己的文字與構圖，還要把題目帶回工作。

## 2K、三十多種比例與五十五種文字，如何用在海報？

輸出大小、畫面比例與文字能力各自影響交付，不能用其中一項代替其他條件。最高 2K 描述解析度，比例決定構圖形狀，語言支援則關係到圖內能生成哪些文字。

官方說明可選三十多種比例，也能自行輸入比例。這讓同一個構想能往直式限時動態、橫式橫幅或方形貼文發展，但改比例會改變畫面安排，並不是把原圖裁切一下就一定保留重點。

例如直式海報裡，人物和主標可以上下排列。換成很寬的橫幅，可能就需要左右分配。如果只保留相同比例的人物，文字可能被擠成難讀的小字，所以每種用途應有自己的版面條件。

### 支援語言仍要落到實際文案

官方表示可用各種語言寫提示，圖內文字則支援五十五種語言。提示能被理解，與生成的每一個中文字都正確，是不同層次，不能從語言數量推算繁體中文的錯字率。

對台灣活動素材，值得逐項核對的是人名、日期、價格、專有名稱和標點。這些文字往往不長，卻直接影響報名與信任。若只在縮圖上看整體效果，錯一個字可能直到公開後才被發現。

解析度也要連到觀看距離。手機貼文上的主標清楚，不代表放大印成海報後，小字仍足夠銳利。確定要印製時，還得按實際尺寸、輸出檔與印刷流程檢查。

圖片模型能生成視覺上的向量風格，也不代表檔案本身就是向量。向量是能依路徑縮放和修改的物件表示，和看起來邊緣俐落的點陣圖片，交付方式並不相同。

當一張圖的內容接近需求，接下來的成本往往來自修改。

## Magic Layers 怎麼接續？生成圖片與可編輯元素分兩步

Craft 與 Magic Layers 的連接，讓創作者可以從圖片繼續調整設計元素。Magic Layers 是把平面圖片拆解成可編輯內容的工具，因此它接在生成之後，不能省略成所有輸出一開始就帶有完整原稿圖層。

Canva 表示，Craft 的結構安排有助於這項轉換。對使用者，應看的成品是轉換後的文字、主體和背景能否按需要分開，以及修改一項時會不會破壞其他部分。

### 用一個真實修改要求看出差別

例如活動日期從週六改成週日，需求可能只是替換一個字。若文字已能獨立編輯，就不必為這個小變化重新生成整張圖。但仍要看換字後是否維持原本字體、間距和對齊。

若修改的是人物位置，問題則變成移走主體後，原本被擋住的背景是否完整。這和改字不同，不能只因一項修改成功，就認為整份設計的所有元素都能同樣處理。

比較時可以保留生成圖、拆層後版本和最後交件檔，逐一看文字內容、位置和背景。這樣才能知道清稿時間花在生成、分解還是人工調整，而不是只記第一張圖幾秒出現。

還可以先決定哪些元素允許模型重畫。若是新商品的包裝照，輪廓、容量標示與商標通常不宜自由改動。若只是背景場景，創作空間就大得多。把這個差異寫進需求，有助於分配生成和編輯的工作。

對固定版型的品牌素材，也可以把品牌字體和標誌保留在既有設計物件中，讓生成圖提供背景或情境。這是編輯建議的分工方式，適合重視名稱與視覺一致性的工作。

## Dream Lab、公開 API 與 MCP，哪些今天能用？

Dream Lab 和公開 API 已有可用公告。API 是供程式呼叫功能的介面，MCP 與更快版本則仍屬後續安排。截至十月二十三日，官方發布文把 Craft 開放給全球 Canva 使用者，並指引從 Dream Lab 進入。

這裡的開放描述可用對象，不等於每種方案都無限生成。若要估固定工作量，仍應查看自己帳號的模型選項、額度與當前條件，不能從「所有使用者」推成不需付出任何成本。

對開發團隊，公開 API 的價值是把生成接到既有產品，例如讓電商素材工具依輸入產生圖片，再送回設計師檢查，而不是每次都手動開網頁貼提示。

### 現可用和後續路線要分開排工作

MCP 是讓 AI 助理以共同方式連接外部工具的介面規範。Craft 官方頁特別把 Canva MCP 標為 Coming Soon，因此不能據此要求所有助理現在就能直接呼叫新模型。

若透過供程式呼叫的 API 介面建立工作流，生成完成也只是一個中間結果。若圖片接著要放進廣告或商店頁，還需要保存原提示、模型版本和選用檔案，讓設計師能對回同一份素材，避免後續修改時找錯版本。

Craft-fast 和 Craft-ultrafast 也還是預告。官方談到蒸餾與自訂推論引擎的改進，但沒有因此公布這兩個未來版本的完整可用時間、專屬費率或對外速度保證。

對需要多人重複使用的流程，版本差異會影響結果。若之後改用速度更快的變體，原本海報的文字、細節和修改表現都應重新抽查，不能只因名稱都有 Craft 就當成同一份測試。

入口選定後，用一張需要反覆修改的素材，最容易看出它對工作有沒有幫助。

## 用一張台灣活動海報做比較：把文字、構圖與修改各自驗收

初次比較可以固定一份海報需求，分別看生成結果與修改後的可用成品。這是建議的驗收方法，不是本站執行過的模型測試，也沒有預設哪個工具會勝出。

先寫下不得遺漏的文字和畫面條件，例如活動名稱、日期、主講人、報名資訊，以及人物不能被字蓋住。讓每個候選工具處理同一份需求，比拿各自最好看的一張圖片相比，更接近工作選擇。

若同一活動有三個尺寸，也應沿用同一份文字清單逐張核對。這能分清是比例改變造成資訊遺漏，還是原本生成就少了內容，後續才知道該改提示、構圖或編輯步驟。

生成後先看資訊是否完整，再看視覺。若主標漂亮但時間漏掉，還不能當作可發布的活動圖。反過來，資訊都在但層級不清，也需要調整讀者先看見的順序。

接著只改一個必要條件，例如日期或背景顏色，記錄哪些元素受到影響。這一步能看出局部修改是否有效，還是每次都得重新挑選整張圖。

最後把結果放到真正會出現的位置，例如手機貼文預覽或投影片。中文字在編輯器放大時可讀，不代表縮小後仍看得清楚，交付尺寸應和觀看情境一起檢查。

我會以完成這些修改所需的總時間，決定是否導入固定出圖。若模型擅長情境圖，但關鍵字仍得人工製作，就讓它負責背景，把品牌與必須精確的資訊保留為設計物件。

## Canva Craft 常見問題

### Canva Craft 的排名是第二還是第四？

官方引用的模型排名是第四，研究團隊排名是第二，對象不同。這些都是發布時的榜單口徑，不是永久名次。

### Canva Craft 圖片一定能直接編輯每個字嗎？

官方描述可透過 Magic Layers 轉成可編輯元素。是否符合自己的字體、圖層與交付需求，仍要看實際轉換結果。

### 現在能透過所有 Canva MCP 工具使用 Craft 嗎？

發布文把 Craft 的 Canva MCP 整合標示為 Coming Soon。Dream Lab 和公開 API 已有可用公告。

## 讓成品修改成本決定是否採用

Canva Craft 的新意，是把設計規劃、圖像生成和後續修改接得更近。對有固定素材需求的人，最有用的比較是同一張圖從提示走到可交件，究竟少了哪些重做。

先保留精確文案和品牌規範，再測生成與修改，會比只依榜單換工具更有依據。想追蹤創作工具、圖像模型與實際工作流程，可以免費訂閱 AI 郵報。
