## 【分享】台灣團隊開發 免費 AI Prompt 管理網站，終於不用再到處找提示詞了

- 分享至

最近 AI 幾乎已經變成每天工作都會用到的工具。  
像是 ChatGPT、Claude、Gemini，甚至 AI 繪圖工具，每天都會累積很多好用的 Prompt（提示詞）。  
但不知道大家有沒有跟我一樣的困擾...  
好用的 Prompt 都存在聊天紀錄裡  
Notion、Word、TXT、Google Keep 到處都是  
明明之前寫過一個很好用的 Prompt，結果就是找不到  
最後只能重新寫一次  
最近剛好看到一個由 台灣團隊 開發的新工具 PromptTok(prompttok.net)，覺得蠻實用的，分享給有在使用 AI 的朋友。

PromptTok 是做什麼的？  
它不是聊天 AI。  
而是專門用來整理、收藏 AI Prompt（提示詞）的工具。  
可以把自己平常累積的 Prompt 分門別類整理起來，需要時快速找到，不用一直翻聊天紀錄。  
對於每天都在使用 ChatGPT 或 AI 工具的人，我覺得蠻方便的。  
![https://ithelp.ithome.com.tw/upload/images/20260806/20058095rjaZTbfNfY.jpg](https://ithelp.ithome.com.tw/upload/images/20260806/20058095rjaZTbfNfY.jpg)  
主要功能  
📁 三層資料夾分類 Prompt  
最有感的是可以用資料夾整理 Prompt。  
例如：  
遊戲開發  
├─ 殭屍  
│ ├─ 一般殭屍  
│ ├─ 胖殭屍  
│ └─ Boss  
│  
├─ NPC  
└─ 場景  
或是  
ChatGPT  
├─ 翻譯  
├─ SEO  
├─ 文案  
├─ 程式  
└─ Email  
分類好之後，要找 Prompt 就快很多。  
🚀 一鍵送到 AI  
整理好的 Prompt 可以直接送到 AI 使用。  
不用一直複製貼上或重新搜尋，常用 Prompt 可以快速重複利用。  
💾 JSON 備份  
辛苦整理的 Prompt 也可以匯出成 JSON。  
之後就算換電腦或想備份，都不用擔心資料不見。  
⚡ 適合 Prompt 很多的人  
如果只是偶爾用 ChatGPT，可能感覺還好。  
但只要每天都在用 AI，很快就會累積幾百個 Prompt。  
這時候有一個專門整理 Prompt 的地方，找起來真的方便很多。  
使用情境  
目前想到幾種很適合的用途：  
ChatGPT 提示詞整理  
Claude Prompt 收藏  
Gemini Prompt 管理  
AI 繪圖 Prompt 分類  
Stable Diffusion Prompt  
Midjourney Prompt  
FLUX Prompt  
Cursor、Copilot 程式開發 Prompt  
SEO 常用 Prompt  
文案 Prompt  
翻譯 Prompt  
基本上只要是 AI 提示詞，都可以整理在一起。  
操作方式  
1.首頁  
介紹 PromptTok 的主要功能，包括三層資料夾管理、一鍵送到 AI、JSON 備份，以及快速整理 AI Prompt。  
  
2\. 建立 Prompt 分類  
先建立自己的資料夾，例如：  
廢土生存  
├─ 一般殭屍  
│ ├─ zombie │  
├─ attack │  
├─ walk │  
└─ alert  
│  
├─ 胖殭屍 │  
└─ fat zombie │  
└─ 共用 Prompt  
![https://ithelp.ithome.com.tw/upload/images/20260806/20058095FDbj7i9Pim.jpg](https://ithelp.ithome.com.tw/upload/images/20260806/20058095FDbj7i9Pim.jpg)  
之後每個 Prompt 都可以依照主題分類收藏，不管累積多少都不容易混亂。

3. 快速使用 Prompt  
	需要時直接選擇 Prompt，一鍵送到 AI，不用重新找、不用重新整理，也不用一直翻聊天紀錄。
4. JSON 備份  
	所有 Prompt 都可以匯出備份，方便保存與移轉，資料掌握在自己手上。  
	心得  
	自己用了幾天，最大的感受不是 AI 變得更厲害，而是以前整理過的 Prompt 終於找得到。  
	尤其現在 AI 工具越來越多，Prompt 也越存越多，有個專門整理 Prompt 的地方，比全部塞在聊天紀錄或筆記裡方便不少，promptfolder國外提供也有也不錯可惜存取操作速度太慢 。  
	如果平常就有使用 ChatGPT、Claude、Gemini，或是常玩 AI 繪圖，我覺得可以試試看。  
	也想看看大家平常都是怎麼管理自己的 Prompt？有沒有更好的方法也歡迎分享交流。
