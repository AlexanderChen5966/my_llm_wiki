近期 Anthropic 在 Claude 推出了讓人興奮的全新工具： **Claude Design** 。Claude Design 的核心概念是把傳統的「設計工具操作流程」轉化成「對話流程」，並且可與 Github、Claude Code 整合，也能使用你既有的 Skills 來持續迭代工作流程。

當然，可能不是所有人都有 Coding 的需求，不過 Claude Design 有一個主打的功能模組，是生成「Slide Deck」簡報檔案。

究竟 Claude Design 好用在哪裡？Claude Design 與一般免費版用戶也能用的 Claude Chat、付費版限定的 Claude Cowork 與 Claude for PowerPoint 差在哪？

以下，我們就以使用 Claude Design 做簡報，來快速讓你理解這是一款什麼樣的工具：

以近期我主講的「 [**AI 簡報極速工作流**](https://portaly.cc/managertoday/product/3uIHatNl8kWOHw1wkFEl?utm_source=web_mt&utm_medium=article&utm_campaign=ai_presentation&utm_content=article_72033) 」為例，使用 Claude Design 做一份產品說明簡報，大概會經過 9 個流程。讓我們把 Claude Design 從頭到尾玩一遍吧～

## 什麼是 Claude Design？多了「設計畫布」好在哪？

Claude Design 是一個「對話式設計工作台」：你說話，它在右邊的畫布上即時生成、即時修改、即時更新，可以下載成 PPT 檔案來編輯每一個區塊。

它的介面分為兩個區塊：

- **左側｜Chat 對話欄** ：你在這裡輸入需求、上傳文件、下達修改指令
- **右側｜設計畫布** ：Claude 在這裡即時生成並顯示你的成品，你可以直接在上面點擊操作

整個工作流程，就是在這兩個區塊之間不斷來回：說話 → 看結果 → 說話 → 看結果。 **你不需要學任何設計軟體的操作邏輯，你只需要能說清楚「你要什麼」。**

在此之前，先提醒一下使用門檻：Claude Design 目前以「Research Preview（研究預覽版）」形式開放， **需要訂閱 Claude Pro、Max、Team 或 Enterprise 付費方案** 的使用者才能使用；免費用戶目前尚未開放。

### 步驟三：上傳素材文件，讓 Claude 有參考資料可用

這是整個流程中最關鍵的環節之一。 **Claude Design 生成的簡報品質，取決於你給它多少有用的素材。**

### 步驟四：輸入簡報製作 Prompt，下達生成指令

接下來是讓 Claude Design 開始「動起來」的關鍵步驟。在左側聊天欄位的輸入框中，輸入你的需求描述。 **Prompt 寫得越具體，生成的結果就越貼近你的期待。**

根據 Anthropic 官方建議，一個好的 Prompt 應該包含以下四個核心要素：

| 要素 | 說明 | 我的實際範例 |
| --- | --- | --- |
| **目標（Goal）** | 你要做什麼類型的設計 | 「製作一份共 8 張投影片的新產品提案簡報」 |
| **版面配置（Layout）** | 希望如何呈現、多少頁 | 「封面深色系，內頁深淺交錯排列」 |
| **內容（Content）** | 要涵蓋哪些資訊與主題 | 「包含封面、受眾痛點、課程架構、差異化、定價與 CTA」 |
| **受眾（Audience）** | 這份設計給誰看、什麼情境 | 「提案對象是業務與行銷主管，用於跨部門新產品佈達會議」 |

以我的實際操作為例，我輸入的 Prompt 是：

「我剛上傳了一份名為『AI 簡報極速工作流』的 80 頁課程企劃 Word 文件。請你完整閱讀並深度理解後，扮演資深產品企劃，為我提煉出最核心的精華，並建立一份共 8 張投影片的『新產品提案簡報』」。」

確認 Prompt 內容後，按下右下角橘紅色的「Send」按鈕，Claude 就會開始讀取文件並著手生成。左側聊天欄位會出現 Claude 的工作狀態列，顯示它正在進行：「Running script, Listing files, Reading, Invoking skill」等動作。

這代表 Claude 正在依序執行：讀取你上傳的文件、分析內容結構、規劃投影片架構，然後開始一頁一頁生成。

### 步驟六：用 Chat 繼續迭代修改，讓簡報更接近完美

生成的第一版只是起點，不是終點。Claude Design 真正的威力，在於「 **對話式迭代** 」。你繼續在左側聊天欄位說話，它就繼續在右側畫布修改。

### 新增投影片頁面：用 Tweaks 面板下追加指令

除了修改既有內容，你也可以直接在 Tweaks 的對話框裡要求 Claude 新增頁面。

點擊右上角的「Tweaks」切換鈕，開啟 Tweaks 控制面板後，面板上方有一個文字輸入框，標示「Ask Claude to add sliders or options」。這個輸入框不只是用來調整 Tweaks 選項的，也可以用來對 Claude 下達特定指令。

我輸入的指令是：「新增一頁讀者用 AI 簡報的痛點，以及課程怎麼解決這些痛點」。

### 步驟七：3 種精細編輯工具，把細節調整到位

生成和迭代之外，Claude Design 還提供三種不同的手動編輯工具，讓你能夠針對特定元素進行精準調整。

這三種工具的按鈕，都在右上角的工具列上。

### 工具一：Edit 模式——直接在畫布上打字修改

點擊右上角的「 **Edit** 」按鈕（橘色高亮狀態代表已啟用），畫布就會進入手動編輯模式。

在 Edit 模式下，你可以直接在投影片上點擊任何一個文字區塊， **像在 Word 裡打字一樣，直接修改內容** 。不需要透過 Chat，也不需要重新生成整頁：點哪裡改哪裡，所見即所得。

舉例來說，封面投影片的大標題區域被點選後，出現藍色邊框，文字游標顯示為可輸入狀態，標題第二行顯示「（這裡能直接打字）」。這是我在示範直接在畫布上打字修改的效果：

![Claude Design ai 做簡報_能直接編輯字.jpg](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-04/fn76-1776656314.jpg?w=1200&output=webp)

經理人

除了可以直接打字，進入 Edit 模式後並以點選大標題為例，右側還會出現「 **排版細節面板** 」，顯示目前選取元素的所有樣式屬性，包含：

- **Typography（文字排版）** ：Font（字型）、Size（字號）、Weight（字重）、Color（顏色）、Align（對齊）、Line（行距）、Tracking（字間距）
- **SIZE（尺寸）** ：Width（寬）、Height（高）
- **BOX（容器）** ：Opacity（透明度）、Padding（內距）、Margin（外距）、Border（邊框）、Radius（圓角）

右側自動展開的排版細節面板，讓你可以精確微調每一個樣式數值，不需要靠 AI 生成，完全是手動控制，適合需要符合特定品牌規範的商業簡報場合。

### 工具二：Draw 模式——用手繪標注告訴 Claude 要改哪裡

點擊右上角的「 **Draw** 」按鈕啟用後，按鈕會呈現橘色高亮狀態，代表目前處於手繪標注模式。

Draw 模式的核心概念很簡單： **與其在 Chat 裡用文字費力描述「第三頁左下角那個按鈕」，不如直接在畫布上把它圈起來** ，搭配底部文字框輸入說明後送出，Claude 就能精確知道你指的是哪個元素。

畫面底部同時會出現兩個模式可以切換：

- **Draw（⌘1）** ：手繪模式，用滑鼠在畫布上自由繪製圈選範圍
- **Click（⌘2）** ：點擊模式，直接點選畫布上的特定元素

右側還有一個「Queue」區域，可以把多個標注批次排入佇列、一次送出，不需要一個一個等待回應。

![Claude Design ai 做簡報_修改_大標.jpg](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-04/c8w5-1776656313.jpg?w=1200&output=webp)

經理人

舉例來說，看到某一頁有一個多餘的按鈕或文字區塊想移除，但用文字描述位置很難說清楚，直接用手繪把它圈起來，在底部輸入「刪除這個按鈕」，比說「第 9 頁右側中間那個橘色按鈕」清楚得多。

不過，雖然 Draw 模式在概念上直覺，但在實際操作中有一個已知問題： **手繪的圈選範圍不夠穩定，有時候圈完之後範圍會移位或消失，導致 Claude 無法正確辨識你指的是哪個元素** 。

如果你遇到以下情況，建議直接切換到 **Click 模式（⌘2）** ：

- 圈選後送出，Claude 修改了不相關的地方
- 手繪範圍 一 放開滑鼠就跑掉
- 想精確點選某個特定元素（按鈕、標題、圖表）

### 工具三：復原功能——後悔了？一鍵退回上一步

當 Claude 的修改結果不如預期，或是你不小心刪掉了不該刪的東西，只需要點擊左上角工具列的 **「復原（Undo）」箭頭圖示** ，就能退回上一個版本狀態。

![Claude Design ai 做簡報_復原上一步.jpg](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-04/e9d5-1776656350.jpg?w=1200&output=webp)

經理人

左上角工具列有兩個箭頭：向左的「復原（Undo）」和向右的「重做（Redo）」，以紅色框標示的是復原按鈕。畫布上顯示的是已修改後的封面（大標題已更新為「AI 簡報極速工作流」，以藍色強調色呈現）。如果對這個版本不滿意，按下復原就能退回修改前的狀態。

此外，旁邊的「重整（Reload）」也非常重要。如果整個 Claude Design 工作流中，發現生成的結果好像右欄的預覽畫面似乎沒有更新，或是顯示最新版本，就重新整理一下頁面吧！

## 步驟八：Tweaks 面板——一鍵微調視覺風格，不需要重新生成

這是 Claude Design 最讓我驚喜的功能之一，也是我認為它和其他 AI 簡報工具差異最大的地方之一。

## 讓 Claude Design 產出更好結果的 6 個 Prompt 技巧

用了幾輪之後，我整理出讓 Claude Design 表現更好的幾個實用操作習慣，供你參考：

### 1\. 先給素材，再下指令，不要空口說白話

上傳你的文件、大綱、舊版簡報截圖，讓 Claude 有東西可以讀。空著手直接下「幫我做一份很棒的課程提案」，它只能靠猜，產出一定很空洞。

### 2\. 要求特定頁數和頁面結構

「幫我做 8 張投影片，包含以下這幾頁的主題⋯⋯」比「幫我做一份簡報」精準得多。頁數、每頁主題、深淺背景交替都可以指定。

### 3\. 第一版不完美沒關係，重要的是快速確認架構

收到第一版後，先確認「投影片的邏輯順序對不對」，架構確認後再用 Chat 或 Edit 調整細節。不要在第一版就試圖讓 Claude 一次做到完美，那樣 Prompt 會變得很複雜，結果往往反而更亂。

### 4\. 修改要具體，不要說「感覺不對」

「第 3 頁的字太小，把標題改大一點」不夠精準；「第 3 頁的標題字級從 40px 改成 60px」才是 Claude 能精確執行的指令。越具體，改越準。

### 5\. 善用 Tweaks 探索風格方向，不要一直重新生成

如果你不確定要哪個配色，先用 Tweaks 面板點看看五種強調色各是什麼感覺，再決定要不要透過 Chat 進一步微調。這比每次都重新下 Prompt 生成一個新版本省時太多了。

### 6\. 要求 Claude 做多個版本讓你選

如果對方向不確定，可以直接說「給我封面的 3 個不同配色版本，讓我選」或是「針對投影片第 6 頁，除了表格之外，嘗試做成金字塔圖、流程圖等 5 不同圖解，另開新視窗給我選擇」。

## Claude Design 目前的限制與注意事項

作為一個仍在 Research Preview 階段的產品，Claude Design 有幾個使用上的限制，提前知道比較不會踩坑：

### 1\. 付費門檻

目前僅開放給 Claude Pro、Max、Team、Enterprise 訂閱用戶。免費帳號無法使用。

### 2\. 有用量上限

密集生成的情況下，可能會觸碰到使用配額的上限，系統會提示需要等候一段時間（通常是幾小時）才能繼續使用。建議不要一口氣把所有的修改需求全部塞在同一個 Session 裡，分批操作效率更高。

### 3\. Draw 標注偶有消失

用 Draw 模式在畫布上圈選並輸入備注後，備注文字有時會在 Claude 讀取前消失。遇到這種情況，解決方法是直接把備注內容貼到左側的 Chat 欄位中重新送出。

### 4\. Canva 匯出目前仍不穩定

Send to Canva 的功能測試中偶有錯誤，如果需要送去 Canva 後製，目前建議先用「Export as PPTX」匯出，再手動上傳到 Canva。

## Claude Design 改變了什麼？

Claude Design 目前還不是一個完美的工具，還在 Research Preview 階段，還有用量限制、還有一些小 bug。但作為一個「讓你更快從 0 到 1 的 AI 協作工具」，它已經超越了我對「AI 做簡報」這件事的既有想像。
