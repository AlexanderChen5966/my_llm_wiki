網站連結 [https://motion-reference.takayustudio.jp/](https://motion-reference.takayustudio.jp/)

Motion Reference 是由 TakayuStudio 製作的動態設計參考網站，將常見的介面與動畫效果整理成可搜尋、可播放的動態範例。它適合在設計網站互動、遊戲 UI、文字動畫或轉場效果時，先觀察動作的速度、緩動方式與整體感受，再以範例作為設計和實作的參考。網站目前提供 782 個動態參考，並可用日文或英文介面瀏覽。

使用者可以依動作名稱、用途、速度、緩動效果或視覺感受搜尋，也能透過分類縮小範圍。參考類型涵蓋 UI、遊戲、捲動、表單、手勢、SVG 等場景，從基礎的進場與移動，到不同節奏和回饋感的動畫，都能直接預覽。相較於只展示成品截圖或影片的靈感網站，Motion Reference 更著重「動作本身」：可以調整播放速度、暫停、逐格檢視，也能操作部分範例，觀察互動如何影響動畫。

網站提供的功能包括：

- 即時預覽動態範例，並調整播放速度或只播放選取的效果。
- 以文字測試文字動畫，也可切換字體類型與日文、英文顯示。
- 透過時間軸、逐格控制與洋蔥皮效果，觀察動畫前後變化。
- 查看動畫時間、緩動、用途、感受、觸發方式與設計注意事項。
- 比較原始動態與調整後的版本，觀察時間、幅度、延遲和緩動設定帶來的差異。
- 查看或複製實作範例，包含 HTML、CSS、WAAPI、GSAP、React 等形式，也能下載重現用的 HTML。

從實際工作情境來看，這個網站可用在動態提案、介面原型設計、動畫規格溝通，以及前端實作前的效果確認。例如，設計師可以先挑選適合的動態參考，再與工程師討論動畫的觸發條件、播放時間與緩動曲線；前端工程師則能參考範例程式，快速建立初步效果。網站也標示這些程式碼是以範例為起點的基本實作，仍須依實際 DOM 結構和互動狀態調整，因此更適合作為參考與學習工具，而不是直接套用就能完成所有專案需求的動畫套件。

整體而言，Motion Reference 把動畫靈感、效果比較與實作提示放在同一個介面中，特別適合 UI 設計師、網頁設計師、前端工程師、遊戲介面製作者與動態設計初學者。當你知道想呈現「滑順、俐落、彈跳」等感覺，卻還不確定該如何安排時間與緩動時，可以用它搜尋和比較不同範例，讓抽象的動態描述更容易轉化成具體設計。
