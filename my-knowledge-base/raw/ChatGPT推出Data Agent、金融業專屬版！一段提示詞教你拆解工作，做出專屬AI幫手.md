OpenAI 最近同時推出兩個很值得觀察的新服務：Data agent，以及金融業專屬的 ChatGPT for Financial Services。這類消息一出，很容易又讓人想到：數據分析師、華爾街菜鳥要失業了？

數據分析的 Agent 主打免寫 SQL，可連接企業數據庫、追查指標變化、製作互動儀表板；ChatGPT for Financial Services 則把專業金融資料、來源追溯、金融分析與財務模型等能力放在一起。

## OpenAI 同時推出兩個專業工作產品

![OpenAI 同時推出兩個專業工作產品](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-09/img-mcp-78a7372613846916.jpg?w=900&output=webp)

OpenAI 推出 Data agent，以及金融業專屬版 ChatGPT 。前者協助企業分析自己的數據，後者從投資銀行與股票研究等金融工作切入。它們都在把某類工作需要的工作邏輯，融合在 AI 裡。

## 數據 Agent 不是查數字，還要先懂你的資料脈絡

![數據 Agent 不是查數字，還要先懂你的資料脈絡](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-09/img-mcp-08bf395e5a8e304b.jpg?w=900&output=webp)

使用者不用自己寫 SQL 等查詢語法，就能請它連接公司核准的數據來源，追查指標為什麼變動，再整理成互動式儀表板。它還可以讀取公司的指標定義、計算方式與資料關係。前提是公司管理員有開放串接此功能，而且你本來就有查看數據的權限。

## 金融業專屬版 ChatGPT，把資料、分析與產出放在一起

![金融業專屬版 ChatGPT，把資料、分析與產出放在一起](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-09/img-mcp-722145ea9d2b8c8d.jpg?w=900&output=webp)

它內建專業金融資料，能協助研究、財務分析與建構模型，並讓使用者追溯數字與說法的來源。企業還能放入自己的 Excel、Word、PowerPoint 範本，讓模型、研究報告與簡報符合公司的格式與風格。目前只開放符合資格的金融機構洽談導入。

## 換成你的工作，怎麼思考你的 Agent？

![換成你的工作，怎麼思考你的 Agent？](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-09/img-mcp-4f96b372f6224644.jpg?w=900&output=webp)

挑一件你每週都會重複做的工作，問 AI：「請協助我把這項工作拆成 5 個部分：資料與背景、處理步驟、判斷原則、使用工具、交付標準。一次只問我一題。幫我找出：哪些例外會改變做法？遇到什麼情況需要進一步追查？哪些判斷不能只靠固定規則？做到什麼程度才算可以交付？最後整理成一份工作拆解表」

## 決定人和 AI 怎麼分工

![決定人和 AI 怎麼分工](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-09/img-mcp-17876eda1cd3c123.jpg?w=900&output=webp)

有了工作拆解表後，再逐步決定 AI 要做到哪裡。①AI 可以直接做：明確告訴它要拿什麼資料、產出什麼結果。②AI 先做完、人確認：定義 AI 做到哪一步，以及人要檢查什麼。③必須由人判斷：哪些情況要直接交給人決定。

## 用真實工作測試你的 AI

![用真實工作測試你的 AI](https://image-cdn.learnin.tw/bnextmedia/image/album/2026-09/img-mcp-2d56c8d0ccbc62ca.jpg?w=900&output=webp)

拿一個過去真的做過的案例，把需要的資料提供給 AI，請它按照前面的工作拆解與人機分工實際做一次。接著檢查：哪一步做錯了？哪裡理解錯你的意思？每發現一個問題，就把缺少的資料、步驟或判斷規則補回工作拆解表。等做法逐漸穩定後，再考慮接上資料庫、試算表、CRM、搜尋工具或公司範本，讓更多步驟自動完成。
