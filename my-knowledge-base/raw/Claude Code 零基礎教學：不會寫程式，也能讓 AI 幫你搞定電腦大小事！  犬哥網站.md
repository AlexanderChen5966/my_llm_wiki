## Claude Code 是什麼？

==**Claude Code** 是 Anthropic 推出的一款 **代理型（Agentic）AI 工具**== ，它能控制你的電腦終端機，擁有查看檔案、編輯程式碼、執行指令的權限。

在正式介紹 Claude Code 之前，要先了解一件事：Claude 其實有很多型態，Claude Code 只是其中一種。

### Claude 的三種進化型態：從對話到執行

很多人對 [生成式 AI](https://frankknow.com/what-is-generative-ai/) 的印象，都還停留在聊天功能的階段，但其實 Claude 已經進化成三種不同的使用形式，對應不同層次的需求：

- **==Claude Chat（對話型）：==** 這是最基礎的版本，適合用來發想點子、寫文案或翻譯，基本上是以「 你下指令，它給回饋 」的對話模式運作。
- **==Claude Cowork（協作型）：==** Cowork 更進階一點，能讓 Claude 用 **虛擬沙盒環境** 存取你的檔案、連結工具，在你的工作流程中扮演「 AI 助手 」的角色。
- **==Claude Code（終端機版）：==** Claude Code 是一個在你電腦「 終端機 」上運作的工具，可以直接操作你的電腦，自動搜尋檔案、跑程式並完成複雜的開發任務。

### Claude Cowork & Claude Code 的差異

這邊整理了三種型態的主要差異，可以了解到 Claude 針對不同族群做出了各自適合的產品：

| ****功能特性**** | ******Claude Chat****** | **Claude Cowork** | ******Claude Code****** |
| --- | --- | --- | --- |
| ****使用方式**** | 瀏覽器 / App | 桌面 App | 終端機 |
| ********能做什麼******** | 問答、寫作、分析 | 文件協作、任務管理 | 直接操作電腦與檔案 |
| ******檔案權限****** | 需手動上傳檔案 | 只能使用授權的工具或資料夾 | 授權後可操控電腦本地檔案 |
| ******執行能力****** | 只提供文字或程式碼 | 可預覽前端網頁 | 可執行終端機指令、安裝套件 |
| ******互動模式****** | 問答式 | 協作式 | 代理人模式 (自主完成任務) |
| **適合對象** | 所有人 | 想用簡易操作實現跨工具協作的人 | 追求全自動代理的進階學習者 |

在深入體驗 Claude Code 的強大自動化能力之前，建議先搞懂 Claude 的核心強項是什麼。

### 可以利用 Claude Code 做哪些事？

Claude Code 最棒的地方，在於它打破了技術門檻，讓原本需要工程師手動敲程式碼才能完成的複雜任務，變成 ==一般人就能用自然語言，指揮 AI 深入系統去解決問題== 。

![Claude Code 使用上有幾個需要注意的關鍵](https://frankknow.com/wp-content/uploads/2026/04/Claude-Code-notice.jpg)

Claude Code 使用上有幾個需要注意的關鍵

這邊舉四個最實用、最容易遇到的使用情境：

1. **==整理資料夾、批次改檔名==**

你的桌面或下載資料夾，是不是一片混亂？

「 截圖 2024-01-15 」、「 IMG\_0342 」、「 新增文件 (3) 」，來不及整理的資料越積越多，光是看到這些檔名就很頭痛。

一個一個手動改名，或是學著用批次改名軟體都很花時間，現在你只要打一段話給 Claude Code：

**「 幫我把桌面的 Downloads 資料夾裡，所有.jpg 的圖片，依照拍攝日期重新命名，格式是（年-月-日-編號）。 」**

Claude Code 會自動幫你讀取所有圖片的資訊，產生對應的新檔名，一次搞定數百個檔案。

同樣的邏輯也可以用來自動分類資料夾，依照任何你訂的規則都沒問題。

2. **==把一堆 Excel 資料自動彙整成報表==**

統計資料是所有會計、數據分析師都需要面對的日常，假如今天每個部門、每個月份都有一份 Excel，你需要把它們合併成一份總報表，還要算出加總、平均，甚至產出分析報告。

你只要把這些檔案放在同一個資料夾，然後告訴 Claude Code：

**「 幫我把這個資料夾裡所有的 Excel 檔案合併，以『 部門 』分類，計算每個部門的月營業額總和，並產出一份新的彙整報表。 」**

不需要懂任何 Excel 公式，也不需要知道 Python 是什麼，Claude Code 就會自動開啟每一份 Excel、讀取資料、進行計算，輸出一份全新的報表給你。

3. **==幫你建立一個簡單的網頁或工具==**

「 想做一個自動計算匯率跟運費的報價單工具 」、「 我想要一個客製化的作品集網頁 」，這些過去都需要找工程師花錢、花時間才能做。

現在， 你告訴 Claude Code 想要什麼樣的功能、什麼風格，它就能產生完整的網頁，甚至幫你佈署到伺服器，直接用瀏覽器打開就能用。

4. **==自動化重複性的電腦作業流程==**

這是 Claude Code 最強大的主要能力，把每天都會重複的日常工作，變成可一鍵執行的自動化流程。

比如說：

- 每天早上自動整理信箱附件，依照寄件人分類存到對應資料夾
- 每週五自動產出工作週報，抓取你這週的任務紀錄，整理成一份文件
- 每次新增客戶資料時，自動更新對應的統計表格並寄送確認通知

這些事情，你只需要在 Claude Code 溝通過一次，請它幫你寫好腳本、設定關鍵字，之後只要輸入關鍵字，所有的步驟都會自動跑完，完全不需要你手動介入。

## 非工程師，這樣用 Claude Code 就對了！

看到這裡你可能會想，我對程式碼又不熟悉，下指令會不會很難？

你只要先記住一個原則： ==想用好 Claude Code，只需要把你的需求說清楚，剩下的就交給 AI 吧！== 畢竟 Claude Code 的設計初衷，就是讓任何人都能透過「 白話文 」來操控電腦。

不過想要用得順、用得安心，還是有一些心法需要知道。

*Claude Code 使用上有幾個需要注意的關鍵*

### 先從找到「 痛點 」開始

在急著打開 Claude Code 之前，最重要的第一步就是停下來想一想，每天在使用電腦上什麼事情最讓我煩惱？

- 有哪件事，我幾乎每天、每週都要重複做一遍？
- 有哪件事，我每次做都覺得「這應該可以更快」？
- 有哪件事，我一直想做，但因為太繁瑣所以一直拖著沒做？

越具體的痛點，越容易轉換成 Claude Code 能幫你解決的任務，把這些事情列出來，你就有了一份屬於自己的任務清單。

### 懂得下指令：把「 需求 」轉換成「 任務 」

跟 Claude Code 對話時，最有效的溝通方式是「 先討論 > 確認操作範圍 > 最後執行 」。

其實就像在公司管理一個實習生一樣，如果沒有給出明確的目標，也沒有確認執行方向和期望的是不是一致，最後就會發現做出來的結果跟你想的不一樣。

==「 誰、做什麼、對哪些東西、按照什麼規則、輸出什麼結果 」，這五個要素越清楚，Claude Code 的執行結果就會更精準。==

如果你一開始不知道怎麼下這麼完整的指令，也可以先把你的需求丟給 Claude Code，然後請它提問、給你幾個做法，你再從中挑選或調整：

**「 我有一個資料夾裡面有幾百個檔案，我想把它們整理好，但我不確定最好的方式是什麼，你有什麼建議？ 」**

透過來回對話，你會逐漸釐清自己真正想要的結果，最後再由 Claude Code 自動化的替你執行任務。

### 判斷要不要給「 權限 」

這是非工程師最容易忽略，卻也最重要的一環！

Claude Code 在執行某些指令時會徵求你的同意，例如存取某個資料夾、修改某個檔案，或是刪除某些內容，讓你保有最終的控制權。

如果你不確定給了這個權限之後，Claude Code 會動到哪些東西，那就先不要給，改用對話問清楚再說。

- **==特別注意「 刪除 」與「 覆蓋 」：==**

建議你先請 Claude Code 列出它打算刪除的清單，確認沒問題之後再讓它執行，養成保護資料的好習慣。

- **==保護你的系統核心：==**

你的系統資料夾和各種軟體的設定檔，是電腦正常運作的根基。除非你非常清楚為什麼需要提供，否則這些地方的存取權限，一律不給。

- **==採取漸進式授權：==**

一開始只給它讀取的權限，等它分析完畢、你確認邏輯正確後，再給它寫入或執行的權限。任務完成後，也可以撤銷不再需要的權限。

用這樣的心態使用 Claude Code，既能享受它帶來的效率，也能確保你的電腦和資料始終在自己的掌控之中。

## 安裝 Claude Code 完整流程 + 介面介紹

### 付費方案怎麼選？

Claude Code 不是免費工具，使用之前你需要先確認自己的付費方案，目前主要有兩種進入方式：

- **==Claude 會員訂閱制（Pro / Max / Team / Enterprise）：==**

這是大多數人熟悉的月費模式，如果你只是想整理檔案、偶爾跑一些自動化任務，Pro 方案是最簡單的入門選擇。

Max 方案就比較適合重度使用者，讓你可以在 Claude Code 裡跑更複雜、更長的任務，不用擔心中途被限流打斷。

![Claude 方案（實際方案內容請以官方最新公佈為主）](https://frankknow.com/wp-content/uploads/2026/02/Claude-Plans.jpg)

Claude 方案（實際方案內容請以官方最新公佈為主）

如果有團隊協作的需求，再考慮使用 Team / Enterprise 方案，除了免費方案之外，其他方案都是有支援 Claude Cowork 和 Claude Code 使用的。

- **==API 方案（按用量計費）==**

這個方式是透過 API 使用 Claude Code，你需要在 Anthropic 平台上取得 API 金鑰，然後在終端機裡設定環境變數。

這個方式的彈性最高，可以精確控制用量和費用，但設定步驟相對複雜一些，比較適合已經有一點技術背景的用戶。

> 建議新手可以先從 Pro 方案開始試用，感受一下日常的使用量，再決定要不要升級！

### 三種安裝 & 使用方式

根據你的操作習慣，你可以選擇最適合自己的「 入口 」，對應不同的使用習慣和需求，有三種進入方式：

|  | ********桌面版 APP******** | ****終端機（CLI）**** | ********編輯器擴充套件（IDE）******** |
| --- | --- | --- | --- |
| ******適合誰****** | 一般使用者 | 進階用戶 | 習慣以編輯器工作的開發者 |
| **********操作方式********** | 圖形介面，點擊按鈕操作 | 純文字介面 | 整合在程式編輯器裡 |
| ********安裝難度******** | 最簡單 | 中等 | 中等 |
| ********最大優點******** | 不需要任何技術背景 | 彈性高 | 工作流程最順暢（寫程式用） |

### Claude Code 的使用介面

安裝完成之後，打開 Claude Code 會看到一個對話介面，乍看之下和一般的 Claude Chat 很像，這邊就來介紹幾個最常用到的基礎關鍵功能吧～

![Claude Code 基本使用介面介紹](https://frankknow.com/wp-content/uploads/2026/04/Claude-Code-intro.jpg)

Claude Code 基本使用介面介紹

打開介面後，你會看到對話框旁邊有一個 「 + 」號，可以分別用不同方式導入資料：

- **==Upload from computer（從電腦上傳）：==**

不再需要把檔案拖到網頁瀏覽器，直接選取你電腦裡的 Excel、PDF 或圖片，讓 Claude 直接讀取並分析。

- **==Add Context（加入專案資料）：==**

讓你直接把本機的檔案丟給 Claude Code 參考或處理。比如你正在做一個網站，把整個網站資料夾加進去，Claude 就不會雞同鴨講，而是根據你現有的架構給建議。

- **==Browse the web（瀏覽網路）：==**

讓 Claude 可以即時上網查詢資料、API 文檔或行銷趨勢，確保它給你的答案不會過期。

![Claude Code 可以切換 3 種不同的工作模式](https://frankknow.com/wp-content/uploads/2026/04/Three-Modes.jpg)

Claude Code 可以切換 3 種不同的工作模式

Claude Code 介面的右下角，有一個模式切換按鈕，或是用 Shift + Tab 快速切換。

這三種模式決定了 Claude Code 在執行任務時的「 主動程度 」，根據你的任務性質選對模式，就能讓工作效率大幅提升。

- **==Ask before edits（預設模式）：以對話為主，給指令再動作==**

在這個模式下，Claude Code 每次要對你的檔案或系統進行任何實際操作之前，都會先告訴你它打算做什麼，等你確認之後才會動手，安全性較高。

- **==Edit automatically（自動編輯）：代理人模式==**

Claude Code 會在你下完指令後，自動連續執行所有需要的步驟，不再逐一停下來等你確認。適合步驟重複、風險低的任務， **建議先在預設模式下測試一次，再切換自動化處理** 。

- **==Plan Mode（計畫模式）：複雜專案先討論，再請它提供執行計劃書==**

先和你討論整個任務的做法，最後提出一份完整的「 計劃書 」，列出它打算分幾個步驟、每個步驟要做什麼、會影響哪些檔案。看過計劃書、確認沒問題之後，再讓它開始執行。

## 讓 Claude Code 更聰明的進階使用技巧

掌握了基礎操作之後，接下來要介紹的這幾個進階功能，讓你可以把這個 AI 助手打造成專屬你的超級自動化團隊。

你可以把這些技巧想成是替 Claude Code 裝備不同的武器，每一種都有它最適合出場的場合。

### 輸入 / 使用內建命令

在對話框裡輸入「 / 」，就會出現一份 [內建命令清單](https://code.claude.com/docs/zh-TW/commands) ，這些指令是 Claude Code 內建的快捷動作， ==讓你不用長篇大論，一個斜線就能精準觸發特定功能== 。

有些每天會用到的高頻指令，記起來之後能省下不少時間。舉例來說：

- **/compact：** 清除先前的對話歷史，可以節省 Token 成本。
- **/help：** 所有指令的清單和說明。
- **/schedule：** Claude 會以對話方式引導排成任務的設定。

### 使用 Skills 擴充功能：幫 AI 安裝專業技能包

可以把 Skills 想像成哆啦 A 夢的記憶吐司， ==把不同的 Skills 安裝到 Claude Code 裡，他就會學會不同的專業技能，讓產出品質更穩定== 。

- **官方 Skills：** 你可以直接安裝 [Anthropic 官方推出的 Skills 技能包](https://github.com/anthropics/skills/tree/main/skills) ，涵蓋了程式開發、文件產出等常見需求。
- **自定義 Skill：** 你甚至可以根據自己的工作流程（例如：固定格式的週報、特定的排版規範）設計專屬技能，讓 Claude Code 完全配合你的習慣產出。

### 透過 MCP 連接外部資料或工具

==MCP 能讓 Claude Code 不只是在本機上操作檔案，還能直接控制你日常使用的各種軟體和工具。==

串接完成後，你可以用自然語言，指揮 Claude Code 幫你在不同平台之間自動化作業。

像是我們曾經在 [這部影片](https://youtu.be/P_AxLw32WO4) 示範過，讓 Claude Code 透過 MCP 直接操控 WordPress，自動完成新增文章、頁面設計、版面配置等等一系列工作，完全不用手動登入後台。

除了 WordPress，你還可以連結 Google Drive、Slack、甚至是資料庫。詳細的工具名單可以參考 [官方 MCP 說明頁面](https://code.claude.com/docs/zh-TW/mcp) 。

### 設定 Hooks 自動觸發腳本

==Hooks 就是幫 Claude 定規矩，讓它在特定的時機「 自動反應 」，不需要你每次都提醒：==

- **安全防護：** 在 Claude Code 要執行高風險操作之前，自動攔截並請求二次確認。
- **提醒通知：** 當它完成了一個耗時較長的任務後，自動透過桌面通知或通訊軟體跟你報告。
- **串接自動化流程：** 把 Claude Code 的執行結果，無縫接到後續的工作流程，例如任務完成後自動同步到 Notion、自動寄送報告等。

### 用 Subagents 建立分工系統

當你的專案非常大時（例如：同時處理網頁設計、內容撰寫與數據分析），就可以建立 Subagents（子代理），做好分工架構。

你可以 ==把每個 Subagent 想像成一位分工明確的專案成員，可以共享同一個 MCP 工具和 Skills 技能，但彼此之間不會互相干擾，完成之後再把結果回報給主代理整合。==

想學習建立 Subagents 的完整步驟，可以參考 [官方說明文件](https://code.claude.com/docs/zh-TW/sub-agents#explore) 。

## 常見問題

### Claude Code 是免費的嗎？

不是免費的，但有多種方案選擇。

目前需要使用 Claude Pro 或 Max 的訂閱帳號（月費制），或者透過 Claude API（用多少扣多少）來支付費用。

如果你是輕度使用者，Pro 方案通常就包含了一定的使用額度；如果你是重度開發者，使用 API 方案能更精準控制預算。

### 使用 Claude Code 要注意什麼？

最重要的是注意是「 權限控制 」與「 成本管理 」。

**安全第一：** 在執行檔案刪除或修改系統設定時，記得要先仔細閱讀指令，非必要不授權存取敏感資料夾。

**避免重複讀取：** 對話越長，消耗的 Token 就越多，建議在處理不同任務時適時使用 /clear 重新開始，或利用「 計畫模式 」先溝通好再執行，避免 AI 瞎忙造成額度浪費。

### Claude Code 支援中文指令嗎？

完全支援！你可以直接用中文跟 Claude Code 溝通，下指令、問問題、描述需求都沒有問題。

很多內建命令、官方說明文件也都已經有提供中文說明，對台灣使用者非常友善。
