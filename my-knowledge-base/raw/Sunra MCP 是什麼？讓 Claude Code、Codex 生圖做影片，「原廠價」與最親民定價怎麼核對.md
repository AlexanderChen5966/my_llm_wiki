Sunra MCP 在 2026 年 10 月 19 日由 Sunra 官方 X 帳號宣布推出，貼文在查詢時約有 460 個讚、34 萬次瀏覽，台灣時間是當晚將近午夜。

貼文的說法是，所有主流的圖片、影片與音訊模型，都能直接放進 Claude、ChatGPT 和你慣用的 AI 助理，Sunra 對每個模型都用原廠的 API 價格計費，沒有加價，並稱這是業界最親民的定價。

這對想讓助理批次生成素材的人很有吸引力，因為只要一個帳號與一套點數，就不用分別到每家模型平台儲值，也不用為了每個模型各寫一份串接。

查 Sunra 的官方網站與文件後，「按原廠價計費」的說法確實寫在頁面上，我也拿 MiniMax 的官方價目頁對過幾個數字。但「最親民」是廠商自己的比較，而且價格條件寫在腳註裡。

另外，官方網站教你連線的方式，是請程式助理安裝一個命令列工具，開發者文件另有一套 npm 的 MCP 伺服器設定，宣傳影片又示範輸入遠端伺服器網址，三種說法同時存在。

我的判斷是，它適合已經有明確素材需求、想在助理裡批次生成的創作者與開發者，不適合想讓預算完全可預測的人，也不適合只是偶爾生一兩張圖的人。

這個判斷要靠它實際提供的東西來驗證，所以先從模型與點數說起。

## Sunra MCP 是什麼？把圖片、影片與音訊模型接進你的 AI 助理

Sunra 是一個 AI 創作平台，官方網站的說法是給創作者的視覺工作套件。你用白話交代需求，內建的代理就會生成圖片、影片、音樂與 3D，再整理成簡報、影片或場景。

平台另有開發者入口，文件把它稱為整合式模型平台，用同一組 API 金鑰，同時呼叫多模態模型與大型語言模型，後者支援相容 OpenAI 與 Anthropic 的介面。

這次的 Sunra MCP，是把同一批模型開放給你自己的助理使用。MCP 是讓助理呼叫外部工具的通用協定，接上之後，你可以在 Claude Code 這類工具裡直接說：幫我做一張海報，或生成一段 8 秒的雨夜計程車鏡頭。

官網頁面寫的是，圖片、影片、音訊與 3D 的生成，使用的是和網頁版相同的點數。模型來源名單提到 OpenAI、Google、字節跳動、可靈與 ElevenLabs 等。

官方宣傳影片的價目列，則出現 GPT Image 2.5、Nano Banana 2.1、Seedream 5.0 Pro、Eleven v4、Veo 3.1 與 Midjourney V8.1。

官網頁面列出的助理有 Claude Code、Codex、Cursor、Antigravity 與 Grok Bot。

Claude 與 ChatGPT 的圖示也在頁面上，不過我在頁面上沒有看到針對它們各自的步驟，所以一般的聊天應用能不能接，要看帳號內的連線頁說明。

模型與點數都清楚了，剩下的問題是助理要怎麼連上它。

## Sunra MCP 連線：官網的命令列提示、文件中的 MCP 伺服器與影片的遠端網址

Sunra 官方網站的做法是複製一段提示，貼給 Claude Code、Codex、Cursor、Antigravity 或 Grok Bot，由助理照做。

提示只有三步：用 npm 全域安裝 @sunra/cli，執行 sunra login 並在瀏覽器完成登入，再執行 sunra balance 與 sunra tools，回報你的餘額與能做的事。

這個命令列套件在 npm 上建立於 2026 年 10 月 15 日，貼文發出之後約一小時，0.2.2 版才上架，官方頁面指定的就是這個版本。授權是 Apache-2.0，需要 Node.js 18.17 以上。

所以這是剛發布的新工具，版本還在快速調整，連線前最好確認頁面指定的版本與實際安裝的一致。

官網提示是把安裝交給助理執行，等於讓它在你的電腦全域安裝一個剛上架的套件。這個套件在 npm 上沒有說明文件，也沒有連到原始碼倉庫，所以我會先自己確認套件頁與官網一致，再決定要不要貼給助理。

另一條路是開發者文件裡的 MCP 伺服器頁面。它用 npx 執行 @sunra/mcp-server，在環境變數放入 SUNRA\_KEY，設定範例涵蓋 Cursor、VS Code、Cline、Windsurf 與 Claude Desktop。

這個伺服器提供的工具包括列出與搜尋模型、取得模型的輸入格式、送出請求、查狀態、取結果、取消、上傳檔案，以及在執行中設定金鑰。npm 上的版本是 8 月 17 日發布的 0.1.2。

第三種出現在官方宣傳影片。畫面是 Cursor 裡的「Connect Sunra MCP」視窗，名稱填 Sunra，伺服器位址填 `mcp.sunra.ai` ，官網頁面資料裡也有同一個網域。

這是遠端 MCP 伺服器的連法，但官方文件沒有說明它的授權方式，也沒有說明它和前兩種的關係。官方沒有交代 10 月 19 日宣布的 Sunra MCP 究竟是哪一種，我也不想猜，比較穩妥的做法是以你登入後帳號內的連線說明為準。

### 用一個小任務驗收

我會先只做兩件事：執行 sunra balance 看餘額，執行 sunra tools 看助理拿到哪些工具。這兩步不會生成任何東西，卻已足以確認帳號與連線都正常。

接著請助理生成一張最便宜的小圖，並要求它在送出前先說明這次生成預計扣多少點數。官方 FAQ 談 Sunra 內建代理時說，生成的點數成本會在送出前顯示，代理自己的作業則依詞元計費。

你自己的助理，例如 Claude Code，用量另外由它的供應商計費，所以兩種花費要分開看。驗收完成後，再到帳單紀錄確認實際扣款，開發者文件說每筆請求的金額都會出現在那裡。帳單上的金額是不是真如宣稱，取決於「原廠價」這個承諾能不能查證。

## 「按原廠價計費」怎麼核對：價目頁、文件與原廠公告

貼文說每個模型都用原廠價、沒有加價。官網定價頁的寫法是每個模型都按原廠 API 價格，另一段說明則是在 Sunra、MCP 與 API 三條路上，付的都是各家實驗室收的價格。

開發者文件把細節講得更具體。每個模型頁都會標出各端點的價格，多數模型在送出請求時價格就固定，相同的參數永遠同價，少數模型則在完成後依實際用量結算。

例如 Seedance 影片模型是依詞元計費，費用要生成完成後才確定，公式是影格數乘以寬度與高度，再除以 1024。文件舉的例子是 720p、每百萬詞元 6.40 美元的設定，輸出 10 秒、搭配 6 秒參考影片，約 2.36 美元。

參考影片至少按輸出長度的三分之二計費，所以例子裡的 6 秒參考片，實際按 7 秒算。短參考片搭配長輸出時，仍要付這個下限。

要核對這些價格和原廠是否一致，我拿 [MiniMax 的官方價目頁](https://platform.minimax.io/docs/guides/pricing-paygo?ref=aiposthub.com) 對了幾項，2026 年 10 月 20 日查詢的結果如下。

| 規格 | Sunra 文件 | MiniMax 官方價目頁 |
| --- | --- | --- |
| H3，768P | 每秒 0.08 美元 | 每秒 0.08 美元 |
| H3，2K | 每秒 0.13 美元 | 每秒 0.13 美元 |
| H3-Max，480P | 每秒 0.05 美元 | 每秒 0.05 美元 |
| H3-Max，768P | 每秒 0.08 美元 | 每秒 0.08 美元 |
| H3 超出免費額度的參考圖 | 每張 0.04 美元 | 每張 0.04 美元 |
| H3-Max 參考影片 480P、768P | 每秒 0.0553、0.143 美元 | 每秒 0.0553、0.143 美元 |

這個對照只是比對兩份公開文件，並不是我實際生成後的帳單。結果是上面幾項數字一致，所以 Sunra「沿用原廠價」至少在這一家的這幾個規格上成立。

但 Sunra 文件還列了 H3 的 480P、H3-fast 與 H3-max-turbo，MiniMax 那一頁沒有對應條目，我就無法核對。

想確認其他模型，可以用文件提供的價格介面，它能列出每個端點的機器可讀價格規則，其中模型清單與單一端點的規則不需要金鑰就能查詢。

所以結論是，原廠價的說法有查得到的支撐，但每個模型都要自己對一次。不過原廠價只說明單價，貼文的另一個說法是「最親民」，那就要看比較條件了。

## 「最親民定價」的條件：Creator 年繳，以及與 9 個平台的比較

官方宣傳影片先打出「業界最親民的定價」，同一個畫面底下的小字寫著：與其他 9 個平台比較，Creator 方案，年繳。

接著影片列出幾個「起」價。Seedream 5.0 Pro 每張 0.019 美元，GPT Image 2.5 每張 0.004 美元，Nano Banana 2.1 每張 0.015 美元。

Seedance 2.5 則是每秒 0.039 美元，每一項都附註 Creator 方案、年繳。

定價頁可以解釋這個條件。基本版、專業版與 Creator 的月繳價是 12、29、125 美元，改成年繳後每月 9、17、63 美元，折扣依序約 25%、41% 與 50%，對應每月 1,200、3,500、17,000 點。

也就是說，最便宜的那一檔，等於預先付 756 美元一整年的 Creator，而且點數不會滾存，每月重置。官方 FAQ 明寫，方案點數在每個計費週期開始時刷新，不會累積到下個月。

定價頁的成本比較元件，還附了一段方法說明：取已驗證價格中差距最大的項目，以點數用完的價值計算，比較對象是其他平台最高階的個人年繳方案或較低的 API 價格，比較日期是 10 月 14 日到 18 日，並標示為估算。

白話來說，這是一個對 Sunra 有利的比較框架，只要點數沒用完，實際每張的成本就會高於標示。

「起」價也不能直接套用到你的需求。影片標的每秒 0.039 美元，我無法從公開頁面判斷對應的解析度。文件寫明，Seedance 2.5 的費率依輸出解析度與是否帶參考影片而不同。

我用官方公式算過一個 1080p 的例子。文件在說明草稿升級時，寫到 1080p 不含參考影片的費率是每百萬詞元 11.70 美元，所以 10 秒的影片約 5.71 美元，折合每秒約 0.57 美元。

這個數字依文件原價計算，沒有套用任何方案折扣。它不能拿去和 0.039 相除，因為影片沒有交代 0.039 的解析度，也沒有交代年繳折扣怎麼換算。

但它提醒你，高解析度影片的實際成本，可能和標價的「起」差很多。

影片最後的示範是「幫我的專輯做 1,000 張封面」，結尾顯示 3.71 美元，標示為 GPT Image 2.5。影片沒有說明這個金額包含哪些項目。依影片標的每張 0.004 美元估，1,000 張約 4 美元，量級是合理的。

從標價「起」到實際帳單，中間還隔著解析度、方案與用量，所以花費上限比標價更值得先設好。

## 控制花費：預留金額、預算金鑰與助理的批次行為

助理可以幫你自動化，也意味著它可能在你沒注意時，連續送出很多筆生成。影片示範的就是一句話要 1,000 張，所以先決定花費的上限，比先決定模型更重要。

開發者文件有一套預算金鑰，是主金鑰衍生出來的短期子金鑰，有美元上限、最長 24 小時，可以限制可用的模型與必須帶的標籤，適合一個助理的一次作業使用。

不過文件自己也講得很清楚，這是用預估金額做准入，並不是硬性的花費上限，實際結算可能超過。文件舉的預留例子是：Seedance 2.5 每次送出預留 18 到 21 美元，Seedance 2.0 預留 8 美元，語音辨識預留 1 美元。

所以如果你的助理同時送出多筆影片請求，預算池裡需要的可用額度會倍數增加。共用預算池的功能目前只開放給部分組織，要聯絡官方才能啟用。

官方文件還提醒，API 金鑰等同帳戶餘額的存取權，要像密碼一樣保管，不能放進瀏覽器或手機應用的程式碼。

Seedance 2.5 另有草稿模式，可以先用 480p 做草稿，滿意後再升級成 1080p，兩個步驟各按該解析度的費率計費。我的看法是，這比直接送 1080p 更容易在途中喊停。

這些預算金鑰與預算池是文件為 API 設計的功能。官方沒有說明透過網站教你的命令列連線時，是否也適用。

那條路走的是方案點數，因此我的做法是先限制方案額度，並在每次請求前要求助理報價。花費管得住之後，才輪到判斷這個服務適不適合你。

## 適合誰、不適合誰：導入前的檢查

這類服務的價值，在於把多家模型整合在同一個入口，也因此要先確認你的使用型態。

| 情境 | 適合嗎 | 原因 |
| --- | --- | --- |
| 常態批次生成素材的創作者或小工作室 | 適合 | 點數集中管理，助理可以自動化重複工作 |
| 想比較多家模型輸出的開發者 | 適合 | 同一組金鑰可以呼叫不同模型，文件提供機器可讀價格 |
| 每月只偶爾生成一兩張圖 | 不太適合 | 方案點數不滾存，閒置的月份仍要付費 |
| 預算必須逐筆可預測 | 要設限 | 部分模型完成後才結算，預留金額也只是估算 |
| 提示詞或素材含客戶機密 | 要先看條款 | 內容會被送往你所選模型背後的供應商 |

導入前我會先確認五件事。

- 你要用的模型：先到模型頁看標價，並用文件的價格介面確認端點與規格。
- 方案與年繳：先用月繳試用，確定每月真的會用掉點數，再考慮年繳。
- 單次上限：要求助理在送出前報價，並限制單次數量與影片長度。
- 素材權利：方案頁列了商業使用，但各模型原廠的條款是否另有限制，頁面沒有逐一說明，要自己查。
- 退款與降級：官方說退款要寄電子郵件，降級要聯絡客服。

這五件事確認完，還要看廠商的說法有哪些是自己說了算，以及資料會被送到哪裡。

## 限制與風險：價格比較由廠商提供，資料會送往模型供應商

第一個限制是發布時間。這是剛公布的服務，命令列套件在貼文之後才釋出新版，官網、文件與影片的連線說明也不一致，所以操作細節可能很快改變。

第二，價格比較是廠商自己做的。影片的腳註只說比較了 9 個平台，沒有列出名單，也沒有附上可重現的資料，我只能把它當成宣稱來讀。

第三是資料。官方的 [信任與安全頁](https://sunra.ai/trust?ref=aiposthub.com) 寫明，你提交的提示與媒體，會被送到你所選模型背後的第三方供應商，例如 OpenAI、Google、字節跳動或快手。

同一頁說，Sunra 不會拿你的提示、上傳或生成內容來訓練自家模型，也不賣個人資料。但對第三方供應商，官方的措辭是正在取得不訓練、不保留的書面承諾，並公開供應商名單。

資料可能在美國與其他地區處理。官方說帳號資料與生成媒體存放在受管理的雲端，傳輸與靜態時都加密，生成的項目也能隨時從資料庫刪除。

不過官方也坦白說，目前尚未取得 SOC 2 或 ISO 27001 認證。所以公司級的敏感素材，導入前要先索取資料處理協議與供應商名單。

第四是法律主體。隱私政策列出的營運公司是在新加坡註冊的 Second Enlightenment Global Private Limited，使用服務前可以對照條款。

最後，點數與價格會變。官方價目與模型名單在發布期間仍可能調整，所以每次大量生成前，都應該重新看一次模型頁的價格。實際使用前，讀者最常問的是加價、聊天應用、訂閱與商用這四件事。

## Sunra MCP 常見問題

### Sunra MCP 真的沒有加價嗎？

官方網站與貼文都寫按原廠價計費。我對照 MiniMax 官方價目頁，幾個規格的數字一致，但只能代表這幾項。你還要加上方案月費，以及點數是否用完的因素。

### Sunra MCP 可以直接在 Claude 或 ChatGPT 的聊天視窗用嗎？

官網的設定提示針對的是 Claude Code、Codex、Cursor、Antigravity 與 Grok Bot。聊天應用的圖示出現在頁面上，但沒有獨立步驟。影片示範的遠端網址能不能用在聊天應用的連接器，官方也沒有說明，要以帳號內的連線說明為準。

### 一定要買訂閱嗎？

官方開發者文件的 API 是用多少付多少。網頁版與 MCP 使用的是方案點數，官網定價頁列的是訂閱方案。官網的頁面描述提到可免費試用，但額度多少、是否適用於 MCP，頁面沒有說明。

### 生成的圖片和影片可以商用嗎？

官方方案列了商業使用。但每個模型原廠的使用條款是否還有額外限制，頁面沒有逐一說明，所以要商用前，仍要回頭看該模型的條款。

## 先小額驗證價格，再讓助理批次生成

Sunra 的亮點，是把多家模型放在一個入口，讓助理能直接生成素材。要不要用，取決於你的實際用量，而不是影片裡最低的那個標價。

我的建議是先用月繳或最低額度，確認連線、餘額與送出前報價都正常，再挑一個你常用的模型，對照原廠價目頁算一次單位成本，最後才開放助理批次生成。

想持續追蹤 AI 生成工具與 MCP 的更新，可以免費訂閱 AI 郵報，也建議在大量使用前，回到官方定價頁與文件確認最新價格。
