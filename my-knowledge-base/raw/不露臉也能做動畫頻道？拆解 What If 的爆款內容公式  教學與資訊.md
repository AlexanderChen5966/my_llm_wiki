不露臉，也能做出讓人想看完的動畫頻道嗎？這次拆解的樣本是 YouTube 頻道 Ifverse（@IfverseTales）。

原稿列出的數據相當醒目：起步約一個月、發布 33 支影片，增加 60,133 名訂閱者；近 28 天總播放突破 940 萬。比起照抄單支影片，更值得研究的是它如何把大家本來就會好奇的問題，包裝成一段有起點、有轉折、也有結局的故事。

## What If 的內容公式

拆解後，可以把核心寫成： **What If + 極端能力或設定 + 故事化結局** 。

「如果一個普通人突然擁有某種能力，接下來會怎樣？」或「如果時間、智商等條件被大幅改變，生活會變成什麼樣？」這類題目不需要太多背景，觀眾一眼就能理解前提，也自然想知道結果。

接著，影片要把設定一步步推演下去：先交代改變，再展示它造成的影響，最後用一個有回應、有落點的結局收束。觀眾點進來是為了看「如果真的發生，最後會怎樣」，所以故事推進比塞入更多設定更重要。

AI 讓旁白、分鏡和簡單動畫更容易製作，但工具本身不會自動帶來觀看。選題是否熟悉、標題是否清楚、每段敘事有沒有把觀眾帶到下一步，仍然是影片能不能留住人的關鍵。

## 先用三步找到可測的題目

1. **用關鍵字找近期樣本：** 在 YouTube 搜尋「What If + 能力」、「What If + 時間」或「What If + 智商」等組合，觀察近 30 天仍有觀看的影片，優先挑標題一眼看得懂的題目。
2. **整理選題筆記：** 記下頻道名稱、影片標題、近期播放表現，以及標題如何交代設定。重點是找出大家早就好奇的問題，不是複製別人的故事。
3. **先做最短版本測試：** 用手邊已有的流程，例如 Claude 協助整理腳本、配上旁白，再搭配簡單動畫，先完成一支短片，確認題目和敘事是否吸引人。

這類頻道的方向可以濃縮成：硬核腦洞、極簡畫面、清楚的因果推演。保持角色與視覺風格一致，再讓每支影片回答一個明確的 What If 問題，就能逐步測出觀眾願意追看的題材。

## 可直接改寫使用的 What If 提示詞

把下面這段貼到 Claude 或 ChatGPT，再替換方括號裡的題目：

> 你是一位擅長 YouTube 極簡動畫的原創編劇。請以「如果一般人突然遇到【能力／時間／智商等極端設定】」為題，寫一支約 60–90 秒的 What If 動畫短片。先用一句話說清楚設定，再依序提供：① 開場鉤子；② 四段逐步升高的事件，每段都說明前因後果；③ 回應題目的故事結尾。每段請附上旁白、火柴人或極簡動畫的畫面描述，以及必要字幕。請保持視覺簡單、節奏明快，讓觀眾能一路理解並想知道結局；不要複製既有影片的腳本，也不要把推測寫成已證實的科學事實。

先挑一個大家本來就會點進去的問題，再把它講成有完整結局的故事。AI 可以加快製作，真正值得反覆打磨的，仍是題目、推演和敘事節奏。
