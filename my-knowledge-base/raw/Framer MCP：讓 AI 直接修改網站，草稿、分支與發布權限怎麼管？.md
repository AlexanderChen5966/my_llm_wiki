Framer MCP 把 AI 修改網站的入口，接到你原本就在用的代理。因為設計與內容仍留在 Framer 專案，團隊可以在熟悉的畫布檢查成果，不必每次先把網站搬成另一份程式。

Framer 在 2026 年 10 月 22 日透過官方 X 帳號公布功能，同日更新入門文件。它支援能連接遠端 MCP 服務與帳號授權的工具，包括 Claude、Codex、Cursor 等。

MCP 是讓 AI 串接應用程式的協定。這裡連上的，是 Framer 遠端服務，所以不用另外安裝本機橋接程式，也不需要一直開著 Framer 編輯器。

這對已有網站的設計與行銷團隊比較直接：可以先讓代理讀懂目前專案，再修改指定頁面的內容或版型，保留既有元件與樣式。

但能修改專案，也代表要說清楚權限與完成範圍。官方預設讓變更留在專案，若你明確要求，代理也可以發布，所以「先做草稿」應在任務裡講清楚。

從第一次連接開始，最重要的就是分清楚代理開了哪個專案、改了什麼，以及是否已經影響對外網站。

## Framer MCP 能在專案裡改什麼？

依 [Framer 官方功能頁](https://www.framer.com/mcp/?ref=aiposthub.com) ，代理能在帳號有權存取的專案中，操作畫布、元件、支援的專案設定與內容管理系統。這讓網站更新可以接到現有文件結構，而不只生成一張看起來相似的截圖。

內容管理系統常寫成 CMS，用來保存文章、案例或商品等可重複顯示的資料。因此同一個更新要求，可能涉及頁面上的文字，也可能涉及集合裡的內容，最好先確認要改哪一層。

### 改畫布與改內容集合有何差別？

如果你要調整首頁標題，代理可以在對應畫面修改文字。若你要新增多個案例，則可能需要操作集合資料與使用該集合的版型，兩者的影響範圍不同。

因為共用元件可能被多頁使用，一個看似很小的改動，也可能出現在其他地方。例如修改主導覽的按鈕文字，應先知道它是不是共用元件，才看得出這次更新會影響哪些頁面。

官方入門文件提供的例子，包括建立響應式價格頁、列出集合，以及修改首頁標題。這些例子示範可以從小要求開始，讓代理先辨認專案，再逐步擴大操作範圍。

響應式頁面會依螢幕大小調整排版，因此建立頁面後，仍要看桌面與手機的結果。因為文字變長或圖片比例改變，都可能在窄螢幕造成不同的效果。

### 為什麼要保留既有樣式與元件？

若公司網站已有標準按鈕、字體與間距，沿用這些設定通常比另做一套更容易維護。代理可以依現有專案工作，但使用者仍要在需求裡講出保留範圍，避免把「重做一頁」解讀成全面改版。

例如可以指定只調整價格頁的方案說明，其他導覽、表單與頁尾都保留。這讓驗收時有明確的差異，也比較容易發現代理是否碰到不該修改的共用內容。

對代理而言，讀取現有結構與說明修改方式，是動手前的重要工作。如果它只憑首頁截圖推測整個網站，就可能漏掉集合、樣式與元件關係，造成後續維護負擔。

## 第一次如何連接帳號，又避免選錯專案？

依 [Framer 官方入門指南](https://www.framer.com/help/articles/getting-started-with-framer-mcp/?ref=aiposthub.com) ，先在相容客戶端加入 Framer，再開啟登入頁面確認連接。連線使用的是你登入的 Framer 帳號權限，因此帳號是否能存取專案，會直接決定代理看得到什麼。

這裡的授權流程，讓使用者可以在 Framer 頁面確認連接，而不用把密碼交給聊天中的代理。客戶端顯示連線成功後，再提供完整專案連結，會比只講專案名稱更容易定位。

### 客戶端需要支援哪些能力？

官方列出的條件是遠端 Streamable HTTP MCP 與 OAuth。前者是客戶端與遠端工具傳送請求的方式，後者讓你在服務端完成登入與授權，兩者都需要相容才能接通。

不同客戶端有不同入口，有些從外掛目錄安裝，有些則在 MCP 設定加入伺服器。因為選單名稱可能隨版本改變，操作時適合以 Framer 對應客戶端的最新指南為準。

如果團隊由管理員控制外掛，連線也可能需要組織核准。這種情況應先確認管理政策，避免把無法連接誤認成帳號壞了，或反覆建立沒有必要的新連線。

### 為什麼完整專案連結比較可靠？

同一個帳號可能有多個名稱相近的網站，特別是正式版、測試版與客戶副本。完整連結能讓代理直接定位目標，也讓使用者在開始前檢查是否選對。

第一次連線可以先做只讀要求，例如列出專案裡的集合，或說明首頁現有結構。因為這些內容容易辨認，你可以快速確認代理接到的是預期網站，再決定要它修改什麼。

若代理找不到專案，官方建議確認登入帳號有存取權，並重新提供完整連結。如果登入流程曾被中斷，也可以重新完成授權，但不必因此改動網站內容或建立重複專案。

對協作團隊來說，連線成功只是進場。真正開始編輯前，仍應指定要改的頁面、保留的元件與預期結果，讓操作範圍與需求一致。

## 分支、預覽與正式發布，應該如何安排？

官方說明，變更預設留在專案或分支，直到你或代理發布。這讓團隊可以先檢查修改，但同時也表示代理具有在獲得明確要求後發布的能力，不能把預設草稿當成永久的權限限制。

分支可以理解成供修改與比較的工作版本。當代理要重排一頁或修改共用元件時，可以先在分支處理，讓人看過差異，再決定是否合併或發布。

### 給代理的第一個任務可以怎麼寫？

一個清楚的要求可以是：「在指定專案的工作分支修改首頁標題與說明，沿用目前樣式，完成後提供變更摘要與預覽，先保留草稿。」這樣代理知道目的，也知道交付邊界。

相反地，「把網站弄好」缺少判斷基準。因為網站有內容、排版與互動，代理可能各自做出合理選擇，卻與品牌或活動安排不一致，最後讓審閱變成整站重查。

若修改涉及價格或服務條件，應提供已定稿的文案。因為代理可以幫忙排版，但不應自己決定商業承諾，使用者也才能直接比對畫面與正式資料。

### 預覽應該看哪些地方？

先看修改目標是否達成，再看相鄰內容有沒有被擠壓。例如標題換成較長中文後，桌面可能仍正常，手機卻多出兩行，讓按鈕掉到第一屏之外。

接著看共用元件與連結。若代理換了按鈕文字，也要確認目的地仍正確。若新增一張圖片，就要看比例與手機裁切，因為內容存在不等於讀者能正常理解。

表單則需要確認可見欄位、提示與提交後流程是否符合需求。測試時可以使用受控資料，並清楚知道是否會送出通知，避免把畫面確認變成對真實客戶的操作。

這些檢查不必每次都擴大到整站。先針對修改的頁面與共用部分驗收，若變更真的影響導覽或全域樣式，再把相關頁面納入，能更有效地找到問題。

### 發布後要怎麼知道讀者看到什麼？

發布完成後應重新開啟對外網址，確認文字、圖片與連結反映最新版本。因為編輯器內的預覽與公開網站是不同的觀察位置，不能只看到一個成功訊息就結束。

如果外部頁面與預期不同，可以先確認發布版本與快取，而不用急著重做整頁。保留變更摘要與分支，也有助於回查是哪一項更新造成差異。

對只要求草稿的任務，則應保持在草稿階段，交付可審閱的結果。把編輯、驗收與發布各自說清楚，團隊就比較不會因為一句含糊的「完成」而誤解網站狀態。

## 遠端 MCP 與舊版 External Agents，應該怎麼選？

官方把 Framer MCP 列為連接 AI 代理的建議方式，但也說舊版 External Agents 本機命令列方案仍受支援。因為功能尚未完全一致，現有流程不必只因新工具出現就立即搬遷。

以下依官方功能頁與入門指南，整理選擇差異。

| 比較項目 | Framer MCP | 舊版本機 CLI 橋接 |
| --- | --- | --- |
| 連接方式 | 相容客戶端連遠端服務 | 透過本機命令列橋接 |
| 編輯器是否要持續開啟 | 官方說不需要 | 依現有本機流程設定 |
| 功能涵蓋 | 官方建議的新連接方式 | 仍有部分額外工作流程，例如在地化 |
| 既有專案導入 | 可先從單頁修改開始 | 已穩定運作的流程可保留 |

如果工作主要是從熟悉的聊天工具更新頁面，新 MCP 比較容易開始。若團隊已依賴舊版在地化流程，則應先核對功能是否齊備，再決定遷移時間。

AI 的使用量也要看所用代理的方案或點數。因為網站工具與模型運算是不同部分，不能從 Framer MCP 能連線，就推定所有 AI 操作都免費或沒有額外成本。

對代理產品開發者而言，遠端連接也提供把 Framer 工作帶進自有產品的方向。但終端使用者仍須理解帳號權限與發布行為，所以介面應把即將操作的專案與範圍呈現清楚。

### 連不上時，先把原因縮到一個條件

官方入門指南把常見問題分成伺服器網址、客戶端能力、管理員限制與登入授權。這個順序能幫使用者逐項檢查，因為每個問題需要的修正不同，反覆重新安裝未必能解決。

例如客戶端不支援遠端連接時，帳號密碼正確也無法完成。如果只是登入頁面被提早關閉，則應接續授權。先辨認卡在哪一步，才能避免把正常專案誤當成故障來源。

專案定位也可以單獨驗證。讓代理只讀取一個你熟悉的頁面標題，再回報所在專案，能快速確認連線對象，接著才安排編輯，減少選到同名測試站的機會。

如果團隊使用多個 AI 客戶端，則應各自確認連接的網站帳號。因為代理沿用連線帳號權限，同一個人在不同工具裡登入不同帳號，可能看到不同的專案集合。

這些確認可以留成簡短操作紀錄，日後換人或換工具時直接重用。紀錄應說明連接方式與專案範圍，不保存密碼或機密憑證，讓團隊能接手流程，也保留帳號管理的清楚界線。

## 已用 Framer 的團隊，可以先做一頁受限試改

這次更新最直接的使用者，是已經有 Framer 網站，又希望把內容修改接到現有 AI 工作流程的人。因為成果仍留在原生專案，設計師可以接著調整，減少不同檔案之間的交接。

第一次可以先選一頁、只改已定稿內容，並要求保留分支與預覽。等帳號定位、修改與回讀都順利，再擴大到集合或共用元件，也可免費訂閱 AI 郵報持續追蹤工具更新。

## FAQ：Framer MCP 常見問題

### Framer MCP 需要一直開著編輯器嗎？

官方說明不需要。代理可以透過遠端連線工作，你在要檢查或調整結果時再打開專案。

### 代理會不會直接改到公開網站？

變更預設留在專案，但代理在明確要求下可以發布。因此任務應說明這次是草稿修改，還是已授權正式發布。

### 可以立刻取代所有舊版 CLI 工作流程嗎？

官方仍保留舊版本機方案，且指出在地化等部分工作流程有額外支援。遷移前應依實際需求核對。
