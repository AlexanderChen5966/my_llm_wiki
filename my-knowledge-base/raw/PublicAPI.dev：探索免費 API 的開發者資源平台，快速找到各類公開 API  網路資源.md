網站連結 [https://publicapi.dev/](https://publicapi.dev/)

PublicAPI.dev 是一個專門收錄免費公開 API（Public API）的線上平台，提供開發者快速搜尋、瀏覽與比較各種類型的 API 服務。無論是天氣、金融、人工智慧、新聞、地圖、圖片、影音、電子郵件，還是遊戲與社群媒體等領域，都能透過平台集中查詢相關 API，減少自行搜尋官方文件或逐一比較服務的時間。

相較於一般搜尋引擎需要輸入關鍵字尋找 API，PublicAPI.dev 更像是一個 API 目錄（API Directory）。平台會整理每個 API 的用途、分類、驗證方式、官方文件、HTTPS 支援情況與其他基本資訊，方便開發者快速判斷是否符合專案需求。對於剛開始開發新產品、尋找第三方服務或學習 API 串接的使用者來說，是相當實用的參考資源。

PublicAPI.dev 採用分類式瀏覽方式，使用者可依照應用領域快速查找需要的 API，例如 AI、商業、金融、健康、教育、娛樂、天氣、地圖、電子商務等，也可直接透過搜尋功能輸入關鍵字，快速找到相關服務。每個 API 頁面通常都會提供官方網站、說明文件、授權方式以及是否需要 API Key 等資訊，方便開發前先了解使用門檻。

平台提供的主要功能包括：

- 收錄大量免費公開 API
- 依照主題與分類快速瀏覽
- 提供 API 搜尋功能
- 整理官方文件與網站連結
- 標示是否需要 API Key
- 顯示 HTTPS 支援狀況
- 協助比較不同 API 服務

其中一項特色是將 API 依照不同應用情境分類，而非僅以公司名稱排列。例如想開發聊天機器人，可直接瀏覽 AI 類別；若要製作旅遊網站，可查看地圖、交通或天氣相關 API；若需要付款、金融或匯率功能，也能快速找到對應服務。這種分類方式能降低開發者尋找資源的時間成本。

除了 API 基本資訊外，PublicAPI.dev 也會整理各項服務的使用方式與官方文件入口，方便使用者直接前往閱讀完整技術文件。由於平台本身並非 API 提供者，因此主要扮演資訊整理與導覽角色，協助開發者快速找到合適的官方資源，而不是提供 API 測試或管理功能。

整理 PublicAPI.dev 的特色，可歸納為以下幾點：

- 集中收錄各類免費 Public API
- 涵蓋 AI、金融、天氣、新聞、地圖等多元分類
- 提供 API 搜尋與分類瀏覽
- 整理官方文件與開發資源
- 標示 API 驗證方式與 HTTPS 支援
- 適合快速尋找第三方服務

從使用情境來看，PublicAPI.dev 適合各種開發需求。例如網站開發者可尋找天氣或地圖 API；App 開發者可快速比較通知、電子郵件或支付服務；AI 開發者則能探索大型語言模型、圖片生成或語音辨識相關 API。對學生、教學課程與初學者而言，也能透過平台了解不同 API 的用途，作為學習 REST API 與第三方服務整合的起點。

若與 RapidAPI 相比，兩者都提供 API 資源整理，但定位有所不同。RapidAPI 本身提供 API Marketplace、金鑰管理、測試工具與統一計費等功能；PublicAPI.dev 則偏向 API 索引平台，專注整理公開 API 與官方資源，讓使用者依需求前往各自的官方網站申請與使用。若只是尋找可用的免費 API，PublicAPI.dev 的介面相對簡潔，也較容易快速瀏覽不同領域的服務。

對於需要建立新專案或尋找替代方案的開發者而言，PublicAPI.dev 也能作為探索工具。當某項 API 停止服務或價格調整時，可透過平台搜尋相同分類的其他服務，快速找到替代選項，減少重新搜尋資料的時間。

整體而言，PublicAPI.dev 是一個以公開 API 資源整理為核心的開發者平台，透過分類、搜尋與官方文件整理，協助開發者快速找到合適的第三方 API。雖然平台本身不提供 API 託管或測試功能，但作為探索免費 API、比較不同服務與建立開發資源清單的入口，仍具有相當高的實用價值。無論是個人開發者、學生、技術團隊或新創公司，都能利用 PublicAPI.dev 加快前期技術選型與資源搜尋流程。
