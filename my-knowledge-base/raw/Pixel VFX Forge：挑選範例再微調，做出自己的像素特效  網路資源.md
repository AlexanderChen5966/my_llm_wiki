Pixel VFX Forge 是一個讓使用者自行客製化像素特效的互動網站。它提供火焰、斬擊、魔法、命中回饋和環境效果等範例，也能從文字描述混合出效果；更重要的是，你可以繼續調整顏色、輪廓、像素質感、圖層和動畫節奏，讓特效符合自己的遊戲美術風格。

## 從範例出發，逐步調成自己的效果

網站內建 42 種效果，可依戰鬥、魔法、元素、回饋與環境類別瀏覽或搜尋。選好範例後，可在角色畫面上預覽，也可切換成僅顯示特效。若想從不同構想開始，也能輸入文字描述混合效果，再把結果當作初稿繼續編修。這讓創作者可以先快速試出方向，再透過多個控制項逐步塑形，而不是只能接受一次生成的結果。

客製選項涵蓋特效主色與色相、PICO-8 或 Game Boy 等色盤、外框形式、抖色程度與雜點清理；動畫可調整影格數、播放速度、無縫循環與隨機種子。畫布尺寸能縮放，特效也拆成煙霧、火球、粒子與閃光等圖層，方便分別檢視與調整。這些設定適合用來統一整款遊戲的像素風格，或比較同一特效的不同版本。

## 預覽完成後，匯出多種素材格式

特效可以匯出為 MP4，並選擇橫式、方形或直式比例；也能輸出透明背景 GIF、放大後依然清晰的動畫，或由影格組成的 PNG Sprite Sheet。ZIP 遊戲素材包則包含 Sprite Sheet、單張影格、GIF、JSON atlas、Godot 4 SpriteFrames 和特效配方。使用者可依自己的工作流程，選擇適合社群展示、遊戲引擎匯入或後續編輯的格式。

每個特效還能以 JSON 配方複製與載入，保留設定方便重現、分享給團隊，或交由支援的 AI 代理延續編修。因此它適合獨立遊戲開發者、像素美術創作者，以及想快速試做遊戲視覺效果的原型團隊。

## 使用前可先確認的事

Pixel VFX Forge 是 Scenario 的探索作品；「Create yours」會帶到 Scenario 平台，建立自己的探索作品可能需依平台帳戶與方案操作。網站提供預覽與素材輸出，但實際匯入遊戲時仍應確認影格尺寸、原點、播放方式與目標引擎的設定。若要將輸出素材用於商業專案，請先查看 Scenario 當前的授權與平台條款。頁面另提供 [Scenario Skills](https://github.com/scenario-labs/skills) 及 Agent skill 下載入口，供想把特效編輯流程接入代理工具的人參考。

如果你想快速嘗試不同像素效果，並親自控制配色、細節和動畫呈現，Pixel VFX Forge 把效果範例、客製化編輯、即時預覽與多格式匯出集中在同一個工作台，能協助你更快找到符合作品風格的版本。
