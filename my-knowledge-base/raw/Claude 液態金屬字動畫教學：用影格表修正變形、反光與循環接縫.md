液態金屬字動畫最難的往往是變形過程和最後接回開頭。只看一張漂亮截圖，無法知道字母會不會突然跳出來，或循環時出現明顯斷點。

Florence 的公開實驗把初始需求與多次修改一起留下，因此能看見一支動畫如何從可播放變成比較連續的作品。這比只展示第一版，更適合拿來學修稿。

這篇聚焦形變階段、反光與接縫。下面的需求採用不同文字與時長，由本站改寫，沒有複製作者的長篇 prompt。

## 液態金屬字動畫公開實驗讓人看到哪些修改？

[Florence 的長文](https://x.com/flxrnc/status/2105311836190978392?ref=aiposthub.com) 描述金屬團塊、液滴、字母與回到團塊的循環，並留下針對材質、字形和過渡的修改紀錄。

其中有些問題在靜態圖上不容易看出，例如轉場途中冒出突起、亮光蓋住字母，或物件移到畫面外。逐格查看，是為了找出這些發生在中間的錯誤。

若製作用到 Three.js 這類在網頁繪製 3D 畫面的工具，應對照 [官方文件](https://threejs.org/docs/?ref=aiposthub.com) 確認版本與參數。文章裡提到的某個版本問題，不應直接當成所有版本的通用修法。

## 先把循環分成可以核對的階段

把「液態字」拆成形變表，就能要求代理在各階段交出畫面，而不是等整片完成才判斷。

| 階段 | 需要確認的狀態 |
| --- | --- |
| 開頭 | 團塊的形狀與移動方向 |
| 分離 | 液滴如何從主體離開 |
| 成字 | 各部分如何組成可閱讀字母 |
| 回收 | 字母如何回到下一輪的開頭 |

先做沒有聲音的視覺循環，再加音效。如果畫面還在調整，先精修聲音可能會在下一次改時間時全部重對。

## 可複製的液態字需求

在可保存動畫原始檔的程式專案中送出需求，先指定工具版本並輸出關鍵影格。若只有聊天文字回覆，就還沒有完成動畫製作。

以下為本站改寫，非原作者逐字 prompt，尚未做成片實測。

```
製作一支 8 秒可循環的液態金屬字動畫，文字為「FLOW」。
先列出使用的繪圖工具與固定版本，再給形變時間表。
開頭是一個流動團塊，分出液滴後形成四個可閱讀字母。
字母停留後逐步融回團塊，最後的運動要接到下一輪。
先輸出各階段關鍵影格與轉場附近的連續影格。
反光不能蓋住字形，任何物件都不可無故跳出或消失。
視覺循環確認後才加聲音，交付影片與可修改專案。
```

## 用正常速度與逐格檢查不同的問題

正常速度適合看節奏與文字是否讀得到；逐格則適合找突然跳動、接觸錯誤與形狀穿透。兩者都要看，因為逐格順暢也可能整體太慢。

再把影片連播幾次。如果每到同一位置都像重新啟動，就要檢查最後和最初的形狀、速度及方向，而不只是兩張圖是否相似。

### 金屬感只要把材質設成銀色嗎？

反光與環境會影響金屬的辨識。若看起來像白色塑膠，應檢查光線與反射，而不只是把顏色調得更亮。

### 能直接把原文參數貼進所有版本嗎？

不建議。先確認工具版本與參數意義，再用一個短片段驗證，避免舊版修法造成新的問題。

先把字母讀得清楚、形變接得連續，再增加材質與聲音細節，會比較容易知道每次修改解決了什麼。
