Claude Academy 是 Anthropic 建立的官方學習平台，提供 Claude 使用方法、AI 基礎知識、Claude Code、Claude Platform、API、MCP（Model Context Protocol）與 AI Fluency 等課程。它不只是簡單的產品說明文件，而是把學習內容整理成 Course、Tutorial 與 Use Case，部分完整課程還包含 Quiz、學習時數與 Completion Badge，適合從第一次接觸 Claude 的一般使用者，一路學到建立 AI 應用的開發者。

Claude Academy 與一般第三方 Prompt 教學網站最大的差異，在於內容直接圍繞 Anthropic 自家的產品與方法論。除了教使用者怎麼下 Prompt，也會說明 Claude.ai、Claude Code、Claude Cowork、Claude Platform，以及 MCP、Agent Skills、Subagents 等較進階的開發主題；另一條學習路線則是 AI Fluency，著重如何理解生成式 AI 的能力、限制與正確協作方式。官方首頁因此把服務定位涵蓋到「正在探索 AI」、「剛開始使用 Claude」以及「準備在團隊導入 Claude」等不同族群。

目前 Claude Academy 的內容可以從產品與能力兩個方向理解。產品方面涵蓋 Claude.ai、Claude Cowork、Claude Code、@Claude 與 Claude Platform；AI 基礎方面則提供 AI Fluency 系列。對一般使用者來說，可以從 Claude 101 開始；程式開發者則可以直接進入 Claude Code 101、Claude Platform 101、MCP 或 Claude API 課程。

目前比較主要的完整課程包括：

- Claude 101：13 堂課、1 次測驗，約 2.5 小時
- Claude Code 101：12 堂課、1 次測驗，約 1 小時
- Claude Code in Action：9 堂課、1 次測驗，約 1 小時
- Introduction to Claude Cowork：14 堂課、1 次測驗，約 2.5 小時
- Claude Platform 101：13 堂課、1 次測驗，約 1.5 小時
- Introduction to Model Context Protocol：10 堂課、1 次測驗，約 1 小時
- Model Context Protocol: Advanced Topics：11 堂課、1 次測驗，約 1.5 小時
- Introduction to subagents：4 堂課，約 45 分鐘
- Introduction to agent skills：6 堂課，約 1 小時
- AI Fluency: Framework & Foundations：14 堂課、1 次測驗，約 4 小時
- AI Capabilities and Limitations：13 堂課、1 次測驗，約 3.5 小時
- Building with the Claude API：67 堂課、8 次測驗，約 9 小時。

如果是第一次使用 Claude，Claude 101 是比較直接的起點。官方課程從第一次與 Claude 對話、有效 Prompting 開始，接著涵蓋 Projects、Artifacts、Skills 與 Connected Tools。這條路線不是要求使用者具備程式背景，而是先學會如何把 Claude放進日常工作，例如思考問題、撰寫文件與分析資料。

Claude Academy 另一個值得注意的地方，是目前已經投入不少內容介紹 Claude Code。除了基礎的 Claude Code 101，還有 Claude Code in Action，以及 Skills、Subagents 等獨立課程與教學。官方對 Claude Code 101 的定位是學習這項 Agentic Coding Tool 的運作方式與核心工作流程；進一步的 Claude Code in Action 則聚焦如何控制、設定、自動化與驗證較長時間、較少人工介入的 Coding Agent 工作。

對近期開始使用 Claude Code Skills 的人，Academy 也有獨立的 Introduction to agent skills。課程會從建立第一個 Skill 開始，延伸到設定、多檔案 Skill、團隊分享與 Troubleshooting。官方對 Skill 的定義是可重複使用的 Markdown Instructions，Claude Code 會在符合任務時自動套用。這比只閱讀一份 Skill 規格文件更接近循序學習。

Subagents 則有另一套 Introduction to subagents 課程，重點是如何把複雜任務拆給多個 Claude Subagent 平行處理，以及如何進行較具確定性的 Orchestration。對已經不只把 Claude Code 當成「幫我修改一個檔案」工具，而是開始建立 Agent Workflow 的開發者，Skills 與 Subagents 會是值得接著學的兩個方向。

MCP 也占了 Claude Academy 相當重要的位置。Introduction to Model Context Protocol 會使用 Python SDK，從頭建立 MCP Server 與 Client，並涵蓋 Tools、Resources、Prompts 三項核心 Primitive；完成基礎內容後，還能繼續學 Advanced Topics，接觸 Sampling、Notifications 與 Roots 等協定機制。

如果目標是直接開發 Claude 應用，則可以從 Claude Platform 101 往 Building with the Claude API 前進。後者目前有 67 堂課、8 次 Quiz，約需 9 小時，內容範圍已經從 Prompting 延伸到 Tool Use、RAG、Agents、MCP 與 Production Patterns。對需要在正式產品中使用 Claude API 的工程師來說，這比只學基本 API Request 完整許多。

企業若使用不同雲端環境，也有專門路線。Claude with Amazon Bedrock 約 8 小時，內容包含 API、Tool Use、RAG、Agents 與 AWS Production Deployment；Claude with Google Cloud's Vertex AI 則約 8.5 小時，針對 Vertex AI 環境說明相同類型的開發與正式部署問題。

Claude Academy 並沒有把所有內容都做成長課程。Tutorials 區域提供大量數分鐘即可完成的短篇教材，例如 Getting started with Claude.ai、Intro to Projects、Getting started with connectors，以及 Claude Code Skills 的建立、設定、分享與除錯。網站目前還有 Claude Cowork、Claude in Excel、Claude in PowerPoint、Claude in Chrome、Claude Security 等不同產品或使用情境的短篇教學。

這種內容安排很適合「遇到問題再學」。如果只是想知道 Skill 是什麼，可以先看約 3 分鐘的 Tutorial；確定要正式建立自己的 Skills，再投入約一小時完成 Introduction to agent skills。相較於所有內容都塞進十幾小時的大課程，這種 Course + Tutorial 的結構比較容易依需求選擇。

另一條相當完整的主線是 AI Fluency。Anthropic 在 Academy 使用 4D Framework，分別是 Delegation、Description、Discernment 與 Diligence，用來說明如何有效率、負責任且安全地與 AI 協作。除了通用的 Framework & Foundations，還有針對 Builders、Educators、Students、Nonprofits、Small Businesses 與 pK–12 教育工作者設計的版本。

如果不想只學「怎麼把 Prompt 寫得更好」，AI Capabilities and Limitations 會更有參考價值。這門課從 Next Token Prediction、Knowledge、Working Memory 與 Steerability 四個面向建立生成式 AI 的心智模型，並說明 Knowledge Cutoff、Context Window、模型可能產生不實資訊，以及什麼時候應該使用 Web Search、Retrieval 或其他工具補足模型限制。

這也讓 Claude Academy 與一般 AI Prompt 課程有所區隔。它沒有把所有問題都歸結成「Prompt 寫得不夠好」，而是要求使用者先判斷問題到底來自模型知識不足、工作記憶限制、Steerability，還是生成機制本身。當輸出不理想時，再針對真正原因修改工作方式。

目前網站還提供 Use Cases，定位比課程更偏實戰。例如可以學習如何準備一週工作、比較不同供應商 Proposal、把研究內容整理成 Presentation，甚至建立自己的 Portfolio Website。對不想先完整上完一套課，而是希望直接看 Claude 可以怎麼應用在工作上的使用者，這種案例式內容會比較容易開始。

從學習路線來看，如果完全沒有 Claude 經驗，可以先從 Claude 101 開始，再補 AI Fluency 與 AI Capabilities and Limitations；平常以程式開發為主，則可以走 Claude Code 101 → Claude Code in Action → Agent Skills／Subagents → MCP。若目標是建立正式 AI 產品，可以改走 Claude Platform 101 → Building with the Claude API → MCP，再依公司的雲端環境補 Amazon Bedrock 或 Vertex AI。

對企業與教育單位而言，Claude Academy 的價值則不只是個人自學。平台同時提供 Teaching AI Fluency、教育工作者課程以及 Small Businesses、Nonprofits 等不同職業情境內容，因此可以作為團隊建立共同 AI 基礎知識的教材，而不必讓每個人自行在網路上尋找品質不一的教學。

整體而言，Claude Academy 可以理解成 Anthropic 把原本分散的「產品教學、AI 素養與開發者教育」集中後建立的官方學習入口。初學者可以從 Claude 101 與短篇 Tutorial 開始，進階使用者能學 Claude Code、Skills、Subagents 與 Cowork，開發者則有 API、MCP、Bedrock 與 Vertex AI 等完整路線。尤其 Claude 產品與 Agent 功能更新速度很快，直接使用官方 Academy 的好處，是比較容易按照目前 Anthropic 實際提供的產品與工作方式建立學習路線。
