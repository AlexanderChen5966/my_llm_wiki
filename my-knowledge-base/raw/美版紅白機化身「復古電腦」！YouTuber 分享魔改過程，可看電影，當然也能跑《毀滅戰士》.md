就在最近，一名 YouTuber 成功將任天堂旗下經典主機 NES (美版紅白機) 改造成了一台功能完整的「復古電腦」，不僅支援了鍵盤和滑鼠的操作，甚至還能連上網路，或播放 DVD ，當然，絕對不能忘記的一點，就是這個裝置能夠執行 1993 年經典射擊遊戲《毀滅戰士》。

![美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達](https://www.kocpc.com.tw/wp-content/uploads/2026/10/20261029142520_0_088087.png "美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達")

最初於 1985 年推出的 NES 奠定了任天堂在歐美遊戲市場的地位，同時也是《超級瑪利歐》以及《薩爾達傳說》等超經典 IP 的起點，可以確定的是，這台主機當初的設計並不是一台桌上電腦，但這似乎完全無法阻止科技 YouTuber「Throaty Mumbo」嘗試為這台傳奇主機展開一場大改造。

![](https://www.youtube.com/watch?v=o0s7tRcqsOs)

在這支長達 55 分鐘的 YouTube 影片中，這名創作者半開玩笑地表示自己「玩膩了電玩遊戲」，所以想把 NES 改造成一台接近 90 年代水平的家用電腦設備。有趣的是，在臺灣玩家社群被稱為「紅白機」的日本原版 NES 正式的名稱其實是 Famicom，而其真正的全稱為「Family Computer」(家庭電腦)，因此，這項企劃某方面來說也讓這台主機真正呼應了原本的名稱。

然而，這項被 Throaty Mumbo 稱為「NESPC」的改造計劃處處充滿了各種挑戰。在最初的嘗試中，Mumbo 先嘗試了在裝置上安裝修改版的 Windows 98 系統，但實際操作上出現了大量的故障問題，隨後他又嘗試了以 Linux 為基底的模擬作業系統，結果在執行上遭遇了嚴重的卡頓。

![美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達](https://www.kocpc.com.tw/wp-content/uploads/2026/10/20261029142513_0_c18a19.png "美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達")

經歷了各種失敗嘗試後，他最後決定自行開發一套參考了 Windows 設計的客製化桌面環境，並搭配 EverDrive N8 Pro 卡匣及其內建的 FPGA (現場可程式化閘陣列)。這套額外硬體能夠處理需求較高的 x86 指令運算，同時繞過 NES 原本的 CPU。

最終他利用這種方式成功模擬出了經典的 Windows 98 操作環境，重現開始功能表、檔案管理員、資源回收桶等功能，甚至連內建的《踩地雷》遊戲的沒有漏掉。不僅如此，Mumbo 還自行製作了專用的 USB 轉接器，讓這台「NES PC」裝置能夠支援鍵盤與滑鼠操作，同時還加入了 MIDI 鍵盤，讓使用者可以進行音樂創作。然而，他的改造計畫還沒有完全結束。

![美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達](https://www.kocpc.com.tw/wp-content/uploads/2026/10/20261029142518_0_a4bc39.png "美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達")

透過先前開發的 NESCD 周邊配件，Mumbo 成功為這台裝置加入了播放 CD 與 DVD 的功能，並展示了播放 2000 年代 Adult Swim 成人動畫系列《Aqua Teen Hunger Force》的一集，即使畫面以極度粗糙，但也因此呈現出一種有趣的復古風格。

另一方面，這台裝置也能連上 Wi-Fi 並瀏覽各種網站，像是維基百科與 YouTube 等，但可想而知的是，影片播放的畫質當然稱不上清晰，但對於一台 40 年前推出的主機來說，這已經是一項非常不可思議的成就。此外，這台裝置還能自訂桌面，啟動各種螢幕保護程式，並遊玩《寶可夢》系列等 GameBoy 遊戲，而作為一台能連上螢幕的裝置，當然不會忘記《毀滅戰士》。

![美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達](https://www.kocpc.com.tw/wp-content/uploads/2026/10/20261029142511_0_ceeedc.png "美版紅白機化身「復古電腦」！YouTuber 分享魔改過程，可看電影，當然也能跑《毀滅戰士》 - 電腦王阿達")

在影片的尾聲，Mumbo 展示了這台裝置運行《毀滅戰士》的畫面，為這款1993 年經典射擊遊戲「什麼都能跑」的傳奇再次計上了新的一筆。而雖然 NES 主機的圖形處理能力相當有限，而遊戲畫面偶爾也會出現一些錯誤與異常，但在卡匣額外硬體的協助下，這款作品仍然得以運作。

以目前來說，Mumbo 已經將 NESPC 專案公開上傳至 GitHub，讓任何有能力挑戰這項改造工程的網友們都能取得相關檔案並嘗試自行製作。
