科學研究包含閱讀、分析、寫作與實驗，這些工作使用 AI 的方式可能差很多。

Anthropic 在二〇二六年十一月五日公開研究，分析超過二十萬筆與科學任務相關的 Claude 工作對話。

結果顯示，資料分析與寫作特別常見，實體資料蒐集則較少交給模型處理。

這份資料記錄的是產品內的使用行為，還需要和問卷及研究時間估計一起理解。報告也試算 AI 普遍採用後可能節省多少時間，但那些數字依賴明確假設，和已經量到的研究成果增長有不同意義。

我認為它最有用的地方，是幫助研究團隊先挑選能檢查成果的小任務。要知道哪些流程值得嘗試，應先理解樣本如何形成，再把任務分布、學科差異與成本推估接起來看。

## 二十萬筆研究對話到底代表什麼？

報告的基本單位是一段產品工作對話，同一個人可以產生多段紀錄。主樣本涵蓋二〇二六年八月二日至九月三十日，共二十萬七千〇四十九筆與科學工作有關的工作階段。

其中十二萬八千九百一十四筆來自 Claude 對話或 Cowork，七萬八千一百三十五筆來自 Claude Code。

因此，樣本數描述產品內的活動量，無法直接換算成有多少位科學家採用 Claude。一個人處理同一個研究計畫，可能在不同日期開啟多次工作對話。反過來說，團隊也可能在產品之外完成大量研究工作，這些活動不會全部出現在資料裡。

解讀時把單位說清楚，才能避免把使用次數誤當成研究人口。

研究使用名為 SciNet 的分類架構，把工作放進七千二百六十二個任務、三十四個領域與三百一十八個子領域。分類模型依固定標籤辨識工作類型，再將彙整結果與研究時間估計比較。

這個方法能觀察哪些任務較常出現，但分類結果也有方法上的誤差，不能當成逐項由研究者本人確認的工作紀錄。

Anthropic 說明，這套分析以彙整分類為主，使用固定類別，並對帳號數較少的資料格設置限制。這是公司對分析方式的說明，我們沒有另行稽核其內部資料處理。

對讀者而言，重要的是研究回答了產品使用分布問題，尚未直接回答每項任務是否正確、節省多少分鐘或產出多少篇論文。

這也使它和隨機實驗不同。若想證明 AI 讓研究更快，通常還需要可比較的工作條件、時間紀錄與成果評估。這份報告提供大規模行為線索，可以協助形成下一步問題。知道樣本的單位與分類方式後，才能讀懂各類任務所占的比例。

## 研究者使用 Claude 分析與寫作的比例為何較高？

分析與寫作都有可交付的數位輸入與輸出，因而較容易出現在產品對話中。報告顯示，資料分析約占 Claude 科學工作對話的百分之三十三點七，在 Claude Code 則占百分之四十八點一。

研究估計這項工作約占一般研究時間的百分之二十七點六，顯示它在產品使用中相對突出。

寫作也有類似差異。在 Claude 對話中，寫作約占百分之三十二，而研究時間估計中的寫作比例約為百分之十六。這可以反映使用者常拿模型整理文字、修改表達或協助形成草稿，但不能從比例直接推論寫作時間減半。

對話的長短、難度與最後是否採用，都會影響實際效益。

相較之下，資料蒐集在 Claude 和 Claude Code 的比例分別約為百分之十一點五與十一點九，低於研究時間估計的百分之二十八點六。這個落差符合許多研究仍需實體操作、招募參與者或取得觀測資料的工作特性。

模型可以協助規劃與處理相關資訊，實體任務仍有自己的時間與資源需求。

提出想法的比例同樣需要謹慎解讀。報告中的構想任務約占 Claude 的百分之四點二，Claude Code 約百分之二點一，低於研究時間估計的百分之七點一。

這描述的是分類後的使用分布，不能單憑較低比例認定模型沒有創意，也不能把一次腦力激盪視為一項有效科學發現。

對研究團隊來說，這些差異可以轉成具體的試用問題。若目前大量時間用在資料清理，可以先比較模型產出的程式是否可重跑、是否保留原始資料，以及結果是否和人工基準一致。若主要負擔是寫作，則可以檢查文字是否準確表達證據。

這些使用差異也提醒團隊，應依學科工作形態選擇導入位置。

## 不同領域的研究者會遇到哪些差異？

程式密集的學科與需要實體實驗的學科，能交給模型的工作範圍不同。報告指出，電腦科學在 Claude Code 科學工作對話中的比例約為百分之三十二點七，而全球研究者領域分布中，電腦科學約占百分之四點三。

兩個分母不同，這個比較呈現使用傾向，並不是電腦科學研究者的採用率。

程式工具適合處理能在數位環境裡執行與檢查的工作，例如資料格式轉換、測試程式或整理運算結果。實驗室研究即使能用模型輔助分析，仍需要材料、儀器與操作。

當流程中有很長的實體等待時間，某一段程式變快，也不一定等比例縮短整個研究計畫。

報告另分析 Claude for Science 的補充資料。這部分和二十萬多筆主樣本分開處理，其中生物與生醫相關工作超過一半。

特定研究用途的入口會吸引不同的工作，因此不能把補充樣本的比例直接混入一般 Claude 或 Claude Code 的總體分布。

補充分析還比較不同工具中的自主執行程度。這類比較有配對領域與任務條件，特別是生物及生醫場景，不能把其中的高自主比例擴大成所有科學工作的整體自動化率。

一次工作階段中模型連續完成多個步驟，也不代表研究者已經把問題定義、成果審查與責任一併交出去。

研究同時訪問五百二十八位科學家，但受訪者較偏向積極使用 AI 的族群，且生命與健康領域較多。這能提供早期使用者的經驗，對整體研究人口的代表性仍有限。當工作範圍與樣本來源不同時，節省時間的推估也必須保留各學科的條件。

### 把使用傾向轉成可以驗證的研究問題

報告也用模型對任務能力的評估，檢查哪些工作更容易被使用者交給 Claude。這類分析可以觀察能力判斷與使用分布是否相關，仍不能單獨證明能力提高造成採用增加。使用者熟悉程度、可用資料與機構規則，都可能影響選擇。

例如，資料分析對話很多，可能因為這類工作確實能受益，也可能因為程式介面讓它比較容易留下紀錄。若研究團隊想了解自己的情況，可以先盤點每週固定工作，記錄哪些曾交給模型、哪些因資料或權限而無法使用，再比較時間與品質。

這份小型內部紀錄能補上大規模產品資料看不到的脈絡。

同樣地，少見的任務也不必立刻排除。某些構想工作可能只需一次短對話，就對後續研究產生影響。另一些看似繁忙的寫作對話，最後可能完全沒有被採用。任務次數、投入時間與成果價值分別衡量，才能避免用同一個比例代表三件事。

## 研究時間與產出倍數怎樣解讀？

報告用成本與時間假設建立情境，估算普遍採用可能釋出的研究時間。在當前能力廣泛採用的設定下，估計可節省的研究時間介於百分之二十七與五十二，中位數為百分之三十八。

固定預算下的研究產出估計約為原本的一點三五至二點〇二倍，依領域而不同。

這些倍數來自情境計算，並非追蹤研究團隊後觀察到的實際論文增長。研究要把節省時間換成額外成果，需要假定其他環節能跟上。

如果儀器時段、實驗材料或資料取得已經滿載，分析變快後可能只是更早進入等待，產出不會自動按相同比例增加。

成本設定也會影響結果。報告使用研究者每小時九十五美元、AI 每小時三十美元，且節省一小時人工作業需要〇點二小時 AI 使用的假設。這是一組模型參數，並非所有機構的實際工資或產品帳單。

學校、企業與不同地區的成本結構可能差異很大，讀者應把自己的條件代回去。

報告還討論更高程度自動化的情境，但這些設定並不等於公司承諾某個年份會交付完整自主研究產品。問卷中對未來年份的期待，反映受訪者的主觀判斷。

將可能情境與現況分開，才能保留報告的資訊價值，也避免讓預測掩蓋現在真正量到的使用行為。

我會特別注意推估未涵蓋的部分。研究品質、想法價值、儀器資源、機構審查與合作協調，都可能影響最後成果。較多文字或較多模型呼叫，無法直接替代這些工作。把推估還原為假設後，團隊就能用自己的時間紀錄檢查是否適用。

## 研究團隊如何設計第一個可檢查的試用？

第一個試用應先選能保留原始材料與評估標準的數位任務。例如已有人工確認的資料表，可以讓模型協助撰寫整理程式，再以固定輸入比較輸出。這樣才能知道它是否正確保留欄位、處理缺漏值，並重現原本的分析結果。

若選擇文獻整理，驗收重點就會不同。可以要求每個結論連到具體原文，檢查模型有沒有混淆研究族群、比較條件與限制。文字讀起來流暢只代表表達完成，研究者仍要核對引用是否真的支持這句話。

這項檢查時間也應列入成本，才能估算淨節省。

時間紀錄可以很簡單。先記人工完成同類任務所需時間，再記模型準備、等待、核對與修訂時間。對第一次使用的新工作，學習成本可能較高，最好和重複執行的任務分開觀察。

當流程穩定後，再比較幾次結果，會比只看一次順利展示更有說服力。

團隊還需要安排誰判斷研究問題、誰檢查程式與誰接受最終成果。模型可以在連續步驟中自主執行，研究決策仍需要有能理解證據的人負責。這對專業門檻高、錯誤不容易被發現的任務尤其重要。

這份 Anthropic 報告提供的線索，是科學工作裡有些數位任務已經大量進入 AI 工具。下一步應把使用經驗連回具體結果。將原始來源、模型產物與人工修訂一起保存，才有機會把使用次數轉成可評估的研究幫助。

## 常見問題

### Claude 二十萬筆對話是否代表二十萬位科學家？

沒有。研究單位是工作階段，同一個人可以有多次活動。資料也只涵蓋指定產品與期間，不能直接代表全球科學家總體採用情況。

### 報告是否證明 AI 已讓研究產出增加兩倍？

沒有。產出倍數是依成本、時間與普遍採用設定計算的情境。真實成果仍受設備、資料、研究品質與組織流程影響，需要另外評估。

### 最適合先試哪一種研究工作？

可優先考慮已有明確輸入、可重跑結果與人工基準的數位任務。先比較正確性與含核對時間的總成本，再決定是否擴大使用。
