網站連結 [https://www.designeer.xyz/](https://www.designeer.xyz/)

Designeer 是一個為設計師、前端工程師與設計工程師整理的網路資源目錄，將分散在各處的介面靈感、元件庫、開發工具、視覺資源與實用工具集中在同一個網站。它本身不是用來繪圖或寫程式的設計軟體，而是協助使用者找到合適參考、工具與學習資源的探索平台；特別適合在製作網站或產品介面時，需要同時考慮視覺設計、互動細節與前端實作的人。

網站目前將內容分成 Inspiration、Components、Build、Visuals、Utilities 五大類，另設有 Design Engineers 人物目錄。Inspiration 收錄介面與網站靈感來源；Components 聚集可用於專案的 UI 元件庫與設計系統；Build 涵蓋程式編輯器、AI 程式代理、MCP 工具與部署服務；Visuals 整理字體、色彩、3D、著色器與圖示等視覺素材；Utilities 則收納設計及開發過程中常用的小型工具。瀏覽者可以依分類探索，也能透過站內搜尋快速查找特定資源。

Designeer 的特色在於它以「設計與工程交會處」作為策展方向。網站不只收錄靜態的視覺參考，也整理能直接應用在製作流程中的元件、程式工具和 AI 資源，因此從尋找靈感到開始實作，都有機會在同一個目錄裡找到入口。官方表示，目錄不是單純由自動化程式大量抓取，而是會開啟、測試並評估資源；一般收錄不需付費購買排名，贊助內容則會清楚標示。使用者也可以提交工具或產品供團隊審核。

使用 Designeer 時，可以依手邊的工作情境來找資料：

- 製作網站前，先從 Inspiration 參考不同網站的版面與介面表現。
- 開始開發時，到 Components 尋找適合技術框架的元件或設計系統。
- 評估工作流程時，在 Build 查看程式編輯器、AI Agent、MCP 與部署相關服務。
- 調整視覺細節時，從 Visuals 找字體、配色、圖示或 3D 資源。
- 處理日常設計與開發需求時，再到 Utilities 尋找輔助工具。

官方資訊頁目前列出超過 422 項經策展的工具資源，以及 132 位設計工程師名錄，並表示目錄會持續加入新工具、版本更新與社群投稿。這類資源平台的價值在於縮短搜尋時間，但收錄不代表每項工具都適合所有專案；使用前仍應確認工具的價格、授權、技術相容性與維護狀況。整體而言，Designeer 適合需要定期尋找設計靈感、UI 元件、AI 開發工具或介面製作資源的設計師與開發者，也可作為探索設計工程領域新工具的入口。
