這幾天軟體圈最熱門的話題，大概就是 GitHub Copilot 丟出來的震撼彈了：今年六月開始，那個我們習慣的「月費吃到飽」要正式終結，全面改走「用量計費（Usage-based）」。


以前人家問我當工程師有什麼好處，我常開玩笑說：「至少生財工具很便宜，每個月花個幾百塊台幣訂閱 IDE 和 AI，就能生產幾百萬的產值。」

結果好日子沒過幾年，AI 吃到飽的時代就結束了。看著官方宣布的新機制，我心裡忍不住犯嘀咕： ****這年頭連寫個 Code，難道都要開始比誰的資本比較雄厚了嗎？****

本來以為這只是官方想多賺錢的防禦性政策，直到我自己去後台下載了今年 4 月份的真實用量報告（Preview Report），看完數據後，我差點把手上的咖啡噴出來。

---

## 驚悚實測：當我的 $39 帳單，變成 $443 美金...

先給大家看看我熱騰騰、血淋淋的後台模擬數據。

我目前使用的是每個月 ****$39 美金（Pro+）**** 的方案。原本過得安居樂業，結果系統用我 4 月份的真實開發行為去跑新制計費模型，跑出來的結果長這樣：

![vocus｜新世代的創作平台](https://resize-image.vocus.cc/resize?compression=6&norotation=true&url=https%3A%2F%2Fimages.vocus.cc%2F32dac4fd-2c8b-4ab0-a4e7-e87d30a5fd3a.png&width=740&sign=fH5LfSXWVX3n1wRPkEOT4T3S47fVvyLKAstUTjxz-N4) ![zoomable](https://images.vocus.cc/32dac4fd-2c8b-4ab0-a4e7-e87d30a5fd3a.png)

****「Your April 2026 usage would cost $404.73 more under usage-based billing.」****

是的，你沒看錯，我也沒看錯。如果直接切換成六月新制，我一整個月的消耗會高達 ****47,473 個 AICs（AI 點數）**** 。扣除掉方案內含的 $70 美金配額後，我還得額外支付 ****$404.73 美金**** 的超額費用。

原本一整個月固定付 $39 美金（約台幣 1,200 元）就能搞定的事，到了六月，我的總帳單會直接飆升到 ****$443.73 美金（折合台幣快要 15,000 元）**** ！

最幽默的是，GitHub 系統還非常「貼心」地在上面給了一行建議：

> **「大爺，要不要考慮升級到我們定價 $100 美金的全新 Max 方案啊？這樣可以幫你的月帳單省下 $69 美金喔！」**

謝謝你喔 GitHub，真是溫馨的周年慶百貨式推銷。就算我升級到 Max 方案，我每個月還是要付將近 $370 幾美金啊！看到這個數字，我才驚覺原來自己不是什麼普通工程師，原來我是算力黑洞、通膨的幕後推手。過去那些沒有靈魂的週五下午，習慣把一整份幾萬行的原始碼「啪」一聲丟進 Chat 視窗叫它找 Bug 兼重構， ****以後這種行為不叫寫 Code，叫作「財富自由」**** 。

## 隔壁棚的 Claude Code：突然變成了慈濟功德會？

看完了 Copilot 這張要命的預估帳單，再回頭看看最近在終端機裡紅透半邊天的另一個神器——Anthropic 的 ****Claude Code**** 。

同樣是面對 AI 算力變貴的殘酷現實，Anthropic 走的是另一種計費邏輯。它不跟你算點數扣到完，而是採用「滾動式容量限制（Capacity）」。

如果你訂閱了他們的 Max 20x 方案，一個月定價 $200 美金。它限制的是你「在每 5 小時內能消耗的 Token 上限」，時間過去、額度就會自動回補。

以前我覺得 Claude Code 一個月要收兩百美金（台幣六千多）簡直是搶錢； ****現在看了 Copilot 點數制噴掉我快一萬五台幣的報告後，我突然覺得 Anthropic 簡直是開佛心的慈善機構。**** 至少它幫我封頂了每個月的最高支出，我不用在月底收到帳單時心臟病發。

看到這兩邊的爭霸，我不禁陷入沉思：我賺了薪水，每個月要先付好幾千甚至上萬塊台幣給 AI 廠商當過路費，這到底是開源還是節流？以前我們總笑稱自己是「用肝換錢」，現在好了，變成要先「儲值」才能爆肝。

---

自嘲歸自嘲，日子還是要過，Code 還是要寫。面對這種計費架構的改變，我覺得做為一個務實的開發者，我們接下來必須養成兩個自保的習慣：

### 1\. 別再盲目餵 Context，優化你的 Prompt Big O

以前我們優化程式碼的執行效能，以後我們得優化自己的 Prompt。學會精準地選取片段代碼、只給必要的資訊。每一次你來一回的對話，你彷彿都能聽到瀏覽器背後傳來收銀機「叮」的一聲——那是你真實的美金正在融化。當 AI 開始精算我們的 Token，我們也得開始精算它的智商。

### 2\. 大任務與小任務分流（窮人流工作法~ ）

幸好，這次改制唯一算是有良心的地方，是 IDE 裡最常切換的「程式碼自動補全（Code Completions）」依然是無限次免費，不計入扣點。

所以日常寫 Code 時，繼續享用免費的自動補全；需要小聊天或抓錯字時，把 Chat 的模型手動切換成便宜、速度快的輕量模型（例如 Claude haiku 或 Gemini Flash），這部分幾乎不花成本。真正遇到跨檔案的複雜 Bug 或大架構重構時，再咬牙切換到高階模型或開啟 Claude Code 來處理。

## 以前比演算法，以後比誰會省 Token

講到底，AI 吃到飽終究是有極限的，畢竟算力背後都是實打實的電費和晶片成本。

以前我們去面試，主管看的是你的系統架構設計跟演算法實力； ****以後搞不好面試官會多問一題：「如果公司給你一個月 $50 美金的 AI 額度，你怎麼規劃你的 Token 消耗？有沒有把握不超標？」****

未來的優秀工程師，除了比拼 Coding 能力，可能還得比誰比較會調度 AI 資源，用最少的點數把問題解掉。
