同一個場景連續換畫風，觀眾仍能追蹤故事，是因為有熟悉的主體留在畫面裡。Tak 的藝術史短片，以人物和貓讓快速的風格變化有了觀看線索。

原作者貼文寫的是 Fable。這是一個可以學習連續性的使用案例，並非 Opus 5.5 的操作教學，也沒有在本次公開文字中提供完整 prompt。

本文保留原作與來源，下面另設計「同一座書桌穿越不同媒材」的分鏡練習。它適合想做風格比較或課程片頭的人，應以自己的構圖與素材練習。

## Fable 原作提供的是成片觀察線索

[Tak 的 X 原貼](https://x.com/cherry_mx_reds/status/2106095190285144331?ref=aiposthub.com) 描述了短時間跨越藝術史與貓的副線。觀看時可以注意，觀眾如何在畫風變化後重新辨認主角。

這些是從作品出發的觀察，不能反推作者用了哪套完整程式或生成流程。想了解後來有人如何以程式重建相關做法，可以另看 [花叔專案的來源致謝](https://github.com/alchaincyf/huashu-art-motion?ref=aiposthub.com) ，兩者的作者與成果應分清楚。

因此練習時先留下「有固定線索，再改變畫風」這個原則，不直接複製原作的角色與構圖。

## 替自己的題材保留不變的視覺線索

假設主題是閱讀，就讓同一盞燈、一本書和書桌位置留在畫面中。媒材可以從鉛筆變成剪紙，再變成水彩，但觀眾始終知道自己在看同一處。

分鏡可以這樣安排：

| 段落 | 改變與保留 |
| --- | --- |
| 鉛筆線稿 | 建立書桌、燈與翻頁動作 |
| 剪紙 | 保留構圖，讓書頁成為轉場入口 |
| 水彩 | 延續翻頁方向，改變筆觸與色彩 |

先只練三段，比一次放進很多風格更容易判斷哪裡失去連續。轉場時也要保留正在進行的動作，避免每幕都從完全靜止重新開始。

## 可複製的分鏡練習需求

這份文字可交給你能使用的動畫工具作為分鏡簡報，不限定某個 Fable 介面。先取得三張關鍵影格，再決定是否往影片製作。

以下是本站設計的不同題材練習，非 Tak 的原始 prompt，尚未做成片實測。

```
設計一段 12 秒的媒材變換動畫，主題是同一座閱讀書桌。
依序使用鉛筆線稿、剪紙與水彩，各自重新設計材質。
書桌位置、燈與書的相對關係保持一致。
主動作是一本書持續翻頁，翻頁方向跨場景連續。
先交三張關鍵影格與轉場說明，不直接生成完整成片。
使用自己的構圖，不沿用其他創作者的人物、動物與畫面。
完成後提供可比較的段落與素材來源。
```

## 風格換了，故事也要繼續

檢查時先只看主體的位置和動作方向。若每換一種畫風，書就移到另一處，觀眾會把注意力花在重新定位，無法感受到連續的變化。

再看每種媒材是否有自身的動態特徵。剪紙可以有紙片層次，水彩可以有顏料擴散；只換濾鏡，可能不足以表現媒材差異。

### 這篇提供 Fable 原作者的完整製作法嗎？

沒有。原貼提供成片與使用描述，本文區分作品觀察與本站練習，不把推測寫成作者實際步驟。

### 可以把這個想法套用在其他模型嗎？

可以把它當作創作需求嘗試，但模型與工具不同，結果不保證相同。先用幾張關鍵影格測試連續性即可。

先讓觀眾在三種風格中都認得同一個主體，再增加場景數量，會比一次追求跨越整部藝術史更容易掌握。
