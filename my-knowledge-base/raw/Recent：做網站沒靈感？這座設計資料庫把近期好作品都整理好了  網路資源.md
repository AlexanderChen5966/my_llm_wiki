網站連結 [https://recent.design/](https://recent.design/)

Recent 是一個專門蒐集優秀設計作品的靈感平台，定位是提供設計師、開發者與創意工作者一個經過人工策展的 Design Inspiration Feed。它不像一般社群平台需要從大量貼文中自己挖作品，而是強調 **Quality over Quantity** ，只收錄團隊認為值得參考的設計。

官方表示 Recent 最初在 2023 年成立，用來集中收藏 X 上的優秀設計；2026 年重新啟動後，來源擴展到 Instagram、網站與各種設計工具，同時正式接替 Godly，並把原本以網站為主的 Gallery 擴張到更廣泛的數位設計領域。

現在打開 Recent，可以直接按照設計類型瀏覽，主要包含：

- **Web** ：網站與 Landing Page 設計
- **Interface** ：Web App、產品介面與 UI 靈感
- **Branding** ：品牌識別與視覺系統
- **Product** ：數位產品設計
- **Typography** ：字體與排版案例
- **Motion** ：動態視覺與互動效果
- **Illustration / 3D** ：插畫與 3D 視覺
- **Editorial / Print / Packaging** ：編輯、印刷與包裝設計

如果只想找網站靈感，也有獨立的 Websites Gallery，可以按照 **AI、Agency、Portfolio、SaaS、Ecommerce、Startup、Technology、Finance、Education、Entertainment** 等類型篩選，因此在製作新網站前，可以很快找到同產業的視覺參考。

Recent 現在也不只有 Web Design。網站另外整理 **OG Images** 與 **App Store Screenshots** ，後者可以依 Business、Developer Tools、Finance、Games、Productivity、Travel 等 App 類型瀏覽。對正在設計產品上架頁、社群分享圖或品牌視覺的人來說，參考範圍比過去 Godly 更完整。

它和 Supahero 這類專門鎖定 Hero Section 的網站也有明顯差異。Supahero 適合解決「首頁第一屏怎麼設計」；Recent 更像一座 **綜合型設計策展資料庫** ，從完整網站、UI、品牌、字體到 Motion 都能一起研究。

對 AI Coding 與 Vibe Coding 使用者來說，Recent 也很適合當作 Prompt 前置研究工具。與其直接要求 AI「做一個漂亮的 SaaS 網站」，不如先從 Recent 找到幾個喜歡的 Layout、Typography、Color、Motion 與 Interface 案例，再拆解成具體的 Design Direction，生成結果通常會更容易控制。

另外 Recent 還整理了 Design Tools 與 Design Jobs，因此整體定位已經逐漸從單純的 Inspiration Gallery，發展成設計師探索作品、工具與工作機會的入口。

整體而言，Recent 可以理解成 **Godly 的擴大進化版** 。如果平常需要找 Landing Page、UI/UX、Branding、Typography、Motion 或 App Screenshot 靈感，又不想在社群平台的大量內容中慢慢篩選，Recent 強調人工策展與品質優先的方式，會是一個很適合定期打開瀏覽的設計靈感來源。
