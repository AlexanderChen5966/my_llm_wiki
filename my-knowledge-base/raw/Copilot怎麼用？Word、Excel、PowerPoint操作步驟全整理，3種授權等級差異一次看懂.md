主管突然說「以後報告先用 Copilot 處理」，打開 Word 卻找不到按鈕；或收到公司通知說帳號多了 Copilot，卻不確定能做什麼、能不能用。《經理人》整理 Word、Excel、Outlook、PowerPoint、Teams 5 個工具的具體操作步驟，供讀者參考。

### 目錄

## 開始之前：怎麼確認自己的 Copilot 授權等級

公司說要用 Copilot，實際上有 3 種不同等級，能做的事差很多：

| 授權標籤 | 說明 |
| --- | --- |
| Copilot Chat (Basic) | 沒有加購授權，無法直接在 Word、Excel、PowerPoint、OneNote 中使用 Copilot；仍可使用獨立的 Copilot Chat，以及符合資格訂閱所包含的 Outlook Copilot |
| M365 Copilot (Basic) | 沒有加購授權，但可在 Office 應用程式裡使用標準的 Copilot 功能 |
| M365 Copilot (Premium) | 公司加購授權，享有完整工作資料推理（讀取信件、會議、跨檔案資料）與優先存取 |

**怎麼查自己是哪一種：** 用工作或學校帳號登入 [m365.cloud.microsoft](https://m365.cloud.microsoft/) ，捲到首頁最下方，姓名下方會顯示上述其中一個標籤。這個方法比「看文件右下角有沒有按鈕」準確，因為按鈕位置可以被移到功能區，而且看到按鈕不代表你是哪一種等級。

**沒有加購授權（Basic）能做的事：** 在一般 Copilot Chat 中，Basic 等級沒有完整的工作資料推理能力（Work IQ），無法自動搜尋你所有可存取的信件、會議、聊天與檔案來回答問題；但 Outlook 內建的 Copilot Chat，以及公司另外設定的代理程式（可存取指定的 SharePoint 或連接器內容），是例外情境。若要 Copilot 全面整合這些工作資料，通常需要公司加購 Premium 授權。

**找不到 Copilot 功能時，依序檢查：**

1. 確認 Office 已更新到最新版本
2. 開啟任一 Microsoft 365 應用程式，點「檔案 > 帳戶 > 更新授權」，再關閉並重新啟動應用程式
3. 公司帳號使用者，確認更新通道不是「Semi-Annual 企業通道」（該通道不支援 Copilot），應切換為「目前通道」或「每月企業通道」
4. 點「檔案 > 帳戶 > 帳戶隱私權 > 管理設定」，確認「分析您內容的體驗」和「所有連線體驗」已開啟

剛拿到公司指派的新授權，功能生效可能需要一點時間。以上步驟都做過還是不行，建議直接請 IT 系統管理員協助確認授權與組織設定，原因不一定出在公司政策，也可能是登入帳號、版本或功能推送進度的問題。

## Copilot 在 Word 怎麼用

1. 開啟文件，點文件角落的 Copilot 動態動作按鈕
2. 聊天窗格會自動開啟，預設進入編輯模式
3. 輸入指令，或直接選擇建議動作

**能做的事：**

- 起草新內容：輸入提示描述想要的結果，例如「為業務團隊草擬新方案簡介，包含背景、優點、風險」
- 改寫既有段落：選取文字後點旁邊的 Copilot 圖示進行重寫、調整語氣
- 理解長文件：要求「幫我摘要這份文件的重點」「列出還沒解決的問題和待辦事項」

用「使用 Copilot 編輯」這個功能時，目前不支援串接外部工具。可用性也會因授權等級、訂閱類型、組織設定而有差異，介面顯示以實際畫面為準。

## Copilot 在 Excel 怎麼用

選取活頁簿 **右下角** 的 Copilot 圖示開啟。

**3 種模式：**

| 模式 | 用途 |
| --- | --- |
| 編輯模式（預設） | 直接修改活頁簿內容，適合多步驟任務 |
| 規劃模式 | 先產生計畫讓你確認，再執行 |
| 聊天模式 | 只分析資料、不修改工作表 |

**能做的事：** 新增刪除工作表、跨工作表套用公式、建立圖表與樞紐分析表、找出資料中的趨勢與異常值、排序篩選與條件式格式設定。開啟或關閉自動儲存都能使用。

手機和平板功能較精簡：官方目前列出 iPad 支援聊天與規劃模式（編輯模式陸續開放中），iPhone、Android 則為聊天模式。這部分官方頁面持續更新中，實際能用的模式請以當下畫面為準。

## Copilot 在 Outlook 怎麼用

**草擬新郵件：**

1. 首頁 > 新郵件
2. 工具列選 Copilot 圖示，下拉選單選「草稿」
3. 輸入提示詞，或直接選擇建議的提示
4. 點「生成」，檢閱內容並依需要調整長度、語氣，或重新生成
5. 滿意後選「保留它」，再編輯細節並送出

**改寫或回覆郵件：** 在訊息區點「幫助我寫作」或「幫助我回覆」，於聊天中互動修改。也可以選取已寫好的文字，點旁邊的 Copilot 圖示重寫。

**用聊天問問題：** 用工作或學校帳號登入，點應用程式上方的 Copilot 按鈕。Outlook 內建的 Copilot 聊天比較特別，即使帳號是 Basic 等級（沒有加購 Premium），也能有限度地存取信箱與行事曆，問「總結我上週跟某專案相關的信」「我下次和某人的會面是什麼時候」；但要做更複雜、整合多方資料的查詢，還是需要 Premium 等級授權。

在新版 Outlook 和網頁版 Outlook 中，如果郵件設定為純文字格式，Copilot 草擬功能無法使用，需要切換成 HTML 格式的郵件才能生成草稿。另外，截至 2026 年 7 月，傳統版 Outlook for Windows（20026.20182 以上版本）有已知問題，部分 Copilot Chat (Basic) 與 Premium 授權的使用者會發現 Copilot 按鈕從功能區上方或左側應用程式列消失。微軟建議暫時改用新版 Outlook 或網頁版 Outlook（OWA）繞過此問題。

## Copilot 在 PowerPoint 怎麼用

1. 開啟新簡報，點投影片右下角的副駕駛圖示
2. 聊天窗格點「新增內容」，下拉選單選「特工模式」
3. 輸入描述簡報內容的提示，送出
4. Copilot 可能會反問目標受眾、風格、圖片偏好等問題，可以回答或跳過，接著會先產生 **大綱**
5. 確認大綱方向沒問題後，再請 Copilot 依大綱產生完整投影片

也可以登入 m365.cloud.microsoft，直接告訴 Copilot「製作關於\[主題\]的簡報」，系統會在 OneDrive 產生檔案並提供連結。

目前一次只支援單一輸出語言，引用參考檔案時無法同時提供其他內容。調整簡報長度、語氣、風格、圖片偏好等控制項仍在逐步推出中，不同帳號看到的選項可能不同。官方也明確提醒，產生的內容應該經過人工審核與編輯後再使用。

## Copilot 在 Teams 會議怎麼用

**啟用方式：** 會議中從控制項選取 Copilot 圖示，再依提示開啟與 Copilot 的私人聊天。如果主辦人已在「會議選項 > Copilot 與其他 AI」中選擇「僅限會議期間」，且組織政策允許，即使沒有開啟轉錄或錄製，會議進行中仍可使用 Copilot；若設定為「會議期間及之後」，則必須啟動即時轉錄，Copilot 才能運作；設為「關閉」則無法使用。

**可以問的問題：**

- 「針對這個主題，我們哪裡有意見分歧？」
- 「\[某位參與者\] 對這個提案怎麼回應？」
- 「整理討論想法，做成含優缺點的表格」

**重點提醒：** 會議沒有開啟即時轉錄或錄製時，會議結束後就無法在「Recap」分頁回顧 Copilot 的內容；但這不代表對話紀錄完全消失——依公司的 Microsoft Purview 保留原則，提示與回應仍可能被保留在合規基礎架構中，供稽核或法遵調閱使用。

另外，Copilot 無法在外部組織主辦的會議中運作。匯出限制則有兩種獨立情況：如果會議套用的敏感度標籤不允許匯出內容，或會議開啟了「禁止複製與轉寄聊天、字幕及文字記錄」的選項，Copilot 的回應就無法匯出到 Word 或 Excel。

## 好用的指令（Prompt）範例整理

| 情境 | 可以怎麼下指令 |
| --- | --- |
| 寫報告草稿（Word） | 「為\[對象\]草擬\[主題\]的簡介，包含背景、優點、風險」 |
| 摘要長文件（Word） | 「摘要這份文件的重點，列出還沒解決的問題和待辦事項」 |
| 分析數據（Excel） | 「找出這份銷售資料裡的趨勢和異常值」 |
| 做圖表（Excel） | 「用這份資料做一個依月份分類的長條圖」 |
| 寫信（Outlook） | 「草擬一封信通知客戶專案延期，語氣保持專業但友善」 |
| 追會議進度（Outlook） | 「總結我上週跟\[專案名稱\]相關的信件」 |
| 做簡報（PowerPoint） | 「製作關於\[主題\]的簡報，目標受眾是\[對象\]」 |
| 回顧會議（Teams） | 「整理今天會議的討論重點，做成含優缺點的表格」 |

## 常見問題 FAQ

**Word、Excel、PowerPoint 都看不到 Copilot 按鈕，怎麼辦？**  
先確認 Office 已更新到最新版，再到「檔案 > 帳戶」更新授權並重啟應用程式。商務用戶另外確認更新通道不是 Semi-Annual 企業通道。都排除後還是不行，建議請公司 IT 系統管理員協助確認授權與設定。

**公司沒有加購 Premium 授權，代表完全不能用 Copilot 嗎？**  
不會，但功能會受限。沒有加購授權的 Basic 等級仍可以聊天、分析自己上傳或當下開啟的檔案；差別在於沒辦法自動整合信件、會議等工作資料。Outlook 是例外，即使是 Basic 等級也能有限度查詢信箱與行事曆。實際等級可以到 m365.cloud.microsoft 帳號頁面下方確認標籤。

**用 Copilot 處理公司文件，資料安全嗎？**  
Microsoft Copilot 的提示、回應及透過 Microsoft Graph 取得的資料，不會被用來訓練基礎模型。不過，微軟已於 2026 年 6 月 23 日將 OpenAI 加入 Microsoft Online Services 的次處理者名單，並自 7 月 9 日起提供部分由 OpenAI 營運的模型；自 7 月 24 日起，符合資格的商業客戶預設開放使用這些模型，除非公司 IT 系統管理員主動停用。也就是說，不是所有提示都一定會送給 OpenAI 處理，而是使用者多了可選用部分 OpenAI 營運模型的選項。若工作內容涉及機密或法遵敏感資料，建議先向公司 IT 確認目前可使用的模型與次處理者設定。

**Teams 會議如果沒開轉錄，事後還能看 Copilot 的對話紀錄嗎？**  
如果會議設定為「僅限會議期間」，會議中可以在不轉錄或錄製的情況下使用 Copilot，但結束後無法在「Recap」分頁回顧會議的 Copilot 內容。提示與回應仍可能依組織的 Microsoft Purview 保留政策留存在合規系統中，並非完全不留任何紀錄。若會議設定為「會議期間及之後」，則需要開啟即時轉錄，Copilot 才能運作。

**Copilot 幫忙做的簡報或報告，可以直接拿去用嗎？**  
官方建議產生的內容應該經過人工審核與編輯，尤其是數字、專有名詞和引用內容，建議再自行確認一次再對外使用。
