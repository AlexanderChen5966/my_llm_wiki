OpenAI 正式推出 **ChatGPT Images 2.5** ，新一代圖像模型進一步提升圖片生成品質、編輯精準度與生成速度，同時強化參考圖片的人物與主體一致性。除了模型本身升級之外，ChatGPT 也加入 **Sketch 草圖、圖片註解、創作範本與 Prompt 分享** 等新功能，讓 AI 圖像生成逐漸從單純的「文字生成圖片」，轉變成更完整的視覺創作與編輯工具。

根據 OpenAI 公布的數據，目前使用者每週透過 ChatGPT Images 與 API 中的 GPT-Image 模型，已經產生超過 **30 億張圖片** 。Images 2.5 則是在這個基礎上進一步改善細節、光影、材質、編輯與工作流程。

## ChatGPT Images 2.5 有哪些提升？

這次 Images 2.5 最核心的改進，可以歸納為 **畫質、速度、編輯精準度與一致性** 。

Images 2.5 能產生更加自然的光線與更豐富的材質細節，同時更擅長保留參考照片中的人物或其他主體特徵。當使用者提供一張參考圖片，再要求 AI 更換場景、服裝、構圖或視覺風格時，原本的人物與主體會更容易維持辨識度。

生成速度也有明顯改善。OpenAI 表示，與 Images 2.0 相比，Images 2.5 的 **圖片生成延遲最多降低 50%** ，因此從第一次生成到反覆修改圖片的整體流程都會更快。

## 參考圖片的人物一致性更好

使用 AI 圖像生成時，一個常見問題就是「參考圖明明是同一個人，生成之後卻變成另一張臉」。

Images 2.5 特別改善了這方面的表現。模型能更好地理解參考照片中的人物、地點與其他主體，當它們被放進新的環境、構圖或藝術風格時，原本具有辨識度的特徵更有機會被保留下來。

這項能力對需要建立固定 AI 角色、人物寫真、商品模特兒、品牌角色或系列圖片的使用者尤其重要，也讓透過 Reference Image 建立連續作品變得更加實用。

## 圖片編輯更加精準

另一項重要改進是 **Precision Editing（精準編輯）** 。

過去使用生成式 AI 修改圖片時，即使只要求「更換衣服」或「修改背景」，AI 有時也會順便改掉人物臉孔、姿勢、構圖甚至其他不相關的內容。

Images 2.5 更強調「 **只修改使用者要求修改的部分** 」。

例如只要求修改商品、背景或圖片中的文字時，模型會盡可能保留原本的主體、構圖與視覺風格。對商品圖、廣告素材、人物照片與品牌視覺設計來說，這會比每次重新生成整張圖片更加實用。

## 多輪修改也能維持圖片一致性

ChatGPT Images 2.5 同時改善 **Multi-turn Editing Consistency（多輪編輯一致性）** 。

使用者可以先生成圖片，再依序提出：

「把背景換成東京街頭」

「衣服改成黑色」

「手上增加一杯咖啡」

「其他地方都不要修改」

Images 2.5 在這類連續編輯過程中，更能保留前面已經完成的修改，並讓新的修改建立在上一個結果之上，而不是每修改一次就重新解讀整張圖片。

OpenAI 也特別強調，Images 2.5 在多次編輯後較能避免圖片品質逐漸劣化。對需要反覆微調圖片的實際創作流程來說，這可能是比單純提高一次生成畫質更重要的改進。

## 更懂複雜 Prompt 與視覺風格

Images 2.5 對複雜視覺指令的理解能力也有所提升。

當 Prompt 同時包含人物、位置、構圖、物件、文字、視覺層級與風格要求時，模型更能將這些條件整合成合理的畫面。

包含真實世界資訊的圖片內容準確度也有所改善，同時支援更複雜的版面設計與 **透明背景** 。在風格控制方面，Images 2.5 也更容易按照指定的藝術方向生成結果。

因此除了單純生成插畫或照片之外，它也更適合用來製作品牌素材、UI 概念圖、簡報視覺、社群素材與其他需要固定版面結構的圖片。

## 新增 Sketch：直接畫給 ChatGPT 看

這次 ChatGPT Images 2.5 同時帶來一項很有意思的新功能： **Sketch** 。

過去如果很難用文字描述構圖，通常只能上傳一張參考圖片；現在則可以 **直接在 ChatGPT 裡畫草圖** ，再讓 AI 根據草圖生成完整圖片。

例如可以簡單畫出房間配置、服裝輪廓、人物位置或其他構圖，再搭配文字描述想要的風格與細節，ChatGPT 就能將草圖轉換成完整圖像。

不需要具備專業繪畫能力，Sketch 的主要用途並不是畫出精美作品，而是讓使用者可以用最直覺的方式告訴 AI：「我要的東西大概放在這裡、長成這樣。」

在 ChatGPT 中輸入「@Sketch」即可開始使用這項功能。

## 加入圖片註解，直接指出「我要改這裡」

除了 Sketch 之外，ChatGPT 現在也支援直接在圖片上加入 **Comments（註解）** 。

使用者可以直接針對圖片中的特定位置留下修改要求，讓 AI 更清楚知道究竟要調整哪個區域。

這種操作方式讓圖片編輯更接近一般設計軟體的工作流程，也減少必須用文字描述「左上角那個物件」、「人物右手旁邊的位置」之類空間關係的麻煩。

## 新增 Poster、Merch 等創作範本

OpenAI 也替 ChatGPT Images 加入 **Templates（範本）** 。

當使用者不知道 Prompt 該如何開始時，可以直接選擇常見的創作類型，例如 \*\*Poster（海報）\*\*或 **Merch（周邊商品）** ，再填入需要傳達的資訊、設計元素與視覺風格。

這代表 ChatGPT Images 正逐漸從「Prompt 輸入框」走向更加結構化的圖像設計介面，讓不熟悉 Prompt Engineering 的使用者也能快速開始創作。

## 好用的 Prompt 現在也可以直接分享

如果產生了一張很滿意的圖片，現在分享圖片時也可以選擇 **一起分享產生這張圖片所使用的 Prompt** 。

其他人取得 Prompt 後，可以加入自己的照片、素材與條件，製作屬於自己的版本。

這讓 Prompt 本身變成一種可以分享與 Remix 的創作素材，也更容易形成類似社群挑戰、熱門圖片模板或迷因的傳播方式。

## API 推出 GPT-Image-2.5 Flare 與 Sunburst

這次升級並不限於 ChatGPT。

針對開發者，OpenAI 同時在 API 推出兩款新的 GPT-Image-2.5 模型：

**GPT-Image-2.5 Flare** 是大多數應用的預設選擇，主打品質、速度與成本之間的平衡。OpenAI 表示，相較 GPT-Image-2，它能提供更高品質的圖片，同時將延遲降低 **50%** ，適合社群內容、商品體驗、視覺搜尋、快速原型以及大量圖片生成等用途。

**GPT-Image-2.5 Sunburst** 則定位在要求更高的專業視覺工作流程，生成時間較長，但能提供更加精細的控制，適合正式廣告素材、高品質商品圖片，以及需要多次精準修改的創作工作。

簡單來說，可以理解成：

**Flare → 速度與品質兼顧，適合大多數應用**

**Sunburst → 更重視精準度與細節，適合高品質專業製作**

## AI 圖片的安全與來源辨識

在安全機制方面，ChatGPT Images 2.5 延續 OpenAI 既有的圖片安全措施，會針對 Prompt 與圖片進行檢查，以降低產生有害內容的可能性。

OpenAI 同時持續使用 **C2PA metadata** 與 **不可見浮水印** ，協助辨識由旗下 AI 工具產生的圖片。

## ChatGPT Images 2.5 已經開始推出

ChatGPT Images 2.5 已於 **2026 年 9 月 8 日** 開始推出，涵蓋 **ChatGPT、ChatGPT Work 與 Codex** ，並支援桌面版、行動裝置與網頁版，而且會提供給所有方案層級的使用者。

開發者則已經可以透過 API 使用 **GPT-Image-2.5 Flare** 與 **GPT-Image-2.5 Sunburst** 。

整體而言，ChatGPT Images 2.5 的重點已經不只是「生成出更漂亮的圖片」，而是開始解決 AI 圖像實際創作時最常遇到的幾個問題： **人物不像、改一個地方卻動到整張圖、多次修改後逐漸跑版，以及很難精確描述構圖。**

從參考圖片一致性、Precision Editing、多輪修改，到 Sketch、圖片註解與 Templates，可以看出 OpenAI 正在把 ChatGPT Images 從單次圖片生成工具，逐步發展成一套可以持續「生成 → 修改 → 微調 → 分享」的完整 AI 視覺創作環境。
