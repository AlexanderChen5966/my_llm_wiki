Claude101 是一個專門提供 Claude 學習資源的免費線上教學平台，目標是幫助使用者從零開始掌握 Claude 的各項功能與工作流程。網站以課程形式組織內容，從基礎 Prompt 撰寫到進階的 Claude Skills、Projects、團隊協作與 Claude Code 應用都有涵蓋，讓使用者能按照難度逐步學習。

與許多零散的 AI 教學文章不同，Claude101 採用結構化課程設計。網站將內容劃分為多個等級（Level），讓初學者可以依照學習進度逐步深入，而不是一次面對大量零碎資訊。

從首頁可以看到，目前課程大致分成不同階段：

- Claude 基礎認識
- Prompt 撰寫技巧
- Claude 認證準備
- Claude Cowork 工作模式
- 團隊協作應用
- Claude Design
- Projects 與知識管理
- Claude Skills 建立
- Claude Code 相關應用
- 進階工作流程優化

這些內容主要圍繞在如何把 Claude 變成實際工作夥伴，而不只是聊天機器人。

其中比較有特色的是網站強調實際工作情境。

例如除了介紹 Claude 本身之外，也涵蓋：

- 如何建立長期專案
- 如何管理工作記憶
- 如何建立可重複使用的 Skills
- 如何在團隊中導入 Claude
- 如何降低使用限制影響
- 如何改善 AI 回應品質

這類內容更接近實務操作，而非單純介紹功能按鈕。

從學習定位來看，Claude101 比較像是：

- Claude 使用指南
- Claude 工作流課程
- Claude 生產力訓練教材

而不是：

因此閱讀體驗也比較接近線上課程平台。

另一個值得注意的地方是，網站主打免費（Free Guides）。使用者不需要付費訂閱即可閱讀大部分內容，因此對剛接觸 Claude 的新手而言，算是相對低門檻的入門資源。

從適用族群來看，Claude101 特別適合：

- 剛開始接觸 Claude 的使用者
- 希望提升 Prompt 能力的人
- 想學習 Claude Skills 的開發者
- Claude Code 使用者
- 想建立 AI 工作流的團隊
- 希望系統化學習 Claude 的專業人士

尤其是已經使用 ChatGPT、Gemini 或其他 AI 工具，但還沒有深入了解 Claude 生態的人，可以透過網站快速建立完整觀念。

整體而言，Claude101 並不是一個技術新聞網站，而是一個以 Claude 為核心的免費學習平台。它透過階段式課程與實務教學，協助使用者從基礎 Prompt 撰寫一路進階到 Claude Skills、Projects、團隊協作與 Claude Code 工作流。對於想系統化掌握 Claude 的人來說，是目前相當完整的入門與進階資源之一。
