想了很多很多，但這個還是不得不提及啊，因為是所有程式的核心檔案。

在 Github 上所有...再強調一次 **「所有」** 破解 DRM 的相關開源軟體或腳本都繞不過這個 **核心** 的東西 【 CDM 】

如果是有在想辦法要解密的人應該都會看到 **【 CDM 】、【 device\_client\_id\_blob 】【 device\_private\_key 】** 和 **【 WVD 】** ，以上全部都是講同一個東西，但這樣東西是不會夾帶進檔案送給每個使用者的，一定都會要求大家自行準備好，有些開發者為了避免麻煩也不會明講，最多就是在空白處寫上 **懂得都懂** 來暗示檔案放置的路徑，畢竟要是提供是要吃官司的。

因此一些只想著下載、點擊 & 獲取的使用者就會在那邊哭腰說： **「這軟體沒用」、「這根本騙人的」** 或 **「我明明都按照教學了但根本無法使用」** 等等...理由一大堆，那是因為你沒有在 **指定的資料夾** 內放上最重要的 **核心檔案** 當然不會有用啊。

Chrome自帶的翻譯很好用，雖然翻譯結果爛，但多多少少還是能看得懂吧？何況有時候很多超重要的 P.S. 大大方方擺在那不看，出問題再來留低能留言？如果你是文章作者你會想理他？

好像扯遠了，現在問題就來了，當各位去網路上找尋的時候你也找不到，因為不會有人那麼好心的送給大家使用的，畢竟要獲取一次那麼麻煩，誰願意平白無故送人使用啊。( 如果有找到那代表恭喜你通過第一關，來~第二關，測試檔案還能不能用 )

---

獲取的方法有兩種：

1. 經過 Root 之後的 Android手機
2. Android Studio 提取

---

現在這時代誰跟你 Root 又不是還在 三星S2、S3的時代，一鍵 Root 那麼方便，就算 Root 還要跟銀行App玩貓抓老鼠，想想就煩，因此我在此提供怎麼使用 Android Studio 提取【 CDM 】的方法。

不過基於技術問題我們所能提取到的檔案等級也只能到【 L3 】，簡單易懂的說法就是如果你想要用來解鎖串流平台諸如 Netfilx、HBO 的 1080p、2K 或 4K 的影片那是不可能的，要到達那種等級必須要是【 L1 】等級才行。

你問說微軟的 PlayReady 可以嗎？那就要用到另外一種檔案縮寫為【PRD】，等級則是【 sl2000 】和【 sl3000 】，同樣也可以提取出來，不過我還沒有頭緒怎麼提取【 sl3000 】，但【 sl2000 】倒是沒有問題，你一定沒想到吧，三星很久以前就已經有在部署了，我的是從我以前的三星S3原廠官方ROM提取出來的。好像扯遠了...先拉回來~

**本教學不鼓勵下載散播影片，僅提供教學示範，請於24小時內自行刪除。**

我們來進行 Python 模組的安裝以及確認。

我們需要使用 pip 安裝 **frida、frida-tools、** **pywidevine** **& KeyDive**

**【開啟命令提示字元】** 或 **【PowerShell】** 然後輸入指令

**pip install frida**

**pip install frida-tools**

**pip install keydive**  
**pip install** **pywidevine**

**什麼？你問說有問題沒辦法安裝？你安裝 Python 了嗎？你有加入環境變數嗎？pip 有問題？**

**麻煩請自行 Google「Python初學者安裝教學」，自己去找資料，別只會伸手要人幫你把資料通通備齊。**

**不然這篇文章會夭壽長**

接著我們需要查看我們剛剛安裝的 **frida 版本** ， 然後去 GitHub 下載對應版本的 **frida-server** ，依我 PC 的為例，輸入指令

**pip list**

![](https://truth.bahamut.com.tw/s01/202507/15bc721d6fb64e7b0c3f9035bf2915c6.PNG)

可以看到是 **17.2.11** ，所以到 GitHub 去找對應版本的 **frida-server**

![](https://truth.bahamut.com.tw/s01/202507/6d73136b25a1e4d1a8549c881072f890.JPG)

這邊我下載的檔案是 **frida-server-17.2.11-android-x86\_64.xz**

你說為啥截圖畫面我的在上面你要翻好久才能找到？傻孩子修圖了解一下

把剛剛下載好的 **frida-server-17.2.11-android-x86\_64.xz** 丟進這個路徑

**C:\\Users\\OOOO\\AppData\\Local\\Android\\Sdk\\platform-tools**  

然後解壓縮，接著等待模擬器開啟，不要關這個資料夾。

**我叫你等模擬器啟動沒叫你關資料夾！**

![](https://truth.bahamut.com.tw/s01/202507/11639dd185876ee4cfd219ab8cd4ecb9.PNG)

模擬器已經順利啟動，那麼就在這個資料夾開啟【命令提示字元】或【PowerShell】，最好使用系統管理員權限開啟，才不會出現奇奇怪怪的問題，然後輸入以下指令

首先我們先確定有沒有抓到模擬器，因此先輸入  

**adb.exe devices**

  
這樣代表有抓到  
![](https://truth.bahamut.com.tw/s01/202507/f106deca0ba3688b9d60e3270c89e77d.PNG)

接著按照順序輸入指令  

**adb.exe push frida-server-17.2.11-android-x86\_64 /sdcard**

**adb.exe shell**

**su**

**mv /sdcard/frida-server-17.2.11-android-x86\_64 /data/local/tmp**

**chmod +x /data/local/tmp/frida-server-17.2.11-android-x86\_64**

**/data/local/tmp/frida-server-17.2.11-android-x86\_64**

  
然後你的畫面應該會像下方圖片這樣，接著進行下個步驟  
**你想幹嘛？關掉？我叫你關了嗎？我沒讓你關吧？給我開著！我沒說可以關的你他媽別給我手賤！**

![](https://truth.bahamut.com.tw/s01/202507/4825c001bf9e2d7b0fd57cbde5bd0000.PNG)

此時你的模擬器畫面應該會毫無波蘭，這很正常

![](https://truth.bahamut.com.tw/s01/202507/2f37d332ff81501a5a3891f91382ec2d.JPG)

我們找一塊風水寶地，建立好資料夾，然後在那個資料夾內使用 **系統管理員權限開啟開啟【命令提示字元】或【PowerShell】** ，然後輸入以下指令  

**keydive -kw -a player**

來我們現在數一下，我們畫面上 **現在應該要有一個模擬器視窗，兩個【命令提示字元】或【PowerShell】** ，沒有？那你應該會看到差不多下方這樣的結果。

笑死，我讓你手賤關視窗，再不好好閱讀文章阿，再不信邪阿，回到上一動！重來一遍！

![](https://truth.bahamut.com.tw/s01/202507/75d76a0ef05258285094c4412a7c85ea.PNG)

如果你有當個好孩子乖寶寶，按部就班的操作，那你應該會看到像是下方的畫面  
![](https://truth.bahamut.com.tw/s01/202507/cae4b87004327b22ba69c40d7d0feb6b.JPG)  

依序點擊模擬器畫面 **ok → 右下角 → Test DRM Playback → Google**  
![](https://truth.bahamut.com.tw/s01/202507/c40eea5b1289938d6423ce259a5a08a1.JPG)

然後就是  
  

**DO~RE~MI~SO~**

  
  
模擬器會開始播放，剛剛我們所選的 DRM 測試影片，並且用很快的速度告訴你你剛剛選的風水寶地內出現了東西！我們所需的所有東西都在這邊拉！  
![](https://truth.bahamut.com.tw/s01/202507/6ddcfd80971245b82f15f3a3b04e0b1b.JPG)

但是身為工科出生的，怎麼能不做測試？  
這邊我們選擇簡單又方便又是主流檔案的【 wvd 】 來進行測試。  
因此將【命令提示字元】或【PowerShell】跳轉進風水寶地，輸入以下指令  

**pywidevine test google\_sdk\_gphone64\_x86\_64\_18.0.0不給你看勒\_l3.wvd**

  
之後就會使用【 wvd 】 測試，如果向下圖這樣有回傳 Key ，代表你已經成功獲得專屬於自己的 CDM 了。

![](https://truth.bahamut.com.tw/s01/202507/46718d23d67ec6d98497227b879141ff.PNG)
