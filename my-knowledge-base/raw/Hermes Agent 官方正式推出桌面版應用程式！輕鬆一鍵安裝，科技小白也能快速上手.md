過去阿達已經寫過不少 [Hermes Agent 教學，甚至拍影片一部部帶大家怎麼操作](https://www.koc.com.tw/archives/640800) 。雖然以前已經很簡單了，但還是需要透過 CLI 介面來安裝和設定，對於一些科技小白來說，可能不太容易適應。而好消息是，Hermes Agent 官方的桌面版應用程式終於正式登場，不僅輕鬆一鍵安裝，操作介面也跟現今的多數 AI 工具一樣，非常容易上手，Windows、macOS 和 Linux 都支援。

## Hermes Agent 正式推出桌面版應用程式！輕鬆一鍵安裝，科技小白也能快速上手

開始介紹之前，先說明很多人可能會有的疑問：已經安裝過 Hermes Agent 的電腦，再安裝桌面版會發生什麼事？

根據開發者說明，已經安裝過 Hermes Agent 的使用者，Hermes Desktop 不會重新建立一個全新的 Agent，而是會在偵測到既有 Agent 時直接連接原本環境，也就是說，你原本 Hermes Agent 的資料都會串聯到桌面版。官方也補充，Windows 桌面版與 CLI 安裝版本會共用相同的安裝與資料目錄，因此可以同時使用。
