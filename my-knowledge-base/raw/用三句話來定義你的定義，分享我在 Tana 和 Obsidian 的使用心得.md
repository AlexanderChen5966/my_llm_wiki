用三句話來定義你的定義，分享我在 Tana 和 Obsidian 的使用心得.md

因為 Tana 的關係，我認識了「以節點為主」的筆記方式，類似的筆記軟體有 Roam Search 以及 Logseq。其實接觸後我才發現這種用列表做筆記的方式，其實叫做 Outline (大綱)，但我還是習慣用 Node (節點)稱呼。

因為我覺得大綱是 H1、H2、H3... 這種，比較像 Pages / Block 形式的記錄方式，例如 Notion。但糾結這個名詞實在沒啥意義。只是想跟各位說，我還是習慣用 Node (節點) 表示，我覺得這才是適合的稱呼，請原諒我的任性 。

## 定義對我的意義

在做讀書筆記時，我還蠻熱衷 **定義名詞** 這件事情，這一次我讀的書可能是完全不熟的領域，下一次又是其他的領域，那我該怎麼快速理解我之前閱讀的內容呢？其中一個就是靠名詞定義。

### 為什麼用三句話來定義

在還沒認識節點為主的筆記方式前，我寫筆記的方式就跟寫部落格一樣，用大綱跟段落做分段。以我前陣子閱讀的「投資最重要的事」為例，我現在要定義「基本面」這個名詞。

如果是用段落做分段，我可能會這樣寫(以下內容摘自維基百科)：

> 基本面分析（英語：Fundamental analysis）是一種為股票等證券的資產估價的方法，利用財務分析和經濟學上的研究來評估企業價值或預測證券（如股票或債券等）價值的走勢。這些被分析的基本資料可以包含一家公司的財務報表和非財務上的資訊，如商品需求成長性的預測、企業比較、新制度的影響分析或人口的改變。
> 
> 通常和所謂的技術分析相對，技術分析在研究證券價值的趨勢時，並不使用到市場本身以外的因素來做預測。投資者使用基本分析來檢驗一家公司的財務狀況、其內部運作和其產業市場，用以來了解這家公司的穩定性和成長潛力。被檢驗的項目可能包括有發放股利、公司管理資金方法、公司的負債值和公司收支成長。一個利用基本分析的人會看基本分析的結果來決定要操作多頭或空頭。

隨著年紀愈來愈大、時間愈來愈少，看這些不熟悉的名詞時，如果還要閱讀那麼長的段落，我自己是有些抗拒跟疲累的，而且可能看著看著就放空了 XXD。

所以現在我改用列點來表達，而且盡量精簡成最多三點：

- **評估證券價值的方法** ： 一種評估股票、債券等證券資產價值的方法。
- **內外部因素的綜合考量** ： 透過財務分析和經濟學研究，考量企業的財務報表、商品需求預測、產業比較、新制度影響、人口變化等內外部資訊，以評估企業價值或預測證券走勢。
- **分析公司穩定性與成長潛力** ： 投資者可用來檢視公司的財務狀況、內部運作及所處產業市場，以了解其穩定性和成長潛力，例如發放股利、資金管理、負債狀況及收支成長等。

如果覺得列點的文字太多，甚至只需要看標題(標粗體的文字)就已足夠。這樣的好處是不需要閱讀冗長的文字，就能快速了解基本面，未來有需要可以再對有興趣的部分往後閱讀。

## 如何使用 Tana 與 Tana AI 幫我快速定義

Tana 真的是個很好用的筆記軟體， ~~但我最近還是回去 Obsidian 了（炸）~~ ，其實最主要的原因是...，每次打開 Tana 都要等好久...，有時候要很快速的紀錄東西時，會等到有點滅火。

沒錯，就是為了這麼一小點的理由，我就回去用 Obsidian 了。但我還是很愛 Tana 的記錄方式，這邊也跟大家分享我是怎麼用 Tana 與 Tana AI 幫我做定義的。

▼ 以下是我在 Tana 針對定義做的 template，我把定義的 tag 取名為 #concept，紅框處就是我請 Tana AI 產生的定義內容

![](https://muki.tw/wordpress/wp-content/uploads/2025/06/CleanShot-2025-06-06-at-21.45.32.png)

▼ 我覺得 Tana 的 AI 整合的非常好，以這個功能為例，我是在 filed Setting 的欄位「AI-enhanced field」中設定自定義的 prompt，就能做到以上功能。

![](https://muki.tw/wordpress/wp-content/uploads/2025/06/CleanShot-2025-06-07-at-00.39.40.png)

分享我的 prompt 給大家：

Markdown

```
xxxxxxxxxx
```

```
Please define ${name}
```

```
Use the following format for your definition, and reply in Traditional Chinese Language:
```

```
- maximum of three points
```

```
- If needed, use a format like Key point: Detailed explanation.
```

```
- don't show order number
```

```
- Write the points directly without using titles like "Definition of ${name}".
```

```
Here's an example of that format in use:
```

```
- 評估證券價值的方法：基本面分析是一種評估股票、債券等證券資產價值的方法。
```

## 如何使用 Obsidian 製作名詞定義的文件

我是以 Tana 為最終目標，希望能將 Obsidian 變成像 Tana 這樣的功能。但 Obsidian 需要裝一些外掛才能做到類似的效果，說「類似」是因為我覺得還沒有辦法百分之百的復刻 Tana 的效果，還在努力中ＱＱ。

### 安裝 Note Definitions plugin 定義文件

▼ 首先安裝 Note Definitions plugin 協助製作定義的文件檔案

![GitHub - dominiclet/obsidian-note-definitions: Obsidian plugin for seamless viewing of personal definitions](https://opengraph.githubassets.com/b0819fe4be0836181817d85d4c180e88ec9bacc7cf9e3fb9804a144ed41c64ca/dominiclet/obsidian-note-definitions)

GitHub - dominiclet/obsidian-note-definitions: Obsidian plugin for seamless viewing of personal definitions

Obsidian plugin for seamless viewing of personal definitions - dominiclet/obsidian-note-definitions

https://github.com/dominiclet/obsidian-note-definitions

▼ 安裝後，一定要做的設定是「定義文件」的資料夾位置，其他選項可以按照預設，或用熟了之後再調整

![](https://muki.tw/wordpress/wp-content/uploads/2025/06/CleanShot-2025-06-07-at-00.49.40.png)

▼ 設定完成後，放在這個資料夾的文件都會加上 DEF 的識別

![](https://muki.tw/wordpress/wp-content/uploads/2025/06/CleanShot-2025-06-07-at-00.49.57-1.png)

▼ 未來在其他文件中，只要輸入跟資料夾內相同的檔名 (例如：變動成本)，這段字就會自動變成連結，滑鼠移過會出現小卡片顯示文件的內容。

![](https://muki.tw/wordpress/wp-content/uploads/2025/06/CleanShot-2025-06-07-at-00.52.23.png)

一定要安裝 Note Definitions plugin 嗎？

不一定，其實用內建的反向連結功能也能做到定義名詞的效果，這部分看個人喜好。

### 安裝 Text Generator Plugin 協助產生文件內容

我找過蠻多 Obsidian 相關的 AI Plugin，需要可以產生文件內容，同時也要能管理 prompt，找來找去，最後選了 Text Generator Plugin，他設定有點麻煩，但也算是符合我的需求。

![GitHub - nhaouari/obsidian-textgenerator-plugin: Text Generator is a versatile plugin for Obsidian that allows you to generate text content using various AI providers, including OpenAI, Anthropic, Google and local models.](https://opengraph.githubassets.com/91e97e524508948507fc565abcd3781073f5322d343ef78912615bc3f4d8d59d/nhaouari/obsidian-textgenerator-plugin)

Text Generator Plugin 的影片有設定 Prompt 的詳細教學，我這邊就不贅述了。不過我有小小修改 Prompt，一樣跟大家分享：

Markdown

```
xxxxxxxxxx
```

```
請定義 {{title}}，並使用以下的規則，用正體中文回應以及台灣用語
```

```
- 使用 Markdown 語法
```

```
- 列表顯示，最多三點，不要用有序列表，要用無序列表
```

```
- 如果可以，用像這樣的格式，一個列點一條內容
```

```
- Key point：Detailed explanation
```

```
以下是一個可能的範例：
```

```
- 評估證券價值的方法：基本面分析是一種評估股票、債券等證券資產價值的方法。
```

▼ 寫好檔案名稱，再使用 Text Generator Plugin 就可以產生定義

![](https://muki.tw/wordpress/wp-content/uploads/2025/06/CleanShot-2025-06-07-at-01.38.15.png)

我使用的是本地的 Ollma 服務，模型為 qwen2.5:7b。我會建議大家不要使用推理模型，不然產生的內容會包含思考的過程唷。
