網站連結 [https://tenzen.studio/photon/](https://tenzen.studio/photon/)

Photon Studio 是一款免費的桌面圖片編輯器，目標相當直接：把大家熟悉的 Photoshop 式圖片編輯工作流程，帶到一套免費、Local-first 的工具中。它能直接在電腦上編輯照片、修飾圖像與製作設計，不需要先把圖片上傳到雲端，也不需要建立帳號才能開始編輯。

如果曾經使用過 Photoshop，Photon Studio 的許多工具應該會相當熟悉。它不是只有裁切、濾鏡與簡單調色，而是提供 Layers、Groups、Masks、Adjustment Layers、Smart Objects 等完整度更高的圖層式工作方式，同時原生支援 PSD 檔案。

目前主要功能包括：

- **圖層、群組與遮色片** ：方便管理複雜的照片與設計專案。
- **調整圖層與智慧型物件** ：支援較完整的非破壞式編輯流程。
- **原生 PSD 支援** ：可以直接處理常見的 Photoshop 檔案。
- **主體選取與背景移除** ：快速辨識照片中的主要物件並完成去背。
- **Curves 曲線** ：精細控制照片亮度、對比與影像階調。
- **Liquify 液化工具** ：可以進行局部變形與人像修飾。
- **Layer Effects** ：支援陰影、發光、描邊與 Overlay 等常見效果。
- **Command Search** ：直接搜尋想使用的工具或功能。

其中最有意思的是， **連主體選取與背景移除都可以直接在自己的電腦執行** 。

現在不少線上圖片編輯器雖然操作方便，但 AI 去背、物件辨識或圖片處理通常需要把素材送到 Cloud Server。Photon Studio 採取不同方向，核心圖片編輯與這類智慧功能以本機處理為主，因此照片、客戶素材與設計檔可以盡可能留在自己的裝置。

這也是 Photon Studio 除了「免費」之外，很值得強調的另一項特色： **Local-first 與 Privacy** 。

官方表示一般圖片編輯不需要把文件上傳給 Tenzen Studio，也不需要建立帳號；Local Editing 可以在沒有網路的環境運作，官方同時表示不會利用使用者的本機編輯內容訓練 AI 模型。

對攝影師、設計師、公司內部設計團隊，或經常處理客戶未公開素材的人來說，這種架構比完全依賴 Browser 與 Cloud Processing 的圖片編輯服務更具有隱私優勢。

Photon Studio 的另一個吸引力則是使用門檻。

它不像 Photoshop 採訂閱制，目前 Photon Studio 可以免費使用，而且提供 **macOS、Windows 11 與 Linux** 版本。對只是需要 PSD、圖層、遮色片、去背、曲線與一般照片修飾，又不想為大型專業軟體支付長期訂閱費用的使用者而言，定位相當有吸引力。

當然，把 Photon Studio 稱為「100% 免費 Photoshop」比較適合作為快速理解它的方式，而不是表示兩套軟體的所有功能都已完全對等。Photoshop 經過多年發展，在專業影像處理、生態系、外掛與進階工作流程方面仍然非常龐大；Photon Studio 更值得關注的是，它正在 **免費重現許多人最常使用的 Photoshop 核心編輯體驗** 。

因此它和 Canva 這類工具的定位也不太一樣。Canva 更偏向模板、排版與快速內容製作；Photon Studio 則更接近傳統桌面影像編輯器，讓使用者真正操作 Layer、Mask、Curve、Smart Object 與 Liquify。

整體而言，Photon Studio 可以理解成一款 **免費、離線優先、注重隱私的 Photoshop 類桌面圖片編輯器** 。不需要帳號、不必把檔案上傳雲端，甚至主體選取與背景移除也能在本機完成，再加上 PSD、圖層、遮色片、智慧型物件與液化等熟悉工具，對想尋找免費 Photoshop 替代方案的使用者來說相當值得嘗試。
