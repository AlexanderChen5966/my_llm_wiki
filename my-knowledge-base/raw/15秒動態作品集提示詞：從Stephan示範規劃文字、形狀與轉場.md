15秒動態作品集若只要求「展示你的動態設計能力」，可以讓模型自由發揮，但它還不知道你的產品要說什麼。15 秒作品集很適合試風格，要拿來做品牌片，仍需補上明確目標。

Stephan Livera 的公開示範用了這種短需求，要求做出像履歷作品集的動態影片。因為主題就是展示技巧，模型不必同時處理真實產品的功能與資訊正確性。

如果你想測試工具能做哪些動作，可以先借用這個方向。要把結果交給客戶或放上產品頁時，再把品牌與觀眾的需求加進來。

## 15秒動態作品集的短 prompt 有什麼用途？

[原貼](https://x.com/stephanlivera/status/2103315922098470926?ref=aiposthub.com) 公開了片長、動態設計作品集的方向，以及作者使用的推理設定。這是他的示範，並不代表這句話由他首創。

短需求的優點是留白多，適合觀察模型會選擇的字體、形狀與轉場。也因為留白多，第一次結果好看，不表示換成你的品牌後仍然合用。

瀏覽器可以用 [CSS 動畫](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_animations?ref=aiposthub.com) 等方式表現文字與圖形，但應由代理根據交付格式選工具，不能只靠影片外觀判定用了哪個框架。

## 同一種風格下，選幾種值得展示的動作

作品集要讓人看見動態設計能力，可以讓文字、形狀與版面各負責一段。因為三段共用配色與字體，觀眾比較容易把它們視為同一件作品。

先寫清楚每段要展示的動作，再決定鏡頭與聲音：

| 段落 | 要展示的能力 |
| --- | --- |
| 動態文字 | 字距、換行與閱讀停留如何配合 |
| 形狀變化 | 一個主體如何有連續地變成另一種形狀 |
| 版面轉場 | 前一幕的元素如何帶出下一幕 |

先不用產品操作填滿畫面。這個練習的目的是辨認喜歡的動態語言，之後才把選中的做法用到自己的主題。

## 可複製的15秒作品集練習需求

在能產生並保存動畫專案的程式代理中送出需求。先確認它能提供預覽與可下載成果，再進入完整製作。

以下是本站改寫版本，非原作者逐字 prompt，尚未做成片實測。

```
製作一支 15 秒動態作品集，主題文字為［自己的名稱或概念］。
全片共用我提供的字體、主色和背景規則。
安排三種動態練習：文字節奏、連續形狀變換、版面轉場。
每段只讓一個主動作帶領視線，前一段的元素接進下一段。
文字完整出現後要能讀完，形狀變化不能無故跳出新物件。
先給關鍵影格與時間表，確認後才做完整短片。
交付影片、可修改專案，以及各段動態的控制方式。
```

## 看作品集時，先看動作之間有沒有關係

第一次看完後，試著描述三段如何連起來。如果每段都像另一支影片的開頭，就讓前段的一個形狀或字母，成為下一段的起點。

再檢查片尾。Logo 出現可以是收尾，但不應靠突然切黑遮掉尚未完成的動作。把收尾前一秒慢慢拖動，通常更容易看出銜接問題。

### 相同 prompt 能產生相同動畫嗎？

不能保證。模型、設定、專案內容與後續修改都可能影響結果，保存自己的原始檔才方便重做與比較。

### 第一支作品集應該展示多少種能力？

先挑文字、形狀與轉場各一種，讓它們共用同一套視覺規則。能連續做出第二支一致的作品，再增加更複雜的材質或三維鏡頭。

先保留自己喜歡的一組文字、形狀與轉場，再用同一風格做第二支短片，就能看出哪些動態規則值得留下。
