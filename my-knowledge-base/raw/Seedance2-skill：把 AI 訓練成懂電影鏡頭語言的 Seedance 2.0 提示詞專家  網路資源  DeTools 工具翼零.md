Seedance2-skill 是一套專門針對 Seedance 2.0 影片生成模型設計的 Claude Skill，主要用途是協助 AI Agent 撰寫更符合官方規範的影片生成提示詞（Prompt）。它並不負責生成影片，而是透過整理 Seedance 2.0 的提示詞結構、鏡頭語言與多模態輸入規則，讓使用者能更穩定地產生高品質影片內容。

隨著 AI 影片生成技術快速進步，模型本身的能力固然重要，但實際成果往往取決於提示詞品質。同樣的場景描述，不同的 Prompt 結構可能導致完全不同的輸出結果。Seedance2-skill 的核心價值，就是將官方文件中的最佳實踐與常見工作流程整理成可重複使用的 Skill，降低使用者摸索 Prompt 的時間成本。

從功能定位來看，Seedance2-skill 更接近一套 Prompt Engineering Framework。它會引導 AI 在產生提示詞時，優先考慮角色描述、場景設定、鏡頭運動、光線氛圍與畫面節奏，而不是單純堆疊形容詞。這種方式有助於提升影片一致性，也能讓生成結果更接近創作者預期。

專案目前涵蓋的重點包括：

- Seedance 2.0 Prompt 撰寫規範
- 鏡頭語言（Camera Language）
- 運鏡描述方式
- 多模態素材引用規則
- 官方推薦 Prompt Pattern
- 故事型影片模板
- 廣告影片模板
- MV 與短影音模板
- 角色一致性維持技巧

其中最有價值的部分，在於對鏡頭語言的整理。許多使用者撰寫 Prompt 時習慣描述「發生什麼事」，卻忽略了「鏡頭如何觀看這件事」。Seedance2-skill 則會引導 AI 補足推鏡、跟拍、特寫、廣角等資訊，使生成結果更具有影片感，而非單純動畫片段。

從實際應用情境來看，Seedance2-skill 特別適合：

- AI 廣告影片製作
- 品牌宣傳短片
- 社群短影音內容
- MV 創作
- AI 微電影
- 產品展示影片

對於剛接觸 Seedance 2.0 的使用者而言，專案最大的價值並不在於增加模型能力，而是在於提供一套經過整理的創作流程。使用者不需要逐頁閱讀官方文件或反覆測試 Prompt，就能較快掌握影片生成的基本原則。

整體而言，Seedance2-skill 是一個以 Prompt Engineering 為核心的實用 Skill。它透過整理 Seedance 2.0 的官方規範與創作經驗，協助 AI Agent 產生更有結構、更符合影片語言的提示詞。對於經常使用 Seedance 製作短影音、廣告或敘事型內容的創作者而言，這類工具能有效降低學習成本，並提升影片生成的穩定性與一致性。
