## Claude 怎麼做影片？製作原理與必備工具一次看

**Claude Opus 5.5 可以用來製作 AI 動畫與影片嗎？可以，但需要搭配動畫程式與影片輸出工具。**

Claude 能根據自然語言提示詞，撰寫 HTML、CSS、JavaScript 等動畫程式，控制畫面中的角色動作、物件變化、鏡頭運動及轉場效果。若要輸出 MP4 影片，則可透過 Playwright 等瀏覽器自動化工具擷取畫面，再使用 ffmpeg 合成影片。

這種製作方式適合像素動畫、手繪風影片、3D 特效及產品宣傳片。使用者可以透過提示詞描述想要的畫風、內容和秒數，由 Claude 協助撰寫及修改程式。

## Claude 免費版能做動畫嗎？需要付費才能輸出影片嗎？

**Claude 免費版也能製作動畫。** 免費用戶可以透過 Artifacts（互動成品）功能，讓 Claude 撰寫 HTML、CSS、JavaScript 等動畫程式，製作像素風、簡單手繪風或互動式動畫，並在支援的環境中預覽成果。

不過，免費版有使用量及模型存取限制，能使用免費版製作動畫，不代表可以使用 Claude Opus 5.5 模型。本文收錄的 Opus 5.5 創作案例，也可能需要較高的模型使用額度或其他工具才能完成。

如果只想製作能在瀏覽器播放的 HTML 動畫，可以先從免費版開始；若希望自動擷取動畫畫面、合成 MP4，或製作較複雜的 3D 場景與音樂 MV，則可考慮使用 Claude Code，搭配 Playwright、ffmpeg 或 Blender 等工具。實際費用仍取決於使用方案、模型用量及外部工具。

### Claude 網頁版、Claude Code、Claude Cowork 有什麼差別？

使用 Claude 製作影片前，首先要確認執行環境，Claude 網頁版適合製作可在瀏覽器播放的 HTML 動畫；若希望直接輸出 MP4，或需要搭配 Blender、ffmpeg 等工具製作複雜動畫，Claude Code 通常更適合。至於 Claude Cowork，則需要留意雲端執行環境對外部工具的支援情況。

以下整理 3 種環境的功能與限制：

| 使用環境 | 能做到什麼 | 注意事項 |
| --- | --- | --- |
| Claude 網頁版、App | 產生 HTML 動畫、網頁互動特效與動畫程式碼 | 可在支援的環境中預覽動畫；若需 MP4，通常須另行錄影或轉檔 |
| Claude Code | 製作完整動畫專案，搭配 Playwright、ffmpeg 等工具輸出 MP4 | 本文多數動畫風格建議使用，可能需要先安裝相關工具 |

### Claude 做影片怎麼下提示詞？3 大技巧讓動畫更符合預期

不論想製作哪種 AI 動畫，都建議在提示詞中加入以下 3 個要求：

1. **先產生分鏡，再開始製作** ：請 Claude 先整理分鏡表，並提供開頭、中間與結尾 3 張關鍵畫面，確認後再製作完整動畫。
2. **讓畫面由時間決定** ：要求所有動畫畫面依時間 t 計算，避免前一格影響下一格，方便指定任一時間點擷取畫面、修改與渲染。
3. **正式輸出前先製作測試片** ：先生成 2 秒測試動畫，或擷取不同段落的縮圖，檢查角色動作、字幕、畫面比例和轉場效果。

如果想了解從參考影片、素材準備到影片驗收的完整製作流程，可延伸閱讀《數位時代》〈 [怎麼用Claude做影片？6步驟技巧拆解](https://www.bnext.com.tw/article/92428/20260929-opus-promo-video) 〉。

## Claude 復古遊戲像素動畫怎麼做？

想用 Claude 製作復古遊戲風格的像素動畫，關鍵在於設定 **低解析度畫布、固定色盤與整數倍放大** 。透過 Canvas 2D 與 JavaScript，即可製作角色待機、移動、施法等循環動畫，同時保留經典點陣遊戲的視覺質感。

![Claude做影片](https://bnextmedia.s3.hicloud.net.tw/image/album/2026-10/dihp-1791511663.gif)

圖／ Claude生成

**參考作品** ：X 用戶 @majidmanzarpour 分享的像素巫師動畫，指定 128×96 的畫布與約 24 色的固定色盤，並禁止反鋸齒和漸層。巫師的動作分成待機、集氣、施法、收招等階段，再透過循環播放形成完整動畫。

創作者也要求 Claude 將動作數值對齊像素格，讓動畫呈現近似每秒 8 至 12 張畫面的點陣效果。

**操作步驟**

1. 決定動畫畫布的解析度與色盤數量。
2. 將角色動作拆成待機、準備、主要動作與收尾等狀態。
3. 先輸出 2 秒測試動畫，再調整動作節奏與像素細節。

**Claude 像素風動畫提示詞範本**

```
用單一 HTML 檔與 Canvas 2D 做一支〔10〕秒的像素風動畫，不使用外部圖檔。

【畫面】邏輯畫布 160×90，整數倍放大並關閉平滑；全片只用〔16〕色，禁止漸層、模糊與反鋸齒。

【角色】原創角色：〔外型、服裝、道具〕，約 24×32 像素。

【動作】〔待機 → 準備 → 主動作 → 收尾〕循環，動作節奏如每秒 10 張的點陣動畫。

【驗收】先給分鏡讓我確認；所有畫面由時間決定，渲染後逐秒截圖檢查並回報問題。
```

## Claude 手繪風影片怎麼做？

Claude 也能製作鉛筆、原子筆或蠟筆質感的手繪動畫，適合數據故事、知識解說及節慶影片。製作時除了指定筆觸和紙張質感，也要準備清楚的內容素材，讓動畫能配合故事與資訊呈現。

圖／ Claude生成

**參考作品** ：X 用戶 [@GroundControl](https://x.com/GroundControl/status/2103678647777230877?s=20) 從空白程式專案開始，請 Claude 製作一支 3 分鐘動畫，主題是 2026 年日本高溫。他要求 Claude 上網蒐集資料，整理歷年氣溫比較，再以鉛筆手繪風格呈現，加入輕微色差效果，並透過 JavaScript 合成器製作配樂。

**操作步驟**

1. 確定動畫主題，決定資料由 Claude 上網蒐集或自行提供。
2. 指定鉛筆、原子筆、蠟筆等筆觸，以及紙張質感和視覺效果。
3. 若有固定角色，附上參考圖片，並描述外型與需要保留的特徵。

**Claude 手繪風影片提示詞範本**

```
做一支〔30〕秒、16:9 的手繪風動畫，主題是〔主題〕。

【內容】上網查〔主題〕的資料，挑出 3 到 5 個最有畫面感的重點編成故事，並保留資料來源。

【畫面】〔鉛筆／原子筆〕手繪線條加紙張質感，線條每秒輕微抖動數次，做出手繪感。

【角色】〔附圖〕原創角色，保留〔外型特徵〕。字幕用繁體中文。

【聲音】用 JavaScript 合成符合主題的配樂。

【驗收】先給分鏡讓我確認，渲染後逐秒截圖檢查，輸出 MP4。
```

## Claude 水彩風音樂 MV 怎麼做？

想用 Claude 製作音樂 MV，可以先提供歌曲與歌詞，請 Claude 依照歌詞編寫分鏡，再利用 p5.js 等工具繪製水彩筆刷動畫，最後將畫面與音檔合成 MP4。

製作時建議先確認每句歌詞對應的畫面與秒數，避免完成動畫後才發現音樂節奏與場景轉換無法配合。

![Claude做影片](https://bnextmedia.s3.hicloud.net.tw/image/album/2026-10/sm3m-1791603408.gif)

圖／ Claude生成

**參考作品** ：GitHub 用戶 JohnHeibel 公開了 [〈I'm Upping My P(doom)〉MV 的完整原始碼](https://github.com/mexicat/pdoom-video) 。

根據專案說明，這支影片使用 Claude Code 製作了兩個版本，創作者主要指定角色造型，並要求每句歌詞都要有有趣的畫面和轉場。分鏡表與供多個子代理平行作業的動畫指南，則由 Opus 5.5 協助撰寫。

全片分成 9 個章節，使用 p5.js 搭配 p5.brush 水彩筆刷繪製，在背景瀏覽器中逐格渲染，最後透過 ffmpeg 接上歌曲，合成 MP4 影片。

**操作步驟**

1. 準備具有合法使用權的歌曲音檔與歌詞檔。
2. 請 Claude 產生包含歌詞、秒數、畫面與轉場的分鏡表。
3. 確認分鏡後，分章節製作動畫，最後與音樂合成。

**Claude 水彩風音樂 MV 提示詞範本**

```
資料夾裡有〔song.mp3〕和〔lyrics.txt〕，請做一支完整的水彩筆刷風 MV。

【第一步】逐句讀歌詞，列出分鏡表：歌詞｜開始秒數｜畫面內容｜轉場，交給我確認。

【畫面】用 p5.js 與水彩筆刷效果繪製，原創主角貫穿全片，每句歌詞都要有畫面變化。

【製作】確認後分章節製作，所有畫面由時間決定；逐格渲染後用 ffmpeg 接上音檔，輸出 1920×1080 MP4。

【驗收】渲染後逐秒截圖檢查，回報歌詞和畫面沒對上的地方。
```

## Claude 復古拼貼無限縮放動畫怎麼做？

復古拼貼無限縮放動畫結合實景影像、剪報物件與連續鏡頭縮放，適合品牌形象片與影片開場。

這類動畫的特色是讓鏡頭穿過畫面中的物件，接著進入下一個場景，形成連續縮放的視覺效果。製作時可以搭配 AI 生圖、生影片工具準備素材，再由 Claude 負責場景編排、轉場及影片合成。

![Claude做影片](https://bnextmedia.s3.hicloud.net.tw/image/album/2026-10/ipey-1791602559.gif)

圖／ Claude生成

**參考作品** ：X 用戶 @koldo2k 要求 Claude 製作一支 20 秒、1920×1080 的復古拼貼循環動畫。

鏡頭依序穿過懷錶、相機鏡頭、放大鏡等物件，讓場景從雪山一路轉換到海崖、沙丘與湖泊，影片素材透過 Magnific MCP（讓 Claude 連接外部工具的介面）呼叫多個 AI 生圖、生影片模型製作。

創作者特別要求 Claude 在生成素材前，先列出需要製作的項目與點數花費，等待確認後才執行。配樂則設定為 96 BPM、共 8 小節。

**操作步驟**

1. 列出「場景 → 穿越物件 → 下一個場景」的循環順序。
2. 決定使用自己準備的素材，或串接 AI 生圖、生影片工具。
3. 要求 Claude 先提供素材清單與預估費用，確認後再開始製作。

**Claude 復古拼貼無限縮放提示詞範本**

```
做一支〔20〕秒、1920×1080 的無限縮放循環動畫。

【風格】復古拼貼：實景風景圖層，加上黑白剪報風格的物件，帶網點、白邊和柔和陰影，整體有底片顆粒與暗角。

【循環】〔場景A〕→ 穿過〔物件1〕→〔場景B〕→ 穿過〔物件2〕→ … → 回到〔場景A〕。

【素材】使用我資料夾裡的圖片〔或：說明要用的生圖工具〕；生成前先列出項目與花費，等我同意。

【驗收】縮放速度固定，最後一格接回第一格；逐格檢查每個轉場點。
```

## Claude 卡通 3D 遊戲特效怎麼做？

Claude 可以透過 Three.js 製作卡通 3D 遊戲特效，例如開寶箱、角色升級與成就解鎖動畫。

製作時可要求 Claude 建立具有厚度的 3D 物件，再搭配卡通分階著色、輪廓描邊與動態光效，呈現接近手遊獎勵畫面的視覺效果。

![Claude做影片](https://bnextmedia.s3.hicloud.net.tw/image/album/2026-10/tcnc-1791604298.gif)

圖／ Claude生成

**參考作品** ：X 用戶 @op7418 分享了一組中文提示詞，要求 Claude 製作手遊的「精彩時刻」演出，例如開寶箱與段位晉升。

## Claude 做影片有哪些限制？素材生成、MP4 輸出與工具使用注意事項

Claude Opus 5.5 可以透過程式製作多種動畫風格，但在素材生成、影片輸出與執行環境方面，仍有幾項限制需要留意。

1. **寫實素材可能需要其他 AI 工具** ：如果需要照片級寫實人物、真實場景或複雜的寫實影像，可另外串接 AI 生圖、生影片工具準備素材，再由 Claude 負責動畫編排與合成。例如 X 用戶 @ParanoidAmerica 分享的 MV 製作流程，就包含由 Claude 呼叫電腦上的生圖工具產生素材。
2. **音樂與人聲通常需要自行準備** ：〈I'm Upping My P(doom)〉MV 使用現成歌曲，再透過程式製作動畫與合成。若影片需要人聲演唱，建議先準備具有合法使用權的音檔。
3. **原作者公開的提示詞不一定完整** ：GitHub 收錄庫 Awesome Opus 5.5 Videos 整理了大量動畫案例，但部分創作者只分享部分提示詞，或僅提供作品描述與原始貼文。因此，即使使用相同提示詞，也未必能完全重現原作。
4. **角色與品牌素材須注意授權** ：部分參考作品使用現有品牌角色、遊戲元素或其他公司的產品素材。若要對外發布或商業使用，建議優先使用原創角色、自家品牌素材，或確認已取得相關授權。
5. **雲端環境的渲染工具需要確認** ：截至 2026 年 10 月，Claude Cowork 的 Pro、Max 方案新任務已改在雲端執行。若製作流程需要安裝 Blender、Playwright、ffmpeg 等本機工具，建議優先考慮 Claude Code，並確認電腦具備足夠的運算資源。
6. **複雜動畫仍需要測試與修改** ：即使提示詞詳細，生成的程式仍可能出現字幕錯位、畫面破版、角色變形或轉場不連續等問題。因此，建議先產生分鏡與短版測試片，再正式渲染完整影片。

## Claude 做影片常見問題 FAQ

### Q1：Claude 可以直接生成影片或輸出 MP4 嗎？

Claude 可以透過撰寫程式製作動畫，若要輸出 MP4，通常需要搭配 Playwright、ffmpeg 等工具執行畫面擷取與影片合成。使用 Claude Code 搭配本機渲染工具，是本文多數案例採用的製作方式。

### Q2：Claude 網頁版可以做影片嗎？

Claude 網頁版可協助撰寫 HTML、CSS、JavaScript 等動畫程式，並在支援的環境中預覽動畫。若要取得 MP4 影片，可以透過螢幕錄影，或將程式交由具備渲染工具的環境執行。

### Q3：用 Claude 做 AI 動畫需要會寫程式嗎？

不一定。即使沒有程式基礎，也可以透過自然語言提示詞描述影片主題、動畫風格、秒數、比例與轉場效果，讓 Claude 協助產生程式碼。不過，複雜的影片製作仍可能需要安裝工具、執行程式及處理錯誤。

### Q4：Claude Code 免費嗎？做影片需要付費嗎？

Claude Code 的使用需要符合方案資格，或透過 API 計費。實際費用會受到模型用量、任務複雜度與使用方式影響。若另外串接付費生圖、生影片工具，也可能產生額外費用。

### Q5：Claude 做影片可以加入音樂和配音嗎？

可以。使用者可以提供有合法使用權的音檔，讓 Claude 協助對齊畫面與音樂節奏，再透過 ffmpeg 合成影片。部分簡單配樂和音效，也能使用 JavaScript 程式生成；若需要自然的人聲配音，則可另外準備錄音或搭配語音生成工具。
