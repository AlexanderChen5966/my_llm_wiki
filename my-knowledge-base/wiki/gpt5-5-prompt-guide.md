OpenAI 發布 GPT-5.5 官方提示詞指南，核心翻轉：從「流程導向（越細越好）」改為「結果導向（告訴 AI 要什麼，讓它自己決定怎麼做）」。傳統的逐步指令在高推理模型上反而成為枷鎖，限制了更好解法的空間。

## T（核心論點）

GPT-5.5 是在收到「目標」後自行選擇最高效路徑的模型——不是逐條執行指令的工具。越詳細的流程指令 = 越機械的輸出。告訴它完成狀態與成功標準，讓它自己找路。

**舊模型邏輯**：先確認帳號 → 再查訂單 → 再比對退款政策 → 再決定是否核准  
**新模型邏輯**：描述「完成狀態」+ 列出「成功標準」，模型自己判斷路徑

## B（適用場景）

**適用：** GPT-5.5 或同等級高推理能力模型；有明確驗收標準的任務（coding、資料處理、客服流程）  
**不適用：** 舊版模型（GPT-4o 等仍需明確流程指令）；開放探索性任務（成功標準本身模糊時）  
**注意：** 這份指南針對 GPT-5.5，換其他模型前先測試

## R（7 個寫作關鍵）

### 1. 只寫結果，拿掉流程
描述「做完之後應該是什麼樣子」+ 幾條成功標準，不規定步驟順序。

```
幫我處理這位客戶的問題，處理到解決為止。
完成標準：
- 根據現有資料判斷是否符合處理條件
- 能直接處理的事先做完，再回覆
- 最終回覆說清楚：做了什麼、給客戶的說明、還有什麼卡住了
- 資訊不夠時，只問最關鍵的那一個問題
```

### 2. 推理強度從低開始
先用 `low` 或 `medium` 強度，輸出不夠精確再往上調。預設最高強度反而可能讓模型想太多、繞遠路，且成本更高。

### 3. 舊提示詞不要照搬
遷移時逐條問：「這條是因為舊模型不夠聰明才加的，還是真正的業務限制？」前者直接刪，後者才保留。

### 4. 個性和工作方式分開寫
```
# 個性
平易近人、沉穩、直接。假設用戶是有判斷力的成年人。

# 工作方式
請求夠清楚時優先推進，不要停下來等確認。
只在缺少的資訊會大幅影響答案時才提問，且一次只問一個問題。
```

### 5. 設定明確的停止條件
```
每拿到一批結果，先停下來問自己：現在有沒有足夠依據可以回答用戶的核心問題？
有的話直接回答，不要繼續查。
```

### 6. 把檢索預算（Retrieval Budget）寫進提示詞
```
一般問題先用一次搜尋，關鍵字短而精準。結果夠用就直接回答，不要再查。
只在以下情況才追加搜尋：第一批結果無法回答、缺少必要日期或數字、用戶明確要求全面比較。
```

### 7. 讓模型先給一句「我收到了」
```
執行多步驟任務前，先送一句簡短確認，說你收到了、第一步要做什麼。一到兩句話就好。
```
避免推理過程中長時間的空白畫面，讓用戶知道「它有在動」。

## C（關鍵行動）

- [ ] 檢視現有 Prompt：找出哪些流程指令是「補模型缺陷」的，GPT-5.5 下可直接刪除
- [ ] 在 Agent Prompt 中加入停止條件，避免模型在「其實已夠」時繼續迭代
- [ ] 把「個性定義」和「工作方式」拆成兩個段落，分開維護

## 原始摘要

OpenAI 官方提示詞指南核心翻轉：高推理模型（GPT-5.5）應告訴它要什麼結果，而非怎麼做。七個技巧涵蓋結果導向、推理強度控制、舊提示詞遷移、角色與行為分離、停止條件、檢索預算、確認訊號。
