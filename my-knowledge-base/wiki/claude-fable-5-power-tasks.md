Anthropic 限時免費開放 Claude Fable 5（訂閱戶，2026/7/13 截止），Portaly 創辦人林啟維整理出 5 種最該趁機讓 Fable 處理的長上下文任務，其中商業計畫書骨架換算 API 費用約 $300–500 USD、產出品質達 $2,000 USD 顧問水準。

## T（核心論點）

Fable 的核心優勢是**超長上下文下的一致性比對能力**——能一次讀完整個知識庫、整個官網、或搭出一份完整商業文件的骨架，而不會像小模型一樣中途失焦或跑偏。這類任務的共通點是「一次性、高強度、事後可用便宜模型（Opus）維護」，適合在限時免費窗口內集中處理。

## B（適用場景）

**適用**：知識庫/Skill 一致性健檢、官網多頁重寫、範本類文件（合約/報價單/記帳表）初版建立、大型商業計畫書骨架、任何需要「同時掌握多個文件之間一致性」的長任務。

**不適用**：日常單次小任務（用 Opus 即可，不需 Fable 的長上下文優勢）；需要頻繁小改動的迭代工作（改用便宜模型承接後續修改）。

## R（5 件事）

1. **打造 AI 知識庫**（4–8 小時）：初次建立 AI 角色、公司背景、身份定位、SOP、關鍵利害關係人等，之後所有任務都能引用，一次投入降低長期「背景補充成本」。
2. **知識庫健康掃描**（2–4 小時）：讓 Fable 一次比對整個知識庫/Skill 文件，找出矛盾或過期內容——長上下文讓它能做小模型做不到的**全庫一致性比對**。
3. **官網逐頁重寫**（4–8 小時）：先完整讀官網，再重寫每頁介紹，強化主題聚焦與 SEO；任務需要跨頁一致性邏輯，脈絡長不易跑偏。
4. **建立常用範本**（2–4 小時）：合約、報價單、記帳表等，Fable 產出高品質基本架構後，後續修改交給較便宜的 Opus 承接——一次建好、長期受益。
5. **撰寫大型商業計畫/標案骨架**（4–8 小時）：讓 Fable 搭出顧問等級骨架，架構穩固後交 Opus 細化。案例：換算 API 費用約 $300–500 USD，產出品質相當於 $2,000 USD 顧問文件。

## C（關鍵行動）

- [ ] 免費窗口內優先處理「一次性+高強度+事後可用小模型維護」型任務，而非日常小任務
- [ ] 知識庫/Skill 健檢任務可比照本知識庫的 wiki-health-check，但用 Fable 一次掃全庫矛盾與過期內容
- [ ] 範本/骨架類任務遵循「貴模型搭架構、便宜模型做維護」的分層邏輯
