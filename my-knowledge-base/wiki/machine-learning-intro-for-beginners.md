給非理工背景讀者的機器學習長篇入門，用租金預測、垃圾信分類等生活例子，只靠國中代數與一次函數就講清全貌：從 AI/ML/深度學習/生成式 AI 的範圍差異，一路到監督/無監督/強化/自監督式學習、損失函數、梯度下降、過擬合判讀。現在的大型語言模型不是突然冒出的技術，而是機器學習的延伸。

## T（核心論點）

機器學習與傳統程式的差別：**傳統程式由人先寫死規則，ML 則餵資料讓模型自己學出趨勢**。所謂「學習」很機械化——把輸入與答案的關係轉成數值，預測錯了就修一點、再錯再修，反覆進行。ML 不是消滅所有規則，而是把「能從資料中調整的部分」交給模型。它擅長從大量例子找模式（需求預測/影像分類/異常偵測），不擅長過去沒出現過、蒐集方式改變、或答案本來就模糊的情境。

## B（適用場景）

**適用：**
- 非技術背景者建立 ML 的整體心智模型
- 需要向他人解釋 AI 原理背景、或理解 LLM 為何是 ML 延伸
- 釐清模型/演算法/參數/超參數、特徵量/標籤等易混淆名詞

**不適用 / 注意：**
- 入門概念文，不深入數學推導與工程實作
- ML 輸出通常只是判斷依據非最終決策；醫療/金融/招募/資安等高影響場景要嚴格確認訓練資料、錯誤率與後果

## R（核心概念地圖）

### 名詞範圍與角色
- **範圍**：AI ⊃ 機器學習 ⊃ 深度學習（多層神經網路）；生成式 AI 多建立在深度學習上
- **模型**＝從輸入產生預測的機制（租金公式）；**演算法**＝訓練模型的方法（讓誤差變小）；**參數**＝訓練中調整的數字（各特徵權重）；**超參數**＝人先決定的設定（學習率/樹深/epoch）

### 資料處理
- **特徵量（輸入）vs 標籤（要預測的答案）**；沒放進資料的資訊基本學不到
- **訓練 / 驗證 / 測試** 三分：不切分就無法判斷模型是死背還是真會
- **資料洩漏**：把「事後才知道」的欄位當特徵，訓練分數虛高、實務無用（最需警惕）
- **特徵量設計**：同樣原始資料，設計不同性能差很多；特徵不是越多越好

### 四種學習
| 種類 | 一句話 | 例子 |
|---|---|---|
| 監督式 | 從「輸入＋正解」配對學（有老師）| 租金預測（迴歸）/ 垃圾信（分類）|
| 無監督式 | 沒有正解，找資料結構 | 分群、降維 |
| 強化式 | 依行動後回饋學更好的策略（給獎勵）| 遊戲 AI、機器人；推理模型也用 |
| 自監督式 | 拿資料一部分當答案（遮字還原）| LLM 預訓練的基礎 |

### 用公式看預測
- 線性模型：`租金 = a×坪數 + b×車站距離 + c×屋齡 + d`，把輸入乘權重加總；權重正負可看特徵作用方向（但相關 ≠ 因果）

### 損失函數與最佳化
- **損失**＝把預測錯得多離譜量化成一個可比較的數字
- **MSE**（迴歸常用）：差平方後平均，重罰大偏差、易被離群值拉走
- **交叉熵**（分類常用）：衡量預測機率與正解的差距，自信猜錯會被重罰
- 損失函數是「業務上哪種錯誤最嚴重」的數學翻譯，選錯就往錯方向優化
- **梯度下降**：`新權重 = 舊權重 − 學習率 × 梯度`，往損失下降方向走小步
- **學習率**太大會震盪/發散，太小學很慢；**epoch/batch**：跑完整訓練集一輪＝1 epoch，切小塊更新＝mini-batch
- **學習曲線**判過擬合：訓練好但驗證差＝過擬合（只背歷屆題）

## C（關鍵行動）

- [ ] 遇到 ML 問題先分清：這是監督/無監督/強化/自監督哪一種
- [ ] 建模型前先檢查有沒有資料洩漏（有沒有偷用到事後才知道的欄位）
- [ ] 判斷模型好壞看驗證/測試資料的表現，而非訓練損失
- [ ] 選損失函數前先想清楚「哪種錯誤在業務上最不能接受」
