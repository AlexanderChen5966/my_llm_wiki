AI 負責規劃與分析、自動化系統負責批次執行、人工保留最終控制，是 Claude + Python 自動化工作流的核心三角分工。適合大量重複性工作、資料分析、定期流程與專案管理，最穩定的模式不是完全交給 AI，而是三角協作。

## T（核心論點）

最穩定的工作流模式是三角分工：**AI 協助規劃與分析 + 自動化系統穩定執行 + 人工保留最終控制**。完全自動化反而容易失控——AI 的強項是分析與判斷，系統的強項是大量重複執行，人工的價值在於最終責任與例外處理。

五步驟標準流程：
```
需求分析 → 任務規劃 → 自動執行 → 結果驗證 → 回饋優化
```

## B（適用場景）

**適用：**
- 大量重複性工作（批次整理、分類、命名歸檔、報表生成）
- 資料分析與整理（統計分析、趨勢判讀、自動摘要）
- 自動化工作流程（定期檢查、自動通知、多系統協作）
- 專案協作與管理（文件整理、任務拆分、進度追蹤）

**不適用 / 注意：**
- 需要高度情境判斷的決策（不能完全自動決策）
- 關鍵操作必須保留人工確認機制
- 正式工作環境建議用「AI 規劃 → 系統執行」模式，而非 AI 直接操作

## R（操作步驟）

### 兩種工作模式

**模式一：AI 規劃 → 系統執行（推薦正式環境）**
- 穩定性高、成本較低、容易維護
- 適合：大量資料處理、定期工作、企業流程

**模式二：AI 直接操作（快速模式）**
- 建立速度快、互動性高
- 適合：小型專案、臨時任務、原型開發

### 標準五步驟流程

1. **定義需求**：明確目標、要處理哪些資料、成功條件、哪些事不能做
2. **建立規則**：工作流程、判斷標準、分類方式、例外處理
3. **執行自動化**：讀取資料、執行流程、整理結果、產出報告
4. **驗證結果**：確認符合需求、有無錯誤、是否需要重新處理
5. **持續優化**：調整規則、改善流程、提升效率、降低錯誤率

### 大型任務推薦做法

```
AI 負責規劃
↓
系統負責大量執行
↓
AI 負責分析結果
```

## C（關鍵行動）

- [ ] 確認任務屬性：是否大量重複？是否需要人工判斷？選擇合適模式
- [ ] 設計回饋迴路：驗證結果後要能回饋給 AI 調整規則
- [ ] 建立例外處理機制：不能讓系統在例外情況下靜默失敗
