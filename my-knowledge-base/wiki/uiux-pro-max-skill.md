## T（核心論點）

UIUX Pro Max 是一個 AI Skill，為前端開發提供設計智慧引擎。v2.0 的核心是 Design System Generator——根據產品類型自動執行五階段平行搜尋（161 產業規則 / 67 UI 風格 / 161 色彩方案 / 24 Landing Page 模式 / 57 字型配對），產出完整設計系統（Pattern + Style + Colors + Typography + Anti-patterns + Checklist）。支援 15 個技術棧（React / Next.js / Flutter / SwiftUI 等）與 17+ AI IDE，從「幾個指令 + 幾十分鐘」取代傳統外包前端開發的數週流程。

## B（適用場景）

**適用：** 需要快速產出專業前端的個人開發者或小團隊、SaaS Landing Page / Dashboard / Portfolio 等常見類型、搭配 Claude Code / Cursor / Codex CLI 使用
**不適用 / 注意：** 高度客製化的企業設計系統可能需要額外調整、需要 Python 3.x 環境支援搜尋腳本

## 原始摘要

合併兩篇來源：Scott Hsiao 的 vocus 實戰介紹（安裝→自然語言對話→確認設計方案→實作→封存的流程）與 GitHub README（v2.0 架構、161 產業規則、67 風格、Persist Design System 的 Master + Overrides 模式）。安裝方式：`/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill` 或 `uipro init --ai claude`。核心價值是讓 LLM 如大腦般整合處理，Skill 如軍火庫般按需載入專業能力。
