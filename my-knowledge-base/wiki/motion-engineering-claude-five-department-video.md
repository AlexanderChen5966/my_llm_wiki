## T（核心論點）

產品影片第一版好看、下一版卻因為換兩個字就得整段重排，**原因是製作決定只留在對話裡**（哪張圖已批准、哪一幕要停久、哪句文案不能改）。Motion Engineering 的解法是把同一個代理拆成**五種製作責任**，每個階段都要**留下下一階段讀得到的檔案**，影片才變成「可修改的專案」而不是一次性成品。

- 五個階段是**責任分工，不是要同時開五個代理**；同一個代理分階段執行即可，重點是每階段的輸入、輸出、通過條件清楚。
- 錯誤因此好定位：文字太多回導演刪減、品牌色不一致回美術規則、輸出位置每次不同回動畫的計算方式。

| 階段 | 留下的結果 | 下一階段怎麼用 |
|---|---|---|
| 導演 | 需求、訊息、分鏡 | 決定每幕的溝通目的 |
| 美術 | 字體、色彩、構圖、素材清單 | 所有場景用同一套規則 |
| 動畫 | 場景程式與時間安排 | 產出可重複計算的畫面 |
| 技術 | 預覽、輸出設定、錯誤紀錄 | 確認檔案能正常產生 |
| 審片 | 對照需求的問題清單 | 只修影響結果的片段 |

## B（適用場景）

**適用：**
- 需要**反覆更新**產品畫面、文案、比例的產品短片（SaaS 發布片、功能更新片）。
- 想用 Claude Code 做程式動畫（例如 Remotion）、又不想每次改版都重來的人。
- 多人或多次對話接手同一支片，需要專案本身承載決定。

**不適用 / 注意：**
- 一次性、不會再改的短片：五階段文件成本可能高於收益。
- 這是**製作方法論，不是工具或模型評測**；「一定要特定模型版本」原文 FAQ 的答案是不必，沒有任何模型品質背書。
- 產品尚未具備的功能不要為了轉場好看而補成動畫，否則觀眾會誤以為產品已能做到（與 [[ideas/claude-code-animation-prompt-qa-delivery]] 的驗收邏輯一致）。
- 「輸出成功」只代表檔案產生，內容與真實畫面仍要人工比對。

## R（操作步驟）

1. **先選一個產品變化**：一支短片只呈現一個前後變化（例：雜亂待辦→今天可完成清單）；需求單寫目標觀眾、觀看場景、主要訊息、素材、交付比例。
2. **導演先交分鏡、不寫動畫**：列 3～5 幕，每幕含目的、畫面、文案、大致時間，並指出素材缺口；批准後**存成獨立文件**並標明已定案處。通過檢查：把每幕目的連起來讀，若出現第二個主題先刪減，不先加片長。
3. **美術固定規則**：主色、字體層級、邊界、畫面密度（有品牌規範就直接沿用）；先交靜態首尾畫面，確認整理後的狀態確實存在於產品。
4. **專案資料夾**：素材、原始程式、需求文件、預覽分開放；每張素材記用途（首頁／操作前／操作後／標誌）；另建**修改紀錄**（時間點、問題、修正方式、狀態）。新對話先讓代理讀專案文件並復述已批准內容，復述得出來才表示決定真的存在檔案裡。
5. **先做一幕**：Remotion 以元件加影格安排畫面，文字、座標、動作都由時間計算，重新輸出較易一致；官方有 Agent Skills 可降低用錯工具的機率（官方文件連結見原文，未核對）。第一輪只驗證一個具體變化（例：任務卡移到另一欄），**輸出起點、中段、結束三個影格**再給短預覽——只看兩端會漏掉移動中穿過文字或超出畫面。
6. **參考影片只拆成可檢查的規則**：「像高級廣告」改寫成「每幕只留一個主訊息，文字先完整出現再讓產品畫面變化」；轉場寫成前後元素的關係（哪個元素維持同一身份）；鏡頭靠近要有目的。
7. **技術階段交能重現的預覽**：先輸出最關鍵片段，重啟專案再輸出一次確認位置相同；隨機值與外部即時資料要固定。
8. **審片寫成可立即修的清單**：用時間點（「第三秒文字沒讀完就縮小」），三種看法（照需求、正常尺寸、關鍵交接影格），另外聽聲音、用預計裝置檢查；局部修正提示詞要寫「只修［時間／場景］、保留其他場景、已批准文案、素材與色彩，並確認後續時間軸是否受影響」。
9. **留作下次起點**：保留的是已驗證的視覺規則與元件（字體、字幕、卡片、按鈕、基本轉場）、產品資料與文案分開存、一個最小可輸出的短版本（更新環境後先跑它）；交付包含成片、原始專案、素材清單、需求文件、修改紀錄。直式與橫式要重新排版再分別輸出，不只裁切。

## C（關鍵行動）
- [ ] 下一支程式動畫短片，先寫「一個產品變化＋唯一主訊息」的需求單，再讓代理出分鏡，批准後存檔
- [ ] 建立固定專案骨架：需求／分鏡／美術規則／素材清單／修改紀錄，五份文件各自獨立
- [ ] 第一幕一律要求輸出起點、中段、結束三影格，並重啟後重跑確認一致
- [ ] 審片回饋一律寫成「時間範圍＋現象＋保留項目」格式
- [ ] 若採 Remotion，商用前先看授權（見 [[claude-codex-video-toolchain-selection]] 的官方 LICENSE.md 核對）
