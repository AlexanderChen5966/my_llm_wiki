針對 X 熱傳的「Claude Code UI 設計 10 個 GitHub 專案」逐項查核：十項分屬 Skill／MCP／元件／特效，**不是同類替代品**；應先找出頁面的一個具體缺口，再選一項，並用真實內容、手機、鍵盤驗收。

> ⚠️ **時效與性質**：aiposthub（Philo，2026-10-15）。**專案狀態一律「截至 2026-10-15」**（404、停維護、授權欄位都是當日狀態，會變）。作者聲明表中「可取得」只代表公開文件可讀，**未安裝、未實測**；Design Taste 的前後比較是專案自家示例，非十項工具的共同評測。文末訂閱導流與站內延伸閱讀連結不收錄。

## T（核心論點）

熱門清單不能照單全收：先分清**工作分工**、**現行入口**與**能驗收的結果**。設計指引決定頁面方向，MCP／元件／特效是落實手段；工具名稱應跟在工作目標後面，而不是「裝完整份清單」。

## B（適用場景）

**適用：** 用 Claude Code 做網站，想引入外部設計指引、元件或特效，但不知從哪一個開始。

**不適用 / 注意：**
- 一次只導入一種能力；同時加多套工具會讓效果與維護原因難以判斷
- 本條不是工具評比；沒有任何一項經過作者實測

## R（查核結果）

### 十項專案分工與狀態（截至 2026-10-15）
| 專案 | 主要分工 | 當日狀態與重點 |
|---|---|---|
| Superdesign | 舊編輯器設計外掛 | 可取得，但 README 明示是 2025 年舊外掛、**作者不再積極維護**；現行入口為網頁產品與 superdesign-skill（列 Codex） |
| Better Design | MCP：設計系統與檢查規則 | 可取得；協助代理取得一致的設計依據 |
| Design Taste | 設計與程式工作指引（風格、字體、動態、介面檢查） | 可取得；附同一需求前後示例（自家示例）；列 Codex |
| Canvas UI | 畫布特效元件（表現層） | 可取得；授權 **MIT + Commons Clause** |
| Paper Shaders | Shader 背景與紋理（表現層） | 可取得；可選動態或靜態；文件提醒**固定依賴版本** |
| UI Layouts | 介面元件與版型 | 原連結可取得；適合找具體畫面素材 |
| Hyperiux | 無法確認 | 🔴 **原網址 404**，暫緩依此連結採用 |
| Motion Primitives | 動態介面元件（Motion + Tailwind） | 可取得；README 標示仍為 **Beta** |
| Cursify | 網站游標動畫（React／Next.js） | 可取得；說明有限；**GitHub 授權欄位為空**，需另行確認 |
| trickle | 無法確認 | 🔴 **原網址 404**，暫緩依此連結採用 |

- 404 只代表目前無法從該連結取得內容，**不可推斷已永久刪除**或揣測作者動機；也不宜用相似名稱的其他專案替代，應先由原作者其他公開入口確認新位置
- Superdesign 舊安裝筆記與現行流程不同：交接文件要同時寫專案網址與採用版本

### 授權（作者提醒）
- Canvas UI：MIT + Commons Clause——可作為網站／產品的一部分使用，但**限制元件本身的販售、轉授權、重新散布**；若要做素材包或移植版販售，須先讀原授權文字
- Cursify：授權欄空值不等於無授權，若會影響交付須向作者／文件取得依據
- 十項**沒有共同授權**；採用網址、版本、授權文件一起留存

### 驗收方法（作者以假設的課程報名頁示範，非實測）
- 先把需求寫成可取捨的條件（時間易比較、費用清楚、手機填寫順暢），並要求具體修改（如每個場次顯示日期、時間、剩餘名額），而不是「加某套元件和動態背景」
- 用真實內容：長短不同的標題；空白、填錯、送出失敗狀態；錯誤訊息靠近欄位
- 手機沒有滑鼠：游標效果不能承擔主要功能；鍵盤焦點要可見；動畫／特效關閉後仍能完成任務
- 特效成本：同一頁開關效果對照文字辨識、捲動、輸入；保留靜態版本
- 規則與元件同一套語言：元件預設顏色與間距要對齊產品規則；MCP 連上只代表可取用指引，仍要檢查產出
