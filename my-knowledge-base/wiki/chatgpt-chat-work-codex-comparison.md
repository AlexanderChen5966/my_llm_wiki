OpenAI 於 2026-07-09 推出 ChatGPT Work 與新模型 GPT-5.6，並將 Codex 整合進新版 ChatGPT 桌面 App，介面分為 Chat、Work、Codex 三種模式，架構上與 Anthropic 的 Claude / Cowork / Code 如出一轍。

## T（核心論點）

三個模式不是進階關係，而是各自處理不同層級的工作：Chat 動的對象是想法與文字（交付一段內容）、Work 動的對象是工作流程與外部工具（交付可直接使用的成果）、Codex 動的對象是整個程式碼庫（交付經測試驗證的程式碼變更）。選模式的判斷依據是「這次真正要動的是什麼」，而非職稱。

## B（適用場景）

**適用：** 判斷該用 ChatGPT 哪個模式處理特定任務；理解 ChatGPT Work 與 Claude Cowork 的定位差異。
**不適用 / 注意：** ChatGPT Work 走瀏覽器虛擬環境路線（導航網站/填表單/跨站蒐集資料），與 Claude Cowork 直接操作本機檔案的模式不同；免費版與 Go 方案的 Work/Codex 目前只能使用輕量模型 Terra。

## R（三模式對照）

| | Chat | Work | Codex |
|---|---|---|---|
| 一句話定位 | 幫你想清楚、寫出來 | 幫你把事情做完 | 幫你修改程式碼 |
| 動的對象 | 想法與文字 | 工作流程、檔案與外部工具 | 程式碼庫 |
| 適合任務 | 文案、摘要、翻譯、討論 | 彙整資料、建立文件/簡報/試算表、建網站（Sites） | 讀程式、修 Bug、Review PR、跑測試 |
| 最後交付 | 一段內容 | 可直接使用的成果 | 程式碼變更、測試結果、diff |

**Sites 功能**：Work 底下用一句話描述需求（如「幫我做一個活動報名頁」）即可生成網站，即時預覽調整後直接發布，優先開放 Pro/Pro Lite/Edu 用戶。

**模型配置**：一般 Chat 對話預設仍是 GPT-5.5 Instant；Work 與 Codex 依方案分兩級，免費/Go 只能用 Terra，Plus 以上可在 Sol/Terra/Luna 間選擇。

> ⚠️ 世代註記（2026-09-29 附註）：本條（含 B 層「免費版與 Go 只能用 Terra」）的 Sol／Terra／Luna 為 **GPT-5.6** 分級；GPT-6 為 Astra／Sol／Luna、無 Terra（GPT-6 下 Free／Go 僅桌面版 App 可用 Luna），見 [[gpt-6-astra-prompting-guide]]。

**三種工作型態對應**：內容創作型（行銷/編輯）主力 Chat、Work 負責交付成果；流程管理型（行政/客服/營運）主力 Work、Chat 負責協助思考；軟體開發型（工程師）Chat 討論架構、Codex 實際改程式碼。

## C（關鍵行動）

- [ ] 動工前先問自己：這次要動的是想法文字、工作流程、還是程式碼庫，再決定用哪個模式
- [ ] Work 下指令時比照官方建議，一次交代清楚交付成果、可用資料來源、限制條件、需停下確認的情況
- [ ] 開發者可讓 Chat 與 Codex 搭配使用：討論驗證用 Chat，實際改動程式碼切換 Codex

## 補充資料（來源：數位時代〈ChatGPT Work怎麼用？14個功能、雲端與本機差異一次看〉，2026-08-17）

補上原條目未涵蓋的**執行模式分野**與 14 項功能盤點。⚠️ 該文標明初稿為 AI 編撰，資料來源含 OpenAI 官方公告、官方文件與 Riley Brown 教學影片。

### 🔴 最關鍵的一條線：雲端版 vs 本機版（選錯邊任務會失敗）

| | **雲端版**（網頁／iOS／桌面 app 的 cloud 模式）| **本機版**（桌面 app 的 local 模式）|
|---|---|---|
| 任務跑在哪 | OpenAI 的雲端電腦 | 你自己的電腦 |
| 跨裝置 | **手機與電腦隨時互相接手，筆電闔上照樣跑** | **無法跨裝置接續，電腦一關任務就停** |
| 能碰什麼 | 碰不到你電腦裡的檔案與軟體 | **能開本機檔案、操作桌面軟體與內建瀏覽器** |
| Skills 範圍 | 只有包在 plugin 裡的 skills | 另可用放在 **Codex 本機資料夾的 standalone skills** |

切換方式：開新對話時選「in the cloud」或「on your computer」；對話框右下角的電腦螢幕 icon 也可切換。

🔑 **這條線直接影響「排程自動化」的行為**：設在雲端不依賴你的電腦開機；**設在本機則要電腦開著、ChatGPT 桌面 app 持續運作、專案仍在原位才會跑**。

⚠️ **Skills 的範圍落差**（依官方文件分兩種）：standalone skills 放 Codex 本機資料夾，供桌面 app／Codex CLI／IDE 擴充使用；plugin 內的 skills 則在網頁、桌面與行動版的 Chat 與 Work 都能用。**Riley Brown 實測時直言希望 OpenAI 盡快整合這兩者。**

### 14 項功能的四類分法

- **第一類（零設定即可用）**：製作簡報／建立文件與報告／製作與分析試算表／生成與編輯圖片
- **第二類（接上 Gmail、Notion 之後）**：Plugins 串接外部工具／**Skills 建立可重複工作流程**／排程自動化／**Sites 建立及分享網站**
- **第三類（對話視窗變工作區）**：**Blocks** 編輯內容與圖表／**Branch 分拆對話任務**／多視窗並行處理
- **第四類（不在電腦前）**：語音操作工作流程／**Remote 從手機控制桌面工作**／內建瀏覽器操作網站

原文開場的使用情境很能說明它的定位：**「把筆電接上電源，人拿著手機出門散步 30 分鐘。邊走邊用語音清空信箱、順手派出四、五個工作任務；回到座位時，回信草稿與研究筆記已經躺在螢幕上等驗收。」**

### 🔑 官方建議的入門順序

> **先從查找郵件、擬定回信、整理文件或公開資料研究開始——這些任務容易驗收，也不必一開始就開放高風險操作權限。**
