## T（核心論點）

**「用了 API」不等於資料已經整理好；真正該交付的是一份「能追到來源、能用同一份原始檔重跑出一致結果」的 CSV，再讓 AI 把流程變成工具。** 核心做法是把「來源網址／格式／篩選」三件事分開，並要求 AI 保留原始回應、標記異常而不是悄悄補值。

## B（適用場景）

**適用：**
- 會用試算表篩選、但還不會自己串接資料的人，從**不需 API key 的公開 JSON feed** 起步
- 每週要重複取得同一來源、保留固定欄位的報表前處理
- 要驗收「AI 寫的資料處理程式」：這套檢查法（保留 raw、異常旗標、replay）可套到任何新來源

**不適用 / 注意：**
- 單次分析：直接下載 CSV 就夠，不必做流程
- 快照只回答「某個時間點」的狀態：可借車數是存量，**不能推出當天借出多少、也不能判斷長期需求**
- 本例來源不支援伺服器端查詢，行政區篩選是**下載全檔後在本機做**；不要在官方網址後自行加 query 參數期待來源替你篩
- 其他服務可能要 key、分頁或付費，換來源要重讀文件
- 若要做成「即時找車工具」，還需設計更新、資料過期顯示與失敗處理（本例沒做）
- 資料只有網頁、沒有下載或介接方式時，才需要評估爬蟲

## R（操作步驟）

1. **先分清三件事**：資料網址（向哪取）／請求方式（本例用 GET）／回傳格式（JSON→整理成表格）／篩選條件（下載後本機篩）
2. **選有欄位說明的來源並記下授權**：本例為臺北市交通局 YouBike2.0 即時資料（data.gov.tw 資料集 137993；欄位說明在臺北市資料大平臺），標示免費、每 1 分鐘更新，授權為政府資料開放授權條款第 1 版——使用時標示機關、資料名稱、來源與授權
3. **把問題縮小到能逐列核對**：例如「快照中，大安區有哪些站點至少有 5 輛可借車」
4. **把需求寫成可驗收的 prompt 給 AI**（原文給了完整範本），要點：
   - Python 3.9+、只用標準函式庫，檔名 `fetch_clean.py`
   - 明確告知是公開 JSON feed、不加 API key、**不准編造行政區 query 參數**
   - 下載設定：連線等待上限 30 秒；失敗要顯示原因，**不能用空表冒充成功**
   - 保留 `raw.json`，另記錄來源網址、下載時間與檔案雜湊
   - `sno` 保留文字並檢查空白／重複；`Quantity`、`available_rent_bikes`、`available_return_bikes` 檢查為非負整數，**缺值或不合法值不可自動補 0**（「不知道有幾輛」≠「確定 0 輛」）
   - 異常寫進 `quality_flags`；`act` 欄位原值保留、不解讀狀態碼
   - 輸出 `cleaned.csv`、`filtered.csv`、欄位映射表與總列數／異常列數／選中列數
   - 提供 `--replay` 讀既有快照重做，完全不連網
5. **執行**：`python3 fetch_clean.py --out run`（程式拒絕覆蓋既有資料夾，重抓要換名如 `run2`）；出錯時把錯誤訊息連同原程式交給 AI，**別接受它重新生成的示範數字**
6. **欄位對照（來源→整理後）**：`sno→station_id`、`sna→station_name`、`sarea→district`、`Quantity→capacity`（大寫 Q 不可自行改）、`available_rent_bikes→rent_bikes`、`available_return_bikes→return_spaces`、`srcUpdateTime→source_published_at`、`mday→station_updated_at`、`act→act`
7. **分開記三種時間**：程式下載時間（只證明何時取得檔案）／來源發布時間／各站更新時間（才是資料內容何時更新）
8. **核對**：用試算表打開 `filtered.csv` 按行政區與車數核對；再從 `cleaned.csv` 挑一列「車數不足或區域不同」確認**沒進入結果**（抓出把「而且」寫成「或者」的錯，只看總筆數發現不了）
9. **replay 驗證**：`python3 fetch_clean.py --replay run --out replay`，同輸入應得同輸出；這能分開檢查「資料變動」與「程式變動」，但**不證明資料內容正確**（雜湊同理）
10. **失敗診斷**：逾時＝等待時間內沒完成；JSON 解析失敗＝內容不符預期格式；必要欄位消失＝回官方頁查是否改版。**不要用空表或自動改欄位名稱掩蓋錯誤**

## C（關鍵行動）

- [ ] 挑一個自己工作上每週要重抓的公開資料來源，先確認：是否需 key、授權條款、欄位定義頁
- [ ] 把「保留 raw＋異常旗標＋replay＋不准補 0」四條寫進自己的 AI 資料處理 prompt 模板
- [ ] 以練習包的條件（行政區、車數門檻）改一次，確認輸出跟著變，再擴充功能
- [ ] 要拿結果做報表前，檢查「該用途需要的條件」——通過範例規則不等於適用任何用途
