## T（核心論點）

**Intelligent UI 是 GPT-6 在 ChatGPT 的新回答方式：模型依問題自行決定給純文字、互動圖表、可點按鈕、表單或能操作的小工具；改的是「答案長怎樣」，不是「答案準不準」。** 價格、時刻等會變的數字，版面再好看仍要回官方確認。

## B（適用場景）

**適用：**
- 「當下要算一算就走」的任務：分帳、預算、比價、存錢試算、概念互動式學習（三門問題）、對話內小遊戲
- 需要比較、篩選、試算或蒐集資料的回答；規格明確的需求蒐集（表單取代來回追問）

**不適用 / 注意：**
- 簡單問題仍只回純文字
- 要「留下來、發佈成連結給別人用」的小工具：主體篇建議用 Claude Artifacts（見下）；ChatGPT 說明頁**未提**能單獨發佈
- 圖表不保證資料正確、按鈕建議不一定適合你的情境（補充篇亦強調）
- 人在香港／澳門：主體篇稱兩地不在 ChatGPT 與 Claude 支援國家清單，在清單外使用帳號可能被封鎖或停權；三家中僅 Gemini 網頁版清單列有港澳（作者轉述，使用前查官方清單）

## R（操作步驟）

### 一、誰有、誰沒有（✅ 以下依主體篇引用 OpenAI 說明頁；來源說明頁：help.openai.com〈GPT-6 and other models in ChatGPT〉）

| 狀態 | 有？ | 原因 |
|---|---|---|
| 免費版、Go（輪到後） | ✅ | 聊天框換成 Luna，**10/8 起分批** |
| Plus 選即時／中／高 | ✅ | 由 Sol 回答（Plus 以上 **10/7 起**） |
| Pro 選極高 | ✅ | 仍是 Sol |
| **Pro 選 Pro 檔** | ❌ | 改用 **Astra**，說明頁寫明不支援 |
| 手動選舊的 GPT-5.6 Sol | ❌ | 說明頁寫「用 GPT-6 時才有」 |
| 手機 App（最新版） | ✅ | 需先更新到最新版 |
| 舊版 Windows、Mac 桌面 App | ❌ | 說明頁要求改用網頁版 |

重點：**想要圖表就留在「極高」以下，要深度推理才切 Pro 檔，兩件事別混在同一題。** 沒出現時的四步排查：①付費方案選 GPT-6 且思考程度在極高以下（選 Pro 檔就沒有）②改網頁版或更新手機 App ③免費／Go 可能還沒輪到 ④直接在問題裡要它「做成可以操作的工具」。

### 二、叫出來：5 個提示詞（⚠️ 作者整理的繁中範例，非官方；成功率取決於「明講要互動＋給具體數字」）

1. 分帳：「幫我做一個 4 個人的分帳計算機，每個人輸入自己點的金額，服務費 10% 平均分攤」（看有沒有輸入框）
2. 存錢試算：「用可以拉動的圖表算每月存 5,000 元、年報酬 5%，20 年後大概有多少」（看能否拖動）
3. 交通比較：「用並排比較從台北到台中搭高鐵、客運、自己開車的時間和花費」（看是否並排卡片；**票價要自己再查**）
4. 學概念：「用我可以自己點的方式解釋三門問題，讓我實際玩幾次」
5. 小遊戲：「做一個可以在對話裡玩的猜數字遊戲，1 到 100，猜錯會提示太大或太小」

### 三、調少／關閉（✅ 說明頁事實；⚠️ 一項為作者建議）

- **沒有一鍵全關**：網頁版設定把「Layout and visuals」（英文名稱；中文譯名作者未對到）關掉，視覺元素變少，但**說明頁寫明不會整個切回純文字**，有些圖表仍會出現
- ⚠️ 作者建議：單題想純文字就在問題後加「只用文字回答，不要圖表」——**這不是正式設定，效果要自己試**
- 互動回答**沒有獨立額度**，用原方案的模型、工具與用量規則；吃額度的是模型與思考程度、以及上傳檔案／生圖／語音等本來就另計的項目，不是版面
- 在某對話要它改版面，不影響其他對話

### 四、三家對照（主體篇表格，作者彙整自各家官方頁，細節以官方為準）

| 功能 | 出現在哪 | 免費版 | 最適合 |
|---|---|---|---|
| ChatGPT Intelligent UI | 回答本身 | 可（10/8 起分批） | 分帳、試算等當下要算的事 |
| Claude 對話內圖解 | 回答本身，隨對話改變或消失 | 所有方案（2026-03-12 測試版推出，預設開啟） | 邊聊邊看圖理解 |
| Claude Artifacts | 對話旁獨立成品，可發佈成連結 | 可；連接 App、資料儲存要付費 | 要留下來給別人用 |
| Gemini Canvas | 獨立畫布 | 所有使用者 | 報告轉網頁、資訊圖表、測驗（分享連結僅網頁版可開） |

- Artifacts 須先在設定 Capabilities 開啟「Cloud code execution and file creation」；發佈後有連結者可開，工具若呼叫 Claude，用量算使用者自己的方案（作者稱這是 ChatGPT 說明頁完全沒提的能力）
- 作者轉述 Anthropic 10/8 公告：文件、簡報、設計範本開放所有方案，連接 App、資料儲存與測試中的 Dashboards 範本仍要付費（見 [[claude-dashboards-beta-2026-10]]、[[claude-motion-beta-2026-10]]）
- Gemini 免費版 10/9 起只剩 Flash-Lite（作者轉述），Canvas 仍在免費名單，但小模型是否使成品變陽春 Google 沒說
- Google 2025-11 研究部落格的 dynamic view／visual layout 為實驗功能，作者因不一定每帳號可見而未放入表格

### 五、作者的分工建議（⚠️ 個人觀點，作者每日用 AI 逾 10 小時、三家都付費）

- 當下要算：ChatGPT（免費版就有）；要留下分享：Claude Artifact；長報告變形：Gemini Canvas
- **不要為了互動回答而付費升級**——作者算出只為此升 Go 一年多花 3,240 元（270×12），而互動回答免費版本來就有（價格為作者計算，匯率與方案價以官方為準）

### 六、補充篇的概念觀點（Dr. Jackei Wong，⚠️ 單一作者評論；範例為假設情境）

- 三項能力：①回答直接變互動圖表（可切換指標、查看特定日期、篩選渠道）②常見下一步做成按鈕（「改寫成社群貼文」「建立促銷方案」等）③追問轉成表單（職位名稱、薪酬範圍、必備技能等一次填完）
- 論點：GPT-6 的意義是「更懂得選擇回答形式」——判斷問題屬比較型、決策型或資料蒐集型，使用者不必自己決定要表格還是圖表
- 與主體篇對照：Wong 篇**未提**Pro 檔／舊桌面 App 不支援、也未提「只能調少」，讀其「GPT-6 引入 ChatGPT」時請以主體篇的方案限制為準

### 七、補充：aiposthub 篇新增資訊（Philo，2026-10-09；⚠️ 依官方發布說明整理，作者明說**未操作不同方案帳號、未測試台灣帳號**，也未重跑展示工具）

> ⏱ 2026-10-09 快照。**以下為補充，不取代上方第一節的方案限制與 Pro 檔（Astra）不支援等內容**；aiposthub 篇未提 Pro 檔／舊桌面 App 的限制，請仍以第一節為準。官方來源：openai.com/index/gpt-6-for-everyone/（〈GPT-6 and Intelligent UI for everyone〉）。站內課程導流不納入。

- **模型對應精確化**：付費方案（Plus／Pro／Business／Enterprise）日常對話由 **GPT-6 Sol**，Free 與 Go 由 **GPT-6 Luna**（既有條目原本只寫 Luna）；兩者針對日常聊天調整，不宜說成完全相同
- **只動 Chat 模式**：這波發布 Work 與 Codex 使用的模型沒有改變；因此軟體串接模型的使用費用不能由這則消費端介面新聞推算
- **Enterprise 看管理員**：能否使用取決於組織管理員設定，不能只看訂閱名稱；逐步推出代表每個帳號實際取得時間不同
- **為什麼能邊生成邊顯示**：官方說明使用「可串流的原生元件庫＋編譯器」（元件庫＝現成介面零件，編譯器把模型生成內容轉成顯示結果），回答不必等整個介面完成；官方也承認設計判斷與創作能力仍有改善空間，訓練評估涵蓋清晰度、實用性、完整性（公司對自家方法的描述）
- **「提早 44%」的條件**：官方稱在**需要網頁搜尋**的問題上，GPT-6 Instant 平均比 GPT-5.6 Instant **早 44% 開始回答**；🔴 **僅指起答時間，不是總完成時間**，也不是每次都必然提早相同比例。作者未重現這些內部評測
- **官方示範題材**：學習（中央極限定理、GDP、空拍基礎、蒙提霍爾問題）、日常（備餐時間表、公路旅行地圖、自行車部位選擇）、小工具（分帳、儲蓄成長計算器、復古遊戲）。示範代表設計方向，不是已驗證學習成效，也不等於所有帳號已能用
- **作者的核對清單（個人建議）**：條件是否一致（文字、圖表、操作結果）、資料是否最新（營業時間、交通時間）、例外是否處理（如分帳時某人未參與某項費用）、保存結果時**連輸入假設（人數、日期、計算條件）一起交接**；自己暫時理解與交給整個班級／團隊使用，所需證據不同

### 八、補充：教育者親測案例（樂尼／學習玩家，vocus，2026-10-09；⚠️ 個人實測，**非官方能力清單**）

## C（關鍵行動）

- [ ] 用提示詞 ❶（分帳）在網頁版測一次，確認自己帳號是否已輪到
- [ ] 用分帳題當驗算題：自己先算一遍再對照介面輸出，並注意自動命名與規則簡化（第九節）
