六大免費線上課程平台快速比較地圖：Anthropic/Claude（13 堂，官方結業證書）、Google（Gemini CLI + ADK，學習徽章）、微軟（AI Agents for Beginners，1 小時）、Hugging Face（7 門課涵蓋 LLM/Agent/MCP/Diffusion/Audio/Robotics，部分有結業證書）、Canva（8 門設計課，官方電子證書）、哈佛大學（85 門課，教材免費、正式證書需付費 $149-299）。

## T（核心論點）

免費課程資源散落各平台，本篇是快速選課地圖而非單一課程深度介紹——依「零基礎/有 Python 基礎/想拿證書上 LinkedIn/想跨領域補強」四種需求分流，快速定位該從哪個平台哪門課開始。

## B（適用場景）

決定要不要投入時間上某個免費 AI 課程之前的快速篩選；想找可放上 LinkedIn 履歷的官方證書課程；零基礎入門 vs 有開發背景進階學習的路徑選擇。

## R（六大平台速查）

| 平台 | 適合對象 | 主題 | 證書 |
|------|---------|------|------|
| **Anthropic/Claude**（Anthropic Academy，13 堂） | AI 新手到開發者 | Claude 基礎/AI 素養/Claude Code/API/MCP/教育應用 | 多數課程通過測驗有官方結業證書 |
| **Google**（Gemini CLI 1 小時 + ADK 8 堂） | 職場人士/PM/工程師 | Gemini CLI 免程式操作、AI 代理開發 | 部分課程有 Google 學習徽章 |
| **微軟**（AI Agents for Beginners，YouTube，約 1 小時） | 開發者/技術型職場人士 | LLM+記憶+工具三組成、Semantic Kernel、Autogen、多代理協作 | 依課程規範而定 |
| **Hugging Face**（7 門課） | 有 Python 基礎的開發者 | LLM/Robotics/MCP/Smol（微調）/AI Agent/Diffusion/Audio | MCP/Smol/AI Agent/Audio 課程有結業證書 |
| **Canva Design School**（8 門課） | 設計新手/行銷人/教師 | Canva 操作/平面設計理論/品牌視覺/行銷素材 | 完成考試可拿官方電子證書 |
| **哈佛大學**（85 門課） | 上班族/管理者/跨領域進修者 | 商業管理/數據科學/電腦科學 AI/社會科學/健康醫療/數學 | 教材免費，正式證書約 $149-299 需付費加購 |

**快速選課建議**：零基礎想拿證書入門 → Anthropic Academy「Claude 101」；想學 AI 代理但不寫程式 → Google Gemini CLI 課（1 小時）；有開發背景想從零建代理應用 → Google ADK（8 堂，偏部署實作）或微軟 AI Agents for Beginners（偏底層架構理解）；想深入開源生態不被單一廠商綁定 → Hugging Face 7 門課；需要短時間內拿可展示證書 → Canva（時長短，10 堂約 60 分鐘）。

## C（關鍵行動）

- [ ] 選課前先用上表快速定位需求對應平台，避免逐一搜尋各家官網
- [ ] 想放 LinkedIn 履歷的證書優先選 Anthropic/Canva/Hugging Face 有官方認證的課程
- [ ] 哈佛課程教材雖免費但正式證書要付費，僅為取得知識可跳過認證
