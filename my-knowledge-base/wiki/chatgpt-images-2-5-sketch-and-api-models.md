> 兩篇報導同一次發布、同一組事實，T 層高度重疊，故併為單一條目而非互連的孿生條目。

## T（核心論點）

> **Images 2.5 真正有感的升級不是單次畫質，而是「多輪編輯的一致性」**——
> 複雜構圖下反覆修改不會讓畫質逐次遞減，以參考照片為核心的 API 工作流能持續錨定原始來源不漂移。

官方端的三大主打是細節更清晰、局部編輯更精準、**延遲較 Images 2.0 最多降低 50%**，
並對全部 ChatGPT / ChatGPT Work / Codex 方案開放。規模數據：**每週經 ChatGPT Images 與
GPT-Image API 產生的圖片超過 30 億張**。

而《數位時代》實測給出一個反直覺結論：
🔑 **`@Sketch` 適合用來「指定構圖」，而不是讓 AI 讀懂草圖語意。**

## B（適用場景）

**適用：**
- 需要跨多張圖維持一致風格的素材生產（品牌素材、保持階層結構的 UI 概念、符合既定版面的簡報視覺）
- 已知元素該擺哪裡，想用簡單線條先定位置再用文字補風格材質
- 要在 API 端選型：大量生成 vs 可直接上線的廣告素材

**不適用 / 注意：**
- 🔴 **不要期待 Sketch「看懂」草圖**：實測中火柴人被原樣畫成黃色線條人（沒變真人）、
  回字形窗戶被畫成三層同心方框、**沒畫的太陽與山脈反而被補上**。要它理解草圖背後的意思，得用文字明講
- ⚠️ 官方定價頁只按每百萬 token 計價，**未提供單張價格**
- ⚠️ Sunburst 生成時間較長，不適合高量生成

## R（操作步驟）

### 1. 介面端四項新工具

| 工具 | 用法 |
| --- | --- |
| **Sketch** | 在 ChatGPT 內手繪草圖當視覺參考，輸入 `@Sketch` 啟用 |
| **模板** | 海報（Poster）、商品周邊（Merch）等常見格式的起手模板，填入資訊與風格 |
| **圖上留言 / 以評論編輯** | 直接在圖片上標註要改的位置，系統只調整指定區域 |
| **分享提示詞** | 分享圖片時附上提示詞，他人可換自己的照片重跑（官方舉例「如果你活在 80 年代會是什麼樣子」這類病毒式模板） |

### 2. API 雙模型分工

| 模型 | 定位 | 適用 |
| --- | --- | --- |
| **GPT-Image-2.5 Flare**（預設） | 畫質高於 GPT-Image-2，延遲低 50%，效率／品質平衡 | 社群內容、產品視覺體驗、視覺搜尋、快速原型、高量生成 |
| **GPT-Image-2.5 Sunburst** | 多輪編輯控制更緊密，生成較慢 | 廣告素材、產品型錄等可直接上線的專業場景 |

早期客戶：Higgsfield AI、Adobe、Manus、Runway。Higgsfield AI 產品主管 Axultan Alimkulov
對 Flare 的品質、編輯精確度與速度給出正面評價。

### 3. Sketch 實測操作結論（bnext，手機版）

- 草圖只畫房子、火柴人、地平線與兩叢草，指令僅「風景畫、野獸派風格、油畫」，**約 20 秒出圖**
- 成品四個元素位置與草圖**完全一致**，構圖忠實到近乎照抄
- 🔑 **正確用法**：先用簡單線條決定人物與物件位置 → 再用文字提示補上風格、材質與細節

### 4. 官方強調的其他能力（kocpc / 官方部落格）

- 更準確理解**複雜視覺指令**、支援**透明背景**等進階版面配置
- 風格呈現更忠實反映使用者的藝術風格要求，生成系列素材時不易偏離原本視覺方向
- 企業用途明確指向「一系列一致風格素材」

### 5. 安全機制

沿用 Images 2.0 建立的架構：對提示詞與生成圖審查、**C2PA 內容來源元資料**、
**不可見浮水印**，並發布 System Card 說明評估方法與安全方針。

## C（關鍵行動）

- [ ] 若正在做 API 選型，預設用 Flare，只在需要可直接上線的廣告素材時才切 Sunburst
- [ ] 用 Sketch 時把工作流改成「線稿定位置 → 文字補語意」，不要期待它推斷意圖
- [ ] 測試多輪編輯一致性：同一參考照片連改五輪，觀察畫質與版面是否漂移
- [ ] 若有既有的圖像 prompt 模板集，檢查是否需要為 2.5 的透明背景與局部編輯能力補一組

## 原始摘要

**主來源（bnext）**：OpenAI 於美國時間 9/8 推出 ChatGPT Images 2.5，主打細節更清晰、局部編輯更精準、
延遲較 Images 2.0 最多降 50%，對全部方案開放；每週超過 30 億張圖片經 ChatGPT Images 與 GPT-Image
API 產生。介面新增 Sketch、模板、圖上留言、分享提示詞四項；API 上架 Flare（預設）與 Sunburst
（多輪編輯控制更緊、較慢）。《數位時代》實測指出 Sketch 對草圖構圖忠實到近乎照抄，因此適合「指定構圖」
而非讓 AI 理解草圖意圖。

**補充來源（kocpc）**：重點放在官方部落格說法——多輪編輯一致性（畫質不隨修改次數遞減、以參考照片
錨定不漂移）是對設計工作流的實質改善，比單次畫質更關鍵；另補上透明背景、複雜視覺指令理解、企業
「一系列一致風格素材」用途、Higgsfield AI 評價與 System Card。
