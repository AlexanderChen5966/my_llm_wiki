LLM Wiki 是一個整理大型語言模型（LLM）與 AI Agent 生態的開源知識庫，定位為「LLM 世界地圖（LLM landscape wiki）」。不是單一 AI 工具，而是一套持續更新的百科式資源，幫助開發者快速理解 AI 領域的模型、框架、工具鏈與工作流。

## T（核心論點）

AI 開發的真正瓶頸不只是技術能力，而是「資訊太分散」。LLM Wiki 的價值在於把快速演進的生態整理成結構化知識，讓開發者能快速掌握整體 landscape，而非只懂單點技術。真正稀缺的是知識整理能力，不是模型能力。

## B（適用場景）

**適用：** AI 初學者建立全局認知；想快速追蹤 AI 生態的開發者；建立 AI workflow 的團隊；想比較不同 framework 與工具的人
**不適用 / 注意：** 深度技術實作細節需另查官方文件；社群維護的開源專案，更新頻率與品質不保證

## R（操作步驟）

LLM Wiki 作為導航資源使用：
1. 依需求瀏覽對應分類（模型比較 / Agent framework / RAG / MCP / Prompt Engineering）
2. 用作「技術版圖快速定位」，確認要深入學習的方向
3. 結合本知識庫 wiki 條目做交叉參考

## C（關鍵行動）

- [ ] 作為定期追蹤 AI 生態的參考資源使用

## 原始摘要

涵蓋內容：LLM 模型與能力比較、AI Agent framework、RAG、MCP / Tool Calling、Prompt Engineering、Multi-Agent 系統、AI Coding workflow、Open-source AI tools、AI infra 與部署工具。開源社群維護，可持續擴充與協作。
