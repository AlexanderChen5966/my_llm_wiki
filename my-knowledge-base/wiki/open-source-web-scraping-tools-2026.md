## T（核心論點）

給 LLM／Agent 用的網頁擷取工具，各自解決不同層次的問題——不是選一個「最好的」，是依情境選對的：**要立刻可用選 Firecrawl，要自主掌控選 Crawl4AI，要互動操作選 Browser-use，要規模化選 Scrapy，要反封鎖選 Crawlee，要長期維護低成本選 Scrapling**。而聲稱「零成本做成月入 5,000 美元服務」的說法**嚴重低估真實成本**——住宅代理、CAPTCHA 解題、改版維護、監控值班才是真正的支出。

## B（適用場景）

**適用：** 建 Agent 需要抓取網頁內容、評估要不要自架爬蟲 vs 用付費服務

**不適用 / 注意：**
- **抓取合法性與使用授權是兩件事**——「公開可存取」不等於「你有權限」
- 先檢查目標網站是否有現成 JSON API，很多時候不需要爬蟲

## R（六個工具定位）

| 工具 | 做什麼 | 適合時機 |
|---|---|---|
| **Firecrawl** | URL → 乾淨 Markdown（非帶導覽列/Cookie 橫幅的原始 HTML）；`crawl` 爬整站、`map` 列 URL 清單不抓內容、結構化擷取抽型別化 JSON | 想立刻能用，不想自組爬蟲團隊 |
| **Crawl4AI** | 開源非同步 Python 爬蟲，輸出可直接餵 LLM 的 Markdown；無 API 金鑰、無額度限制 | 大量需求、有基礎設施團隊、資料不能合法交給第三方服務 |
| **Browser-use** | 把 LLM 接到真實瀏覽器操作——點擊、輸入、捲動、填表、登入、多步驟結帳；**用英文描述目標，自己理解 DOM** | 目標網站真的需要互動、流量不大，否則得人手操作 |
| **Scrapy** | Python 爬蟲框架：請求排程、並行、重試、中介軟體、資料管線、自動節流。**2008 年起在正式環境使用，爬過頁面數比其他工具加總還多** | 大量、穩定、多半靜態的目標站——「無聊但正確的答案，最能養活公司」|
| **Crawlee**（Apify）| Node.js（現支援 Python）：代理輪替、工作階段管理、瀏覽器指紋偽裝、帶退避的自動重試、可續跑的請求佇列 | Node 生態系，或目標站充滿敵意需要反封鎖工具堆疊又不想花錢 |
| **Scrapling** | 🔑 **會自我修復**：記住某元素「原本是什麼」，網站重新設計時（`.product-title` 變 `.ProductCard__title--x7f2`）**根據相似度重新找到元素**，而不是回傳空清單 | 長期維護很多 spider，selector 腐化才是真正瓶頸 |

> Firecrawl 與 Crawl4AI 已收斂到同一洞見：**輸出對 LLM 友善的 Markdown 而非原始 HTML**，是這代擷取工具的共同標準。

## 🔴 「零成本月入 5,000 美元」的成本真相

名單開發代理商向客戶收費，講法常是「開源零成本、趕快去賺」——**這句話的「你的成本是零」承擔了太多**：

- **住宅代理**：最大宗支出，任何開源專案都不附送
- **CAPTCHA 解題**
- **改版維護**：四個目標網站同週改版時，工程師投入的工時
- **儲存、監控、值班告警**

> 代理商真正收費的**不是免費好用的爬蟲程式碼**，是**營運層**——保證就算網站週日改版，資料週一還是會出現。這是真實的服務，值真正的錢。**你要先知道自己到底在賣什麼。**

## 讓你不惹上麻煩的四條實務原則

1. **先讀 `robots.txt` 並遵守**——有禮貌的爬蟲活得比較久；強硬的爬蟲很快被封 IP 段
2. **在對方限速你之前先自己限速**——併發數 2 加一點延遲通常就夠，沒必要對小型網站每秒送 200 個請求
3. **檢查服務條款**，尤其需要登入的內容——**「公開可存取」和「你有權限」是兩件不同的事**
4. **個資是另一個法律宇宙**——GDPR/CCPA 不管資料是不是在公開頁面上；抓產品價格 vs 抓含 email 的姓名，根本不是同一件事

## 🔑 最有價值的一條建議：先看有沒有現成 API

> 打開 devtools，用 Fetch/XHR 過濾 network 分頁仔細看看。**我寫過的爬蟲大概三分之一，其實只要對當時已存在的某個 JSON 端點下三行指令就夠了。**

## C（關鍵行動）

- [ ] 抓取前先開 devtools 檢查 Network／XHR，很多時候不需要爬蟲
- [ ] 依需求選對工具：立即可用 Firecrawl／自主掌控 Crawl4AI／互動操作 Browser-use／規模化 Scrapy／反封鎖 Crawlee／長期維護 Scrapling
- [ ] 動手前讀 `robots.txt`、自己先限速、確認服務條款
- [ ] 涉及個資時**另外評估 GDPR/CCPA**，不要用「反正是公開頁面」當理由
- [ ] 評估自架 vs 買服務時，把住宅代理、CAPTCHA、改版維護、監控算進真實成本
