### Extensions 管理這些擴充功能

這邊的設置就是你從 Raycast 的 Store 當中安裝的外掛或者原生的程式都可以在這邊進行 Alias 或者 Hotkey 設置，讓你可以快速的訪問想執行的項目。

Raycast extension

### Organization 設置

#### 建立和分享擴充功能

- 私人擴充功能商店：Raycast 允許團隊在私人商店中建立、分享和發現擴充功能。這個商店僅對組織成員開放，確保了擴充功能的私密性和安全性。
- 發布私人擴充功能：團隊成員可以開發擴充功能並通過運行 npm run publish 命令將其發布到組織的私人擴充功能商店中。這些擴充功能僅對組織成員可見。

#### 團隊協作和管理

- 管理組織：Raycast 提供了管理組織的命令，允許用戶查看組織成員、重設邀請連結和編輯組織詳情。
- 邀請團隊成員：通過「Copy Invite Link」，可以分享訪問權限給團隊成員，並通過電子郵件接收加入組織的通知。
- 共享快速連結：Raycast 允許團隊成員共享快速鏈接，方便訪問常用的網站、GitHub、項目文件等。
- 共享片段：團隊可以使用共享片段來儲存和放入團隊最常用的文字，如支援回應、代碼審查格式或者是信件回覆等，通過關鍵字自動擴展，減少打字的時間。
- 自定義主題和 AI 功能：Raycast Pro 版本提供了 AI 功能、自定義主題等，使得 Raycast 可以根據個人和工作設置保持同步，並且可以根據用戶的需求進行個性化設定。不過因為我沒付費使用就不多贅述這塊了。

## Raycast 主要功能，簡單卻超實用

### 關鍵字搜尋檔案，直接列出所有相關連檔案給你

Raycast 的強大之處，首先來自其最基本的功能：快速啟動程式與檔案搜尋。只需設置一組快速鍵 (預設為 option + Space)，就能隨時喚醒 Raycast，然後輸入應用程式或檔案名稱的關鍵字，即可獲取結果並啟動。這比傳統方式 (如搜尋 Spotlight 或找硬碟資料夾) 還要快上數倍。

### 計算機、顏色選擇、貨幣轉換一個視窗全滿足

除了檔案與程式，Raycast 內建了諸多實用的小工具，如計算機、顏色選擇器、貨幣換算等，僅需幾個快速鍵就能快速呼叫使用，不必再開啟其他應用程式，大幅減少切換的時間浪費。

## 客製化，成就獨一無二的 Raycast 體驗

Raycast 最吸引人的一點，莫過於其高度客製化的可能。每個人的工作模式不盡相同，我們可以根據自己的喜好和需求，調整 Raycast 的外觀和預設行為，創造出獨一無二的使用體驗。

首先，它提供多種內建主題和配色方案，或者你也可以按照個人風格，自行設計分享獨特的主題。其次，快速鍵組合和許多偏好設定都可以手動調整，使 Raycast 與你的使用習慣高度契合。

除了基本客製化外，透過安裝第三方擴充功能，也能大大延伸 Raycast 的功能範疇。我個人最常用的擴充功能有文字編輯、Markdown 預覽、執行 Shell 指令、 ~~Search for GIFs~~ 等，都是無價的小幫手。只要在擴充商店裡尋找並啟用，就能享受更多實用的工作助手了。

當然，如果你是開發者或有一些程式基礎，更可以嘗試自行開發專屬的 Raycast 擴充功能。Raycast 開發文件相當健全，除了詳細的 API 教學外，也提供了許多範例供參考。\[4\]\[9\] 只要稍加努力，就能打造出獨一無二的專屬工具，完全自定義你的終極生產力體驗。

## 使用心得，真正改善我的工作流程

身為一名內容創作者，我的主要工作就是寫作、蒐集素材和內容管理，而且我還有主業要顧。自從開始使用 Raycast 後，工作效率真的得到前所未有的提升。

原本需要不斷切換應用程式，搜尋雲端硬碟、資料庫或編輯軟體裡的檔案，現在只需在 Raycast 輸入關鍵字，就能找到任何一個想開的檔案或是應用程式。再也不怕忘記檔案的存放路徑，也不需要滑鼠東點西點地尋找，真是種解放。

Raycast 的擴充功能更是實用無比，我找到了一個可以快速分享常用網址的小工具。只需幾個快速鍵，就能立即複製想分享的連結，大幅加快我製作摘要內容的流程。也曾嘗試過用於 Git 版本控制、啟動虛擬開發環境等等，全然改變了過去效率低落的工作模式。

最重要的是，Raycast 成為我工作的指揮中心。不用一直切換應用程式，我可以在 Raycast 介面中搜尋、瀏覽和控制其他應用程式的資源，還能運行自製的各種生產力工具，幾乎所有工作都能在這個窗口中高效完成。使用起來真的相當直覺順手，雙手也不需要太常離開鍵盤。
