## 安裝 Raycast

### 最快安裝方式：透過 Homebrew

如果你已經安裝 Homebrew，打開終端機輸入這一行就搞定：

```
brew install --cask raycast
```

還沒裝 Homebrew？也沒關係：

1. 前往 [raycast.com](https://www.raycast.com/)
2. 點擊「Download for Mac」（需 macOS 13 或更新版本）

> 💡 小提醒：首次啟動後，系統可能會要求你授予「輔助功能」、「螢幕錄製」等權限—— ****務必允許**** ，否則部分功能無法運作。

## 替換 Spotlight（這步最重要！）

這裡有個關鍵建議： ****不要同時用 Spotlight 和 Raycast**** 。

這樣只會讓你的操作習慣分裂，永遠無法真正上手。 ****正確做法是：直接把 Spotlight 的快捷鍵交給 Raycast！****

### 如何徹底替換 Spotlight：

****第一步：關掉 Spotlight 的快捷鍵****

1. 打開「系統設定」→「鍵盤」→「鍵盤快速鍵」
2. 左側點選「聚焦」
3. ****取消勾選**** 「顯示聚焦搜尋」（⌘ + 空白鍵）
![關閉 Spotlight 快捷鍵](https://resize-image.vocus.cc/resize?norotation=true&quality=80&url=https%3A%2F%2Fimages.vocus.cc%2Fad446bfe-57c1-41a4-a531-61448fe240d0.jpeg&width=740&sign=WznbjzikV9e6bUnAJRwCbQkhoT5IQ0xNg-axyNdqEXE) ![zoomable](https://images.vocus.cc/ad446bfe-57c1-41a4-a531-61448fe240d0.jpeg)

關閉 Spotlight 快捷鍵

****第二步：把 ⌘ + 空白鍵綁定給 Raycast****

1. 開啟 Raycast
2. 按下 ⌘ +,（逗號）打開偏好設定
3. 點選「一般」→「Raycast 快速鍵」
4. 點一下輸入框，然後按下 ****⌘ + 空白鍵****
5. 按下「儲存」

****為什麼一定要用 ⌘ + 空白鍵？****

因為你的手指早已對這個組合鍵形成肌肉記憶。沿用它，代表 ****零學習成本、無痛轉移**** ！

![設定 Raycast 快捷鍵](https://resize-image.vocus.cc/resize?norotation=true&quality=80&url=https%3A%2F%2Fimages.vocus.cc%2Ff987118e-ffe1-4b80-87f4-c82f66a8ff9f.jpeg&width=740&sign=xsqH2tBHcwiu2mA-YL6BfrY_LgpEZKWIR9KWZVlytdo) ![zoomable](https://images.vocus.cc/f987118e-ffe1-4b80-87f4-c82f66a8ff9f.jpeg)

## 三大神級功能，立刻提升工作效率

### 功能一：剪貼簿歷史（Clipboard History）

****痛點**** ：你複製了一段重要文字，結果不小心又複製了別的東西——原始內容瞬間消失。

****解決方案**** ：Raycast 會自動保存你過去 ****3 個月內的所有剪貼內容**** ！

舉例：你在寫 Email，需要貼上 5 個不同資訊（地址、姓名、電話等）。

傳統做法：來回切換複製 5 次。 用剪貼簿歷史： ****先一口氣複製完所有內容，再依序貼上**** ，效率翻倍！

![剪貼簿歷史](https://resize-image.vocus.cc/resize?norotation=true&quality=80&url=https%3A%2F%2Fimages.vocus.cc%2Fca382510-7f7a-4e43-aa73-821dbd21286b.jpeg&width=740&sign=XJ069qiNLvdK7Mm2rEHlLwyhrgUu2w8Y5vzU0lhe1pA) ![zoomable](https://images.vocus.cc/ca382510-7f7a-4e43-aa73-821dbd21286b.jpeg)

### 功能二：文字片段（Text Snippets）

****痛點**** ：你總在重複輸入相同內容——Email 簽名、公司地址、常用問候語……

****解決方案**** ：設定一個簡短關鍵字，自動展開成完整文字。

****使用方式**** ：在任何地方輸入

```
;簽名
```
，它就會立刻替換成你的完整 Email 簽名檔。

## 安裝你的第一個擴充套件

擴充套件（Extensions）能為 Raycast 添加全新指令。目前已有 ****1300+ 套件**** ，涵蓋 GitHub、Notion、Spotify、Jira 等主流工具。

****如何瀏覽擴充商店**** ：

1. 打開 Raycast，輸入 “store”
2. 按 Enter 進入「Extension Store」
3. 可依分類瀏覽或直接搜尋

****實戰：安裝「取色器」（Color Picker）****

1. 在商店搜尋 “Color Picker”
2. 點擊「Install」安裝
3. 使用方式：⌘ + 空白鍵 → 輸入 “color picker” → 點擊螢幕任意位置即可取得顏色值
![vocus｜新世代的創作平台](https://resize-image.vocus.cc/resize?norotation=true&quality=80&url=https%3A%2F%2Fimages.vocus.cc%2Fd9543f1f-a758-485c-a9f7-23e41f40fa0f.jpg&width=740&sign=4NlrkFP-IP2OBcKmTzwg5UVGl5W0Ap4N9wscNxyaoZA) ![zoomable](https://images.vocus.cc/d9543f1f-a758-485c-a9f7-23e41f40fa0f.jpg)

****其他新手友善的擴充推薦**** ：

- ****Emoji**** ：比系統表情符號面板更快搜尋與插入 emoji
- ****Calendar**** ：不用打開日曆 App，直接查看今日行程
- ****Spotify**** ：不切換視窗就能控制音樂播放

多數擴充需要綁定 API 或帳號，但 Raycast 會提供清晰的引導步驟，完全不用擔心設定太複雜。
