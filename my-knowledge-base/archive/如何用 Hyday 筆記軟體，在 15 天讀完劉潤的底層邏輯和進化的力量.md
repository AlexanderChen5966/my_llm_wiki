如何用 Hyday 筆記軟體，在 15 天讀完劉潤的底層邏輯和進化的力量.md

身為一個愛買書的人，最大的困擾應該就是沒時間細細品嚐，所以我用了自己做的 [Hyday](https://hyday.web.app/) 筆記軟體，幫助我讀完了劉潤的「底層邏輯」和「進化的力量」，從 03/29 到 04/12，共計 15 天讀完了 13 個章節

![](https://hyday.web.app/screenshot.png)

Hyday

Your Second Brain — 整合筆記、日誌、任務與 AI 洞察的桌面應用，所有資料以 Markdown 儲存在本地。

我的計劃是利用 Hyday 與 AI 將每一個章節都做成結構化筆記，然後透過 Hyday buddy 的記憶系統，將文章與我的生活進行連結，收斂出我可能感興趣的內容

透過 AI 閱讀的目的，不是為了讓閱讀這件事情變快 (因為我還是要自己吸收)，我是想把閱讀這件事拆成一個可重複的工作流，讓他從一件費力的事情變成一件自動發生的事情

## 檢討自己為什麼讀不完書

我讀書的流程大概是這樣：在書店看到一本有興趣的書 → 買回家 → 放在書桌上 → 視而不見 → 突然想到打開翻兩頁 → 又放回桌上 → Loop

我也不是沒有時間，也不是書不好看，而是我沒有建立一個良好的習慣在固定的時間讀書，也沒有激勵自己一定要產出，所以總是有時間的時候閱讀，沒時間或是空閒下來時，閱讀也不是我的第一目標；然後夜深人靜只會在那邊焦慮：「啊，我今天又忘了讀書…」

所以我決定了！

我不要靠意志力，我要靠工作流！

什麼意思呢？

## 閱讀流程的三個小技巧

### 1\. 讓進度被寫下來，不要放在腦袋裡

前面提到我是用 Orbit Agent 執行排程，我用的是 `claude -p` 每次執行都會開一個新的 session，因此 Hyday AI 不會記得上次讀到哪，所以我的解法很簡單，就是寫一個 JSON 檔，讓 Hyday AI 在閱讀前查詢，在輸出後更新進度

reading-progress.json

```
xxxxxxxxxx
```

```
{
```

```
"current_sub_book_title": "進化的力量",
```

```
"current_part": 8,
```

```
"current_part_title": "瘋狂生長",
```

```
"parts_read": 13,
```

```
"total_parts": 13
```

```
}
```

每讀完一個章節，系統會在 `history` 加一筆日期紀錄，讓我知道 Hyday AI 是什麼時候閱讀的

### 2\. 給筆記固定的格式與結構化

我覺得自己以前做的讀書筆記沒啥結構化，大概就是看到哪一段有共鳴才會寫，沒共鳴的就 Let It Go，但有時候明明是很棒的內容，卻因為我沒共鳴略過，事後想引用時才發現根本沒記下來，結果又要重新翻書 ….

所以現在我透過 SKILL 給 Hyday AI 訂好結構，以下是整份筆記的結構：

- 一句話總結：AI 超愛做這個，靠 AI 提煉，也讓我閱讀筆記時，可以快速進入狀況
- 本章重點：前面有提到，我不想要簡單的摘要，而是透過分段、有層次的內容，讓我可以深入了解章節的每個重點
- MUKI 會感興趣的部分：因為 Hyday 主動紀錄了我的興趣、正在做的專案、甚至是最近在煩惱的事情，所以 Hyday AI 會自動找出我可能感興趣的段落並整理給我
- 補充說明：很多書籍都會帶入專有名詞，如果不熟悉會看不懂，所以我請 Hyday AI 把這些名詞、背景、歷史典故補一段白話解釋，這樣我讀筆記時就能前後對照
- 啟發時刻：我請 Hyday AI 帶領我思考：「這篇筆記有哪些概念，可以用在我的專案上？」，自動把書裡的觀點關聯到我正在做的事情，變成我的靈感庫
- 金句摘錄：金句不解釋，一定要有的

### 3\. 用雙向連結建立筆記關聯

先說在前面，筆記的雙向連結不是 Hyday AI 自己建立的，我請 Hyday AI 做的這些讀書筆記，他們每一篇都是獨立的，不會互相指向

這些雙向連結，都是我自己讀筆記時發現，然後再請 AI 建立的，所以我是真的有在讀，而且有讀進去，表示這一套流程真的對我有用

以我的情況為例：

我在閱讀「進化的力量」的私域和飛輪時，就覺得他們跟「第五項修練」的增強迴路、「窮查理的普通常識」的 Lollapalooza 效應，以及「納瓦爾寶典」的複利概念很像

然後我就會跟 Hyday AI 討論，這次建立了一個 wiki 主題叫做增強迴路，前後把七本書的同一個概念整成一張表格。真心覺得超酷的，我瞬間就能融會貫通惹

## 閱讀、學習並實踐

以前閱讀完寫筆記大概就停了，最多就是把筆記發到部落格而已，很難有後續的下一步行動，現在有了 Hyday AI，至少有人可以討論，也能請他幫我出出主意，看能否進一步進行實踐

我讀完「流量新生態」的章節後，就在想劉潤講的私域 (私有化、回購率、轉介紹) 是否能用在 Hyday 上？

以前的我大概只能想到這就斷掉了，因為我還真沒有把各種事物連結起來的 sense，現在我問了 Hyday AI，他給了我建議說最大的變現槓桿不是把軟體賣貴一點，並用這三個概念重新詮釋了 Hyday：

- 私有化：我 (MUKI) MUKI space\* 的讀者 → Hyday 使用者
- 回購率：讓使用者每天打開 Hyday (不是收訂閱費)
- 轉介紹：AI buddy 記得你半年前寫過什麼，這是一種極致的感動 XXD

就…，不管他是不是硬湊，至少他給了我一個方向，讓我不用從 0 開始

然後這也是有個有趣的閉環，我透過 Hyday 讀書，又透過讀書打造 Hyday

## 如何複製這套閱讀流程

如果你跟我一樣，也有讀不完書的困擾，歡迎參考我的用法，打造你自己的閱讀流程

當然，你不一定要用 Hyday，但如果用了，再串接 Hyday AI 會變得方便許多唷！

### 如何讓流程更完善

1. 把筆記放在你每天會打開的 APP 中：軟體真的不是重點，重點你會每天打開他，所以不管是 Hyday、Obsidian、Notion，甚至備忘錄 … 等等，只要有開就有機會
2. 結構化筆記：不要用「抄」書轉成筆記，而是要讓訂好結構化的格式，然後把裡面的內容填滿。愈完整、愈結構化，未來就愈容易被搜尋、被整合
3. 待機時間不要太長：我是一個沒啥儀式感的人，也是個急性子，如果每次讀書都要有儀式感，我就會嫌麻煩直接放棄

之前就提到我現在不是要靠意志力，是要靠工作流，所以工作流設計得愈簡單無腦，我的使用意願就會愈高

## 小結

在 15 天讀完兩本書，換成過去的我是不可能的，現在我做到了，因為我把讀書變成了一個流程，而且是先被動接收，再主動閱讀，這不一定適合每個人，但我還蠻受用的 XXD
