## 核心論點

Claude Design 的三大限制：
1. 工具鎖定（只能在 claude.ai/design 使用）
2. 雲端依賴（資料上傳 Anthropic 伺服器）
3. 訂閱費用（需額外付費）

Open Design 對應解決：本地優先、MIT/Apache 授權、BYOK 自帶 API Key

## 補充數字（早期版本統計）

- 31 Skills + 71 Design Systems（早期，現已擴展到 259+ Skills / 142+ Design Systems）
- SQLite 本地儲存在 `.od/` 資料夾

## 支援的 Agent CLI

Claude Code / Codex / Cursor Agent / Gemini CLI / OpenCode / Qwen CLI / GitHub Copilot / Hermes / Kimi CLI
