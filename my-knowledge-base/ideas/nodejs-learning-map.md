前端轉全端的 7 層能力地圖 + 15 個資源 + 4 條學習路線。核心觀點：問「我該學哪個框架」不如問「我現在缺哪一塊能力」。

**7 層能力與對應資源：**
1. Node.js 基礎：Node.js Learn、MDN Express/Node Tutorial
2. 框架選擇：Next.js（React 過渡）、Hono（輕量邊緣）、Fastify（高效能）、NestJS（工程化）
3. 系統課程串接：Full Stack Open
4. 資料庫 ORM：PostgreSQL Tutorial、Prisma（TypeScript 友好）、TypeORM（NestJS 生態）
5. 介面驗證：Zod（runtime 驗證 + TypeScript 型別推導雙合一）
6. 快取 Redis：node-redis
7. 部署工程化：Docker Node.js Guide、PM2、Node.js Best Practices

**4 條推薦路線：**
- 快速全端專案：Next.js → Prisma → Zod → Docker → PM2
- 後端基本功：Node.js Learn → MDN Express → PostgreSQL → Fastify → Best Practices
- 工程化後端：Node.js Learn → NestJS → TypeORM → PostgreSQL → PM2 → Best Practices
- 補交付能力：Full Stack Open → Zod → node-redis → Docker → PM2
