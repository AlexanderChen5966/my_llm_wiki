## 補充資訊

本文章版本（DeTools 介紹）補充了幾個原條目可能沒有的細節：

**協作優先設計流程：**
```
Question → Options → Decision → Draft → Approval
```
所有流程要求：先提出問題 → 提供選項 → 等待決策 → 展示草稿 → 使用者批准 → 才進行修改。

**已知的 Slash Commands：**
- `/start` `/create-epics` `/create-stories` `/quick-design`
- `/ux-design` `/create-architecture` `/architecture-review`
- `/content-audit` `/story-readiness` `/story-done`

**引擎支援：** Godot Engine / Unity / Unreal Engine（各有專屬 Agent 和工作流程）

**定位**：AI 遊戲開發「作業系統」，不是讓 Claude Code 幫忙寫程式，而是把 AI 轉變成整個虛擬遊戲工作室。
