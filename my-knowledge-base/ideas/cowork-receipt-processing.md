用 Claude Cowork 整理整疊發票圖檔，自動抓日期/金額/統編建成 Excel，模糊發票標紅提示，10 分鐘內完成。

**5 步驟：**
1. 備份到全新資料夾，確保無個資混入
2. Cowork 新任務，拖曳資料夾
3. 下達指令（包含預期結果/操作規則/背景/完成標準）
4. 確認執行計畫（**安全鎖：先列計畫等確認，再執行**）
5. 驗收結果，重點看紅色標記列

**指令範本：**
```
請幫我讀取這個資料夾裡所有的發票圖檔，整理成一張 Excel 表。
表格欄位：日期、發票號碼、金額（按日期排序）。
請確認每張是否打統編：XXXXXXXX。
模糊或無法辨識的列標記為紅色，告訴我是哪個檔案。
請先列出執行計畫，等我確認後再開始，不要直接更動檔案。
完成後回報：處理幾張、合計總金額。
```

**關鍵設計：** 「先列計畫等確認」是減少 AI 誤動檔案的安全鎖——這個 Cowork prompt 設計模式可複用到其他批次處理任務。
