AudioMass 是免費開源的瀏覽器音訊編輯器，利用 Web Audio API 在本機完成所有運算，不需上傳到雲端。

**核心功能：**
- 音訊裁切/剪輯、錄音、音量調整、淡入淡出、壓縮器、均衡器
- 完全在瀏覽器執行（隱私友善、可離線、無需安裝）
- 介面接近 Audacity，有 Waveform 波形編輯

**適用場景：** Podcast 基本編輯、課程錄音整理、語音內容剪輯、音訊格式轉換前處理。

不是完整 DAW，不適合多軌錄音或複雜混音。
