Tripo AI 建立的免費 3D Prompt 與案例資料庫「Tripo 3D Prompts」，收錄 342 條精選提示詞，跨模型整理（GPT-6 Astra、Claude Fable 5/5.1、Claude Opus 5、Kimi K3），取材自創作者實際公開的完整 3D 專案（Blender、Three.js、WebGPU、Godot、Unreal），而非自動生成的通用提示詞。可轉用判準與 211+ 篇相同：明確區分「作者原文分享」vs「依公開資訊重建的參考版本」；使用建議是保留 Prompt 中的 Scene Hierarchy、Controls、Feedback Loop 結構，替換 Subject/Camera/Color Palette 再套用。定位是「創意與工作流資料庫」，與 Tripo Studio 的 Text-to-3D 生成功能互補。若要深入查原文可看其分類篩選與實測影片案例。

與 [[tripo-gpt6-astra-3d-prompts-gallery]] 為同生態互補資源——本篇是跨模型（GPT-6 Astra/Claude/Kimi）342 條的總覽庫；前者是 Tripo 官方建立、GPT-6 Astra 專屬的 211+ 案例子集，並列參考，不合併。
