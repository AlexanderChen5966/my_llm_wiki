Hermes Agent（Nous Research）推出官方 Desktop GUI，Windows / macOS / Linux 一鍵安裝，自動連接既有 CLI 安裝的資料。

**主要功能：**
- 左側欄：Sessions / Messaging（Telegram/Email/WhatsApp/Slack）/ Skills & Tools
- 兩種 Gateway 模式：Local Gateway（本地）vs Remote Gateway（雲端）
- 需設定 API Key + 選擇模型

**注意：** 相關 wiki 已有 [[hermes-agent]] 詳細說明框架架構（三層長效記憶），Desktop 版本是 GUI 封裝，不改變底層能力。
