用 AI 做好網站後，部署是最後一關。不同平台解決不同問題。

**速查表：**

| 平台 | 最適合 | 門檻 |
|------|--------|------|
| GitHub Pages | 熟 GitHub 的靜態網站 | 要懂 repo / push / branch |
| Vercel | 前端工程師（Next.js/React）| Git + 專案結構知識 |
| Zeabur | 後端 / 資料庫 / Bot / Docker | 偏工程取向，概念多 |
| Pipee 派比部署 | AI 網站新手、創作者 | 貼程式碼或上傳 ZIP 就能上線 |

**Pipee（派比部署）的定位：**
不是要取代其他平台，而是解決「AI 做好了但不會部署」的最後一哩路問題。貼入 HTML/CSS/JS 或上傳 ZIP → 取名字 → 按部署 → 取得公開網址。學習成本最低。

**選擇邏輯：**
- 已是工程師 → Vercel / Zeabur / GitHub Pages
- 非工程師 + AI 生成網站 + 想快速上線 → Pipee
- 需要後端/資料庫 → Zeabur
- 已熟 GitHub + 靜態網站 → GitHub Pages
